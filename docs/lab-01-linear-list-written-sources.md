## 转录修正与答案取舍

- 2011：下中位数是第 n 项。公开解析含 `s2=1` 等下标问题及错误复杂度；本 Lab 用二分划分独立推导。只归并到第 n 项也可只用 O(1) 辅助空间，不能称归并必需 O(n) 空间。
- 2013：确认条件为严格超过 n/2。笔记 `(0,1,2,3)` 的候选追踪与其代码不一致，本 Lab 按所给算法追踪为 candidate=2、count=0，并强调最终验证。
- 2018：标记访问必须同时检查 `1<=x<=n`；公开代码遗漏上界。本题仅要求时间高效，O(n) 标记空间是合法方案。
- 2020：转录称三项“均为正数”，但给出的集合与样例包含负数，整理为整数；距离恒等式与三指针证明对整数仍成立。
- 2025：补充包含自乘 j=i、输出 res 与辅助空间分开计算，以及足够宽的整数运算；不使用对负乘数错误提取 max 的中间式。
- 2015：明确带头结点、范围包含 0、删除需释放。清零 n+1 个标记后，总时间应为 O(m+n)，不能只写链表扫描的 O(m)；不声称直接寻址总优于散列。
- 2019：原笔记 slow/fast 都从头结点起，在奇数长度 5 时前半仅有 2 项，照其合并代码会漏掉中间结点。改从首元结点开始，前半取 ceil(n/2)，断链后再逆置/交错，并检查所有结点身份。
- 拆分题：明确 A、B 是不同的预分配空头结点，C 结束为空；奇位尾插时立即断尾，保证每轮结果链都独立。PNG 根据题面重绘，DOT 源随图保存。
- 交集题：第 11 题明确新分配失败的回收结果；第 12 题采用 A、B 结点不共享的所有权模型，并分析放宽为共享尾段时需补充的证明。严格递增的共享尾段可被原算法完整保留，不将不共享误称为数学上必需的条件。
- 匹配题：严格使用连续子序列含义；复杂度取可证明的最坏界，不沿用无分布假设的“期望接近线性”。
- 判环题：相对速度论证在 slow、fast 均入环后展开；比较地址而非数据，不把初始相等当作环。
- 频度题：原笔记“不允许修改 val/freq 之外内容”与必须前移结点矛盾，整理为只改 freq 及必要 pre/next、不改 data；等频时必须继续前移。数据值唯一作为 Locate 返回对象的明确前提。
