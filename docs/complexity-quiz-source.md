# 时间复杂度习题
## 第1题
设 n 是描述问题规模的非负整数，下面程序片段的时间复杂度是（）。
```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```
- A. $O(\log n)$
- B. $\(O(n)\)$
- C. $O(n\log n)$
- D. $O(n^2)$

> 答案：**A**
> 解析：x每次翻倍，循环次数以2为底对数级增长。

---

## 第2题
求整数 $n(n\ge0)$ 阶乘的算法如下，其时间复杂度是（）。
```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```
- A. $O(\log_2n)$
- B. $\(O(n)\)$
- C. $O(n\log_2n)$
- D. $O(n^2)$

> 答案：**B**
> 解析：递归调用n次，线性复杂度。

## 第3题
下列程序段的时间复杂度是（）。
```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```
- A. $O(\log_2n)$
- B. $\(O(n)\)$
- C. $O(n\log_2n)$
- D. $O(n^2)$

> 答案：**C**
> 解析：外层循环$\log_2n$次，内层循环n次，总次数 $n\log_2n$。

## 第4题
下列函数的时间复杂度是（）。
```c
int func(int n) {
    int i = 0, sum = 0;
    while(sum < n)
        sum += ++i;
    return i;
}
```
- A. $O(\log_2 n)$
- B. $O(n^{1/2})$
- C. $\(O(n)\)$
- D. $O(n\log_2 n)$

> 答案：**B**
> 解析：$sum=1+2+\dots+i=\frac{i(i+1)}{2}\ge n$，$i\approx\sqrt{2n}$，循环次数根号n。

## 第5题
设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是()。
```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```
- A. $O(\log n)$
- B. $O(n^{1/2})$
- C. $\(O(n)\)$
- D. $O(n^2)$

> 答案：**B**
> 解析：条件$(x+1)^2 \le n$，$x\le \sqrt{n}-1$，循环$\sqrt{n}$次。

## 第6题
下列程序段的时间复杂度是（）。
```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```
- A. $O(\log_2 n)$
- B. $\(O(n)\)$
- C. $O(n\log_2 n)$
- D. $O(n^2)$

> 答案：**B**
> 解析：i取值 $\(1,2,4,8...\)$，内层循环总次数 $1+2+4+\dots < 2n$，总次数$\(O(n)\)$。

## 第7题
以下C代码的时间复杂度是（）。
```c
int count = 0;
for (int i=0; i*i<n; i++)
    for (int j=0; j<i; j++)
        count++;
```
- A. $O(\log_2n)$
- B. $\(O(n)\)$
- C. $O(n\log_2n)$
- D. $O(n^2)$

> 答案：**B**
> 解析：外层循环条件 $i^2<n \Rightarrow i<\sqrt{n}$；内层循环j<i，总次数$\sum_{i=1}^{\sqrt{n}}i \approx \frac{n}{2}$，复杂度$\(O(n)\)$。

## 第8题
下列关于 $\(T(n)=O(f(n))\)$ 这一记号的说法中，正确的是()。
- A. 存在正常数 $c$ 和 $n_0$，当 $n \ge n_0$ 时 $T(n) \le c\cdot f(n)$
- B. 对于所有 $n \ge 1$，都有 $T(n) \le f(n)$
- C. $\(O(2n)\)$ 与 $\(O(n)\)$ 表示两个不同的复杂度类
- D. $O(n^2) \subseteq \(O(n)\)$，即小复杂度类包含于大复杂度类

> 答案：**A**
> 解析：大O记号定义：存在正常数$c,n_0$，$n\ge n_0$满足$T(n)\le c\cdot f(n)$。

## 第9题
设 $n$ 充分大。下列关于复杂度函数渐近增长由慢到快的排序中，错误的是()。
- A. $O(1) < O(\log n) < \(O(n)\) < O(n\log n)$
- B. $O(n^2) < O(n^3) < O(2^n) < O(n!)$
- C. $O(\sqrt{n}) < \(O(n)\) < O(n^2)$
- D. $O(n\log^2 n) > O(n^2)$（即$n\log^2 n$渐近大于$n^2$）

> 答案：**D**
> 解析：n足够大时，多项式$n^2$增长速度远快于$n\log^2n$。

## 第10题

- A. $\(O(n)\)$
- B. $O(n\log n)$
- C. $O(n^2)$

> 答案：**B**

> **答案：C**

## 第12题
下列关于时间复杂度与空间复杂度的说法中，错误的是()。
>提示：本题不考排序细节，只看额外空间来源。归并排序合并时通常把结果先写入辅助数组 `tmp[0…n\(1,2,\dots,n‑2\)1]`；快速排序原地划分，主要额外空间来自递归调用栈。

- A. 算法的空间复杂度通常只考虑辅助空间，不包括输入数据本身所占的存储
- B. 时间复杂度低的算法，其空间复杂度也一定低
- C. 归并排序的时间复杂度为 $O(n\log n)$，但需要 $\(O(n)\)$ 的辅助空间
- D. 快速排序平均时间复杂度为 $O(n\log n)$，递归调用栈使其平均空间复杂度为 $O(\log n)$

> **答案：B**
> 解析：时间复杂度和空间复杂度没有必然联系，时间快不代表占用空间小。

## 第13题
下列代码段的时间复杂度是()。
```c
int count = 0;
for (int i = n; i > 0; i /= 2) {   //外层: i 从 n 折半递减
    for (int j = 0; j < i; j++) { //内层: j 走 i 次
        count++;
    }
}
```
- A. $O(\log n)$
- B. $\(O(n)\)$
- C. $O(n\log n)$
- D. $O(n^2)$

> **答案：B**
> 解析：总执行次数 $n+\frac{n}{2}+\frac{n}{4}+\dots \approx 2n$，总和是 $\(O(n)\)$。

## 第14题
下列函数 fun 的时间复杂度是()。
```c
int fun(int n) {
    if (n <= 1) return 1;
    int a = fun(n / 2);    // 第一次递归调用
    int b = fun(n / 2);    // 第二次递归调用
    return a + b;
}
```
- A. $O(\log n)$
- B. $\(O(n)\)$
- C. $O(n\log n)$
- D. $O(2^n)$

> **答案：B**
> 解析：递推 $\(T(n)=2T(n/2)+1\)$，主定理求得 $T(n)=\(O(n)\)$。

## 第15题
假定 $\(n>2\)$，执行下面的语句时，语句 S 的执行次数为（）。
```c
for (i = 1; i < n - 1; i++)
    for (j = n; j >= i; j--)
        S;
```
- A. $n(n-1)$
- B. $(n+3)(n-2)/2$
- C. $(n+2)(n-1)/2$
- D. $n(n-1)/2$

> **答案：B**
> 解析：i取值 $1,2,\dots,n\(1,2,\dots,n‑2\)2$；每轮内层循环次数：$n-i+1$。
> $$\sum_{i=1}^{n-2}(n-i+1)=\sum_{k=3}^{n}k=\frac{(n+3)(n-2)}{2}$$

## 第16题
若某算法的空间复杂度为 $\(O(1)\)$，则表示该算法（）。

- A. 不需要任何辅助空间
- B. 所需辅助空间大小与问题规模 $n$ 无关
- C. 不需要任何空间
- D. 所需空间大小与问题规模 $n$ 无关

> **答案：B**
> 解析：$\(O(1)\)$常量空间，辅助空间不随n变化；算法本身仍要用少量临时变量。D包含输入空间，空间复杂度统计**辅助空间**。

## 第19题
设 $n$ 是描述问题规模的正整数，则下列程序段的时间复杂度是（ ）。
```c
i = n * n;
while (i != 1)
    i = i / 2;
```
- A. $O(\log_2 n)$
- B. $O(\sqrt{n})$
- C. $\(O(n)\)$
- D. $O(n^2)$

> **答案：A**
> 解析：初始 $i=n^2$，每次除以2，循环次数 $\log_2(n^2)=2\log_2 n$，复杂度$O(\log_2 n)$。
