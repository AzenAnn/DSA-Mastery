# Lab 02-E-10：逆波兰表达式求值

## 学习目标

- 用操作数栈处理以空白分隔的有符号整数和四则运算。
- 保持减法、除法的左右操作数顺序，并约定除零及栈数量错误。
- 分析每个 token 恰好处理一次的复杂度。

## 前置知识与环境

建议先学习[第 2 章栈与队列](../../../../content/chapter-02-stack-queue/00-overview.md)。使用 ISO C++17；开始前可在本目录运行 `make doctor`。

## 任务

按顺序读取 token。整数入栈；二元运算符弹出两个数：先弹出的是右操作数，再弹出的是左操作数。计算 `left op right` 并将结果入栈。除法采用 C++ 整数除法，即向零截断，例如 `-7 / 3 = -2`。

## 输入格式

第一行 token 数 `n`；第二行包含恰好 `n` 个、以空白分隔的整数或 `+ - * /` token；当 `n=0` 时第二行为空。

## 输出格式

全部 token 处理结束后，栈恰有一个结果则输出该整数；否则输出 `ERROR`。遇到不认识的 token、操作数不足或除数为零也输出 `ERROR`。`n=0` 时输出 `ERROR`。每次运算结果保证在 64 位有符号范围内。

例如输入 `5` 和 `2 1 + 3 *`，先求 `2+1=3`，再求 `3*3=9`，输出 `9`。输入 `3` 和 `8 3 -` 输出 `5`，不是 `-5`。

## 数据范围与限制

- 输入规模不超过 `200000`，除题面另有说明外整数使用 64 位有符号范围。
- `0 <= n <= 200000`；每个操作数和每次运算结果都必须落在 64 位有符号整数范围内，保证不会发生溢出。
- 除数为 `0`、操作数不足或最终栈中不是恰好一个结果时，输出 `ERROR`。
- 标准输出只保留题目要求的结果；调试信息写入标准错误。
- 目标算法应为线性或摊还线性时间，辅助空间不超过 `O(n)`。

## 边界与验收重点

- 单个整数就是答案；空表达式和末尾剩余多个数均输出 `ERROR`。
- `1 +` 操作数不足；`3 0 /` 除零；负数 token `-3` 不等同于减号 `-`。
- 先记录右操作数，再记录左操作数，不能交换减法或除法的顺序。
