# Lab 02-E-09：括号匹配

## 学习目标

- 用栈保存尚未匹配的左括号，并只与最近的左括号配对。
- 区分类型错误、先遇到右括号和扫描结束仍有左括号三种失败。
- 解释为何每个括号只入栈或出栈一次。

## 前置知识与环境

建议先学习[第 2 章栈与队列](../../../../content/chapter-02-stack-queue/00-overview.md)。使用 ISO C++17；开始前可在本目录运行 `make doctor`。

## 任务

从左到右扫描输入。遇到 `(`、`[`、`{` 时等待匹配；遇到 `)`、`]`、`}` 时，它必须与最近尚未匹配的左括号同类。其他 ASCII 非空白字符（包括字母和尖括号）不参与配对，直接跳过。

## 输入格式

一行字符串 `s`，仅含 ASCII 非空白字符，可含括号与普通字符；长度 `1..200000`。空字符串不作为输入。

## 输出格式

所有括号正确配对且没有剩余左括号时输出 `YES`，否则输出 `NO`，末尾换行。

例如 `a{[b](c)}d` 输出 `YES`；`([)]` 输出 `NO`，因为遇到 `)` 时最近的左括号是 `[`。

## 数据范围与限制

- 输入规模不超过 `200000`，除题面另有说明外整数使用 64 位有符号范围。
- 标准输出只保留题目要求的结果；调试信息写入标准错误。
- 目标算法应为线性或摊还线性时间，辅助空间不超过 `O(n)`。

## 边界与验收重点

- 单个左括号和单个右括号都应输出 `NO`。
- `([)]` 的数量相同仍不匹配；`{[()]}` 则正确嵌套。
- 普通字符不改变等待配对的栈；字符串末尾不能留下左括号。

## 题解

<details>
<summary>点击查看题解</summary>

### 思路与不变量

从左到右扫描字符串。左括号入栈，右括号只能匹配当前栈顶；普通字符跳过。扫描到任意位置时，栈中从底到顶正好是已经出现但尚未闭合的左括号，栈外的括号都已经完成匹配。

### 算法步骤

1. 遇到 `(`、`[`、`{` 就压栈；
2. 遇到右括号时，先检查栈非空，再检查栈顶类型是否匹配；不满足则立即输出 `NO`；
3. 匹配成功后弹出栈顶；
4. 扫描结束后，栈为空才输出 `YES`。

### 正确性说明

右括号必须关闭最近尚未关闭的左括号，因此只能与栈顶比较。若栈为空或类型不同，当前前缀已经无法修复；若结束时栈非空，则仍有左括号未关闭。因此算法输出 `YES` 当且仅当所有括号都按嵌套顺序完成匹配。

### 复杂度分析

- 时间复杂度：`O(|s|)`，每个字符只扫描一次；
- 额外空间：`O(|s|)`，最坏情况下所有字符都是左括号。

### 边界注意

- 普通字符不入栈，也不改变匹配状态；
- 右括号先检查空栈，不能访问不存在的栈顶；
- 只检查数量相等是不够的，`([)]` 仍然是不合法嵌套。

</details>
