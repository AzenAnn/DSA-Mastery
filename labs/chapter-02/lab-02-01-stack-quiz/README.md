# Lab 02-04：栈选择题精练

## 目标

辨析栈的后进先出语义、空栈和满栈边界、括号匹配原则，以及常见复杂度判断中的误区。

## 前置知识

建议先阅读第 2.1 节栈的定义与实现，并能区分“操作位置”和“元素访问顺序”。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔或错题记录。
- **输入**：本页按源文件顺序整理的 10 道选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击“提交答案”，再核对对错、正确答案和题解；
3. 做错的题点击“重新作答”后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再使用答案速查表复核，避免只记答案字母。

- [ ] 10 道题均在展开答案前独立作答；
- [ ] 每道错题都记录了错误原因，而不只抄写正确答案；

- [ ] 复做错题时能够在不看解析的情况下得到正确结论。

## 思考题

1. 栈为什么适合括号匹配和表达式求值，而不适合“按值查找”的通用场景？
2. 什么时候“空栈时返回失败”是必要条件，而不是多余的异常设计？
3. 顺序栈和链栈的满/空判定分别依赖哪些状态变量？它们的边界约定有何不同？

## 复盘

- 我最容易在哪个前提上出错：结构语义、边界条件，还是复杂度分析？
- 我是否能把入栈/出栈的顺序画成栈顶变化图，而不是只记住关键词？
- 哪道题的干扰项最容易混淆？它利用了哪个常见误区？
