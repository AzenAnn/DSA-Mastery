### 综合题 1：出栈序列的禁形与条件计数

**来源**：2026 年 408 真题第 42 题（`ds-2026-42`，题面整理）；本 Lab 评分细分为 12 分。

入栈序列为 $1,2,\ldots,n$，元素互异，栈容量足够，允许入栈与出栈交替进行。

1. 当 $n=9$ 时，分别判断序列 `2,3,1,6,4,7,5,9,8` 和 `2,3,1,5,6,7,4,9,8` 能否得到，并给出阻挡证据或可行过程。（3 分）
2. 对输出序列中的 $p_i,p_j,p_k$，其中 $i<j<k$，哪一种大小关系能证明序列不可能得到？说明原因。（3 分）
3. 当 $n=4$ 时，列举所有以 2 开头的合法出栈序列，给出总数。（2 分）
4. 已知 $n=k-1$ 时全部合法出栈序列共 $M$ 个，$k\ge2$。当 $n=k$ 时，以 1 开头、以 2 开头以及所有合法出栈序列分别有多少个？给出推导。（4 分）

::: details 综合题 1 参考答案与评分要点

**（1）第一条不合法，第二条合法。**

第一条先输出 `2,3,1` 后栈空。为输出 6，必须依次压入 4、5、6。弹出 6 后，5 压在 4 上方，无法立即输出 4。

第二条可按下表完成。`+x` 为入栈，`-x` 为出栈，栈状态均从底到顶列出。

| 阶段 | 操作 | 阶段后栈状态 | 新输出 |
| --- | --- | --- | --- |
| 1 | +1 +2 -2 +3 -3 -1 | 空 | 2,3,1 |
| 2 | +4 +5 -5 +6 -6 +7 -7 -4 | 空 | 5,6,7,4 |
| 3 | +8 +9 -9 -8 | 空 | 9,8 |

**（2）禁止出现 $p_i>p_k>p_j$，即 312 型。**

因为 $p_i$ 最大，在它入栈前，较小的 $p_j$ 与 $p_k$ 都已入栈；它们尚未出栈，因为在输出中的位置更后。按递增输入顺序，$p_k$ 后入且压在 $p_j$ 上方。弹出 $p_i$ 后，不可能在 $p_k$ 之前输出 $p_j$，矛盾。第一条序列中的 `6,4,5` 就是这样的三元组。

**（3）共有 5 个。**

```text
2,1,3,4
2,1,4,3
2,3,1,4
2,3,4,1
2,4,3,1
```

先压 1、2 并弹出 2，剩余输入是 3、4，而 1 已在栈底。后续情形与三个有序元素 1、3、4 的合法栈输出一一对应，因此枚举没有漏项。

**（4）依次为 $M$、$M$、$\dfrac{4k-2}{k+1}M$。**

以 1 开头时，必须先压入并立即弹出 1，剩下的 $k-1$ 个元素是同规模问题，故为 $M$。

以 2 开头时，先压 1、2 并弹 2，剩下 1 已在栈中、3 至 k 尚未进入。对有序输入 1、3、…、k 的任意合法操作，其第一步本就必须压 1；省略这一步便与当前状态的后续操作一一对应，仍为 $M$。

设全部合法序列数为 $C_n$。按元素 1 在第 $r+1$ 个位置出栈分类：在 1 前输出的必是 2 至 $r+1$，其内部有 $C_r$ 种；1 后是剩余元素的栈输出，有 $C_{n-1-r}$ 种。不同位置的类别互斥且穷尽，因此

$$
C_0=1,\qquad C_n=\sum_{r=0}^{n-1}C_rC_{n-1-r}.
$$

也可把入栈/出栈看作上升/下降步：长度 $2n$、各有 n 步的平衡路径共 $\binom{2n}{n}$ 条，合法路径要求任何前缀出栈数不超过入栈数。对首次跌到高度 -1 的坏路径，将此前的步方向反转，得到含 $n+1$ 次上升、$n-1$ 次下降的路径；这是可逆映射，坏路径共 $\binom{2n}{n-1}$ 条。故

$$
C_n=\binom{2n}{n}-\binom{2n}{n-1}=\frac{1}{n+1}\binom{2n}{n}.
$$

这里 $M=C_{k-1}$，约去组合数中的阶乘可得

$$
\frac{C_k}{C_{k-1}}=\frac{2(2k-1)}{k+1},
\qquad C_k=\frac{4k-2}{k+1}M.
$$

**评分要点（12 分）**：第一条阻挡证据 1 分、第二条可行过程 2 分；禁形大小关系 1 分、压栈先后与矛盾证明 2 分；五条无重无漏的枚举 2 分；两个条件计数及一一对应理由各 1 分，总数关系及推导 2 分。只写数值而无依据的子问至多得该子问一半分。

:::

### 综合题 2：空间只增不减的队列设计

**来源**：2019 年 408 真题第 42 题（`ds-2019-42`）；保留四项要求，并增加边界核验，按 12 分计。

设计一个队列，满足：初始为空；入队时允许增加占用空间；出队结点的空间可重复使用，队列所占空间只增不减；每次入队、出队都保持 $O(1)$，不能仅满足摊还 $O(1)$。

1. 选择顺序或链式存储并说明理由。（2 分）
2. 画出初始状态，明确 front、rear 的含义以及判空、判定当前空间无可用槽位的条件。（3 分）
3. 画出第一个元素 x 入队后的状态。（1 分）
4. 给出入队、出队的伪代码；说明空队出队失败，以及“入队 x、入队 y、出队两次、再入队 z”时的结点复用情况。（6 分）

::: details 综合题 2 参考答案与评分要点

**（1）选择保留所有已分配结点的循环单链表。**

需要扩容搬移全部元素的普通连续数组，其扩容那次操作为 $O(n)$，不符合“每次 $O(1)$”。普通出队就释放结点的链队列又不符合空间保留要求。本题以每次至多分配一个结点、其成本计为 $O(1)$ 的模型分析。

**（2）使用一个随出队移动的空位标记，而非永久固定的头结点。**

- front 指向逻辑队头的前一个结点；rear 指向逻辑队尾。
- 非空时，从 `front->next` 沿 next 到 rear 的闭区间是有效数据区，front 本身不属于有效数据；`front == rear` 时有效数据区为空。
- rear 之后、front 之前是可供下次入队复用的空闲结点；永远保留 front 这个空位。
- 队空：`front == rear`。现有环没有可复用槽位：`rear->next == front`，此时入队需要增配一个结点。

初始只分配结点 u，自环：

```text
front, rear -> u
u.next = u
```

初始状态同时“逻辑为空”和“现有空间无可用数据槽”。两者不矛盾：当前环只有用于区分状态的一个空位，首次入队允许扩充。

**（3）第一次入队 x 后：**

```text
front -> u -> v(x) <- rear
         ^     |
         +-----+
```

新增 v，`u.next=v`、`v.next=u`；front 仍为 u，rear 为 v。

**（4）伪代码如下，失败不修改队列。**

```text
EnQueue(x):
    if rear.next == front:
        p = allocateNode()
        if allocation failed: return false
        p.next = rear.next
        rear.next = p
    rear = rear.next
    rear.data = x
    return true

DeQueue(out):
    if front == rear: return false
    front = front.next
    out = front.data
    return true
```

出队把 front 移到原队头并取走值；这个结点从此成为新的空位标记，其残留 data 不再属于队列。整个环不删结点，也不释放空间。这样 front 所指结点会变化，不能把最初的 u 当作永远固定的哨兵。

复用轨迹如下，u、v、w 为物理结点编号：

| 操作后 | 物理环 | front | rear | 逻辑队列 | 已分配结点数 |
| --- | --- | --- | --- | --- | --- |
| 初始化 | u → u | u | u | 空 | 1 |
| 入 x | u → v → u | u | v | x | 2 |
| 入 y | u → v → w → u | u | w | x,y | 3 |
| 出 x | u → v → w → u | v | w | y | 3 |
| 出 y | u → v → w → u | w | w | 空 | 3 |
| 入 z | u → v → w → u | w | u | z | 3 |

最后一次入队时 `rear.next=u`，而 `front=w`，有空闲槽位，直接复用 u，不发生分配。每次操作只做常数次访问与指针修改。若历史最大逻辑长度为 H，最小初始方案总计保留 H+1 个结点，空间为 $O(H+1)$；空间不会随着每一次出入队无止境增长。

**评分要点（12 分）**：选型及单次复杂度理由 2 分；指针含义、数据/空闲区和两个判定 3 分；首次入队图 1 分；入队按需扩展且失败不破坏环 2 分；出队不释放且空队不修改 2 分；复用轨迹与复杂度 2 分。其他自洽的循环链结构亦可，不能混用两套 front/rear 约定。

:::

### 综合题 3：共享栈的空间不变量与固定分区比较

**来源**：基于笔记“栈的应用”共享栈题（`ds-drill-stack-application-012`、`016`）整理的综合训练，非原考试大题。**分值：12 分。**

数组 `A[0..m-1]` 同时存放两个栈 L、R。L 从左端向右增长，R 从右端向左增长。topL、topR 指向实际栈顶，空栈初值分别为 -1、m，$m\ge2$。

1. 写出两栈的元素数、空闲槽位数及允许状态的不变量，并推导判空、判满条件。（3 分）
2. 当 $m=10$、`topL=2`、`topR=7` 时，依次向 L 压入两项、向 R 压入两项；再尝试向 L 压入一项。列出每一步的指针值，说明最后一步的结果。（3 分）
3. 写出左右两栈的 Push/Pop 关键伪代码，要求先检查边界再修改指针，失败保持状态不变。（3 分）
4. 若改成 L 永久分配 a 个槽、R 分配 m-a 个槽，证明不存在一个固定 a 能同时支持占用峰值分别为 `(m,0)` 和 `(0,m)` 的两类工作负载；共享方案为何能够支持？说明它仍不能解决什么溢出。（3 分）

::: details 综合题 3 参考答案与评分要点

**（1）不变量由实际占用区间得到。**

$$
|L|=topL+1,\quad |R|=m-topR,\quad free=topR-topL-1.
$$

合法指针满足 $-1\le topL<topR\le m$。L 空当且仅当 `topL==-1`，R 空当且仅当 `topR==m`。共享空间满当且仅当 `topL+1==topR`，此时空闲槽为 0。不存在“L 分到的一半满了”的单独容量限制。

**（2）轨迹如下。**

| 操作 | topL | topR | 空闲槽 | 结果 |
| --- | --- | --- | --- | --- |
| 初始 | 2 | 7 | 4 | L、R 各 3 项 |
| PushL | 3 | 7 | 3 | 成功 |
| PushL | 4 | 7 | 2 | 成功 |
| PushR | 4 | 6 | 1 | 成功 |
| PushR | 4 | 5 | 0 | 成功，空间刚满 |
| PushL | 4 | 5 | 0 | 失败，指针和数据均不变 |

**（3）先判断再修改。**

```text
PushL(x):
    if topL + 1 == topR: return false
    topL = topL + 1
    A[topL] = x
    return true

PushR(x):
    if topL + 1 == topR: return false
    topR = topR - 1
    A[topR] = x
    return true

PopL(out):
    if topL == -1: return false
    out = A[topL]
    topL = topL - 1
    return true

PopR(out):
    if topR == m: return false
    out = A[topR]
    topR = topR + 1
    return true
```

四种操作都只访问本栈栈顶，时间为 $O(1)$，额外辅助空间为 $O(1)$。Pop 无须擦除旧值，只需令旧槽不再属于有效区。

**（4）固定分区无法适配两种相反峰值。**

支持 `(m,0)` 要求 $a\ge m$；支持 `(0,m)` 要求 $m-a\ge m$，即 $a\le0$。由于 $m>0$，两条件不能同时满足。

共享栈仅要求两栈当前元素总数不超过 m，能把全部槽位临时让给任一栈，因此支持这两类工作负载。它解决的是固定分区下的闲置空间问题，不能在两栈**同时**总需求超过 m 时避免真实溢出。

**评分要点（12 分）**：三项计数、不变量、空满判定 3 分；完整轨迹与失败不变 3 分；四个操作及边界检查 3 分；固定分区矛盾、共享优势和真实容量限制各 1 分。

:::

### 综合题 4：仅用尾指针拼接与旋转循环链队列

**来源**：基于笔记“队列”尾指针循环链结构（`ds-drill-queue-016`）延伸的综合训练，非原考试大题。**分值：12 分。**

两个队列 A、B 分别采用**不带头结点**的循环单链表，仅长期保存队尾指针 rearA、rearB；空队列尾指针为空，非空队列的队头为 `rear->next`。两个队列对象不同，结点互不共享。允许使用常数个临时指针。

1. 设计 `Append(A,B)`：将 B 的全部元素接到 A 后面，保持两个原队列内部次序，之后 B 变为空队列。不得逐个搬移数据、分配或释放结点，要求最坏 $O(1)$。（5 分）
2. 非空队列 `a,b,c,d` 执行一次“队头转到队尾”，只修改哪个指针即可？写出结果，并说明空队列、单元素队列如何处理。（3 分）
3. 对 A=`a,b,c`、B=`d,e`，画出拼接前后所有改变的 next 链接。证明算法仍形成一个完整环，并说明为什么“复制 rearB 给 rearA 后保留 B 非空”不满足要求。（4 分）

::: details 综合题 4 参考答案与评分要点

**（1）非空情况下交换两条跨边即可。**

```text
Append(A, B):
    if B.rear == null: return
    if A.rear == null:
        A.rear = B.rear
        B.rear = null
        return

    headA = A.rear.next
    headB = B.rear.next
    A.rear.next = headB
    B.rear.next = headA
    A.rear = B.rear
    B.rear = null
```

当 B 空时 A 不变；当 A 空且 B 非空时，只转移尾指针的所有权。两者都非空时，必须先保存原队头，防止第一次改链接后失去原环的入口。整个操作只改常数条链接，最坏时间和额外空间均为 $O(1)$。

**（2）非空时执行 `rear=rear->next`。**

物理 next 链接不变；新的 rear 是原队头，新队头是原队头的后继，因此 `a,b,c,d` 变为 `b,c,d,a`。空队列保持空并返回失败或约定的无操作结果，不能解引用空指针；单元素自环执行后还是自身，队列次序不变。

**（3）只改变 c 与 e 的 next。**

```text
拼接前：a -> b -> c -> a     d -> e -> d
                rearA           rearB

改动：  c.next: a -> d
        e.next: d -> a

拼接后：a -> b -> c -> d -> e -> a
        rearA = e, rearB = null
```

从 headA 出发，先经过 A 的全部原结点，再通过 `c.next=d` 进入 B，经过 B 的全部原结点，最后通过 `e.next=a` 回到起点。因原来两个环各自完整且不共享结点，新环恰好经过全部结点一次，内部次序保持不变。

若仅 `rearA=rearB` 而不连接两个环，会丢失 A 的原队列。即使已正确拼接，仍让 B 的 rear 非空也会使两个队列对象共同引用同一个环；后续出队、销毁可能影响另一队列或重复释放，不满足“B 变空、结点归 A 所有”的后置条件。题设排除 `Append(A,A)`，不能忽略这一前提。

**评分要点（12 分）**：两个空队分支 2 分、非空拼接与清空 B 2 分、常数复杂度 1 分；旋转指针和结果 2 分、空/单元素边界 1 分；两条改边 2 分、环与次序证明 1 分、所有权说明 1 分。

:::

### 综合题 5：受限双端队列的可达序列与计数

**来源**：基于笔记“双端队列”和“队列”受限出队题整理的综合证明训练（`ds-2010-02`、`ds-drill-queue-014`），非原考试大题。**分值：12 分。**

输入为互异元素 $1,2,\ldots,n$，$n\ge1$。本题统一要求**全部元素入队结束后，才开始出队**，容量足够。

1. 对输出受限双端队列，允许左右两端入队，只允许左端出队。证明可达输出序列恰好由“严格递减的一段、元素 1、严格递增的一段”构成，两段均可为空；据此求不同输出序列总数。（5 分）
2. 对输入受限双端队列，只允许右端入队，允许两端出队。给出判断某个排列可达的必要充分条件，并求不同输出序列总数。（4 分）
3. 当 $n=4$ 时，分别给出一个只由第 1 种结构可达的排列和一个只由第 2 种结构可达的排列，说明可行过程及另一结构不可行的原因。（3 分）

::: details 综合题 5 参考答案与评分要点

**（1）输出受限：每个大于 1 的元素只需决定放在哪一侧。**

必要性：1 最先进入。之后左插的元素位于 1 前，按入队次序的反序出现，所以严格递减；右插的元素位于 1 后，按原入队次序出现，所以严格递增。

充分性：给定这样的目标排列，把 1 前的元素依其原输入次序从左端插入，把 1 后的元素从右端插入，就能构造出目标排列。故该形状既必要又充分。

对每个 $2,\ldots,n$，独立决定左插或右插，共 $2^{n-1}$ 种。目标序列中哪些元素在 1 前可唯一恢复这些选择，所以没有重复计数。$n=1$ 时仅有序列 `(1)`，公式仍得 1。

**（2）输入受限：每次输出必须是剩余区间的一个端点。**

全部右插结束后，物理队列为 `1,2,...,n`。令 $l=1,r=n$，按目标排列依次读取 x：

```text
if x == l: l = l + 1
else if x == r: r = r - 1
else: reject
```

如果每一步都通过检查，则相应从左或右端删除即可，充分性成立；若某步 x 不是端点，它被剩余元素夹在内部，不能直接取出，必要性成立。判断的时间为 $O(n)$，额外空间为 $O(1)$。

前 $n-1$ 步每步恰有两个不同端点可选，最后只剩一个元素，不再产生新选择。不同选择在第一次分歧处就产生不同输出，故总数同样为 $2^{n-1}$，而不是 $2^n$。

**（3）数量相同不表示集合相同。**

| 排列 | 可达结构与过程 | 另一种结构为何不可达 |
| --- | --- | --- |
| 3,1,2,4 | 输出受限：依次入 1、右插 2、左插 3、右插 4，再从左端取完 | 输入受限全入后的端点只有 1、4，无法首先输出 3 |
| 1,4,2,3 | 输入受限：全入后依次从左、右、左、左取出 | 输出受限中 1 后必须严格递增，而 4 在 2 前不满足 |

这里的全部入队后再出队是证明的一部分。放宽为任意交替操作后，不能直接沿用本题的计数公式。

**评分要点（12 分）**：输出受限的必要性 2 分、充分性 1 分、计数及无重性 2 分；输入受限的端点条件与双向论证 2 分、计数和最后一步处理 2 分；两组正确反例与可达/不可达理由 3 分。
