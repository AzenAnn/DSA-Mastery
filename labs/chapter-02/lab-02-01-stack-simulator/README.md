# Lab 02-01：栈模拟器与括号匹配

## 目标

实现一个带明确错误处理的栈模拟器，并用它完成括号匹配检查，验证后进先出的语义与边界行为。

## 前置知识

- 第 1 章线性表的顺序存储与链式存储；
- 第 2.1 节栈的 ADT 与复杂度分析。

## 建议用时

90～120 分钟。

## 任务

1. 任选一种语言，实现一个栈，公开 `push`、`pop`、`top`、`is_empty`、`size` 五个操作；`pop` 与 `top` 在空栈时必须返回明确错误（异常、可空结果或错误码），不能静默返回默认值。
2. 用 `push`/`pop` 序列验证 LIFO 语义：`push(1), push(2), pop() == 2, pop() == 1`。
3. 实现 `is_balanced(s)`：对只含 `( ) [ ] { }` 的字符串判断括号是否正确嵌套。
4. 对输入的括号串输出调试日志（每步的字符、栈内容、操作与结论）。

## 提交物

- 可运行代码（含 `main` 或测试入口）；
- 运行结果输出（至少包含下方验收清单的全部用例）；
- 200 字以内的实现说明：为什么空栈必须显式失败。

## 验收标准

- [ ] `pop`/`top` 在空栈时返回明确错误，且程序不崩溃；
- [ ] LIFO 语义测试通过：后入先出；
- [ ] `is_balanced("{[()]}")` 返回 true；
- [ ] `is_balanced("{[(])}")` 返回 false（交叉嵌套错误）；
- [ ] `is_balanced("(()")` 返回 false（左括号未闭合）；
- [ ] `is_balanced(")(")` 返回 false（右括号先行）；
- [ ] 调试日志逐字符可读，能看出每一步的栈状态；
- [ ] 报告每个用例的退出码或断言结果。

## 加分项

- 统计不同括号类型不匹配的输入，报告是哪一步失败（栈顶是什么、期望是什么）；
- 把栈换成链栈实现再跑同一组测试，比较两种实现的行为差异。
