# Lab 00-01：制作个人 DSA 学习地图

## 目标

把“我要学数据结构”转化为一份可检查、可迭代的学习计划，并熟悉本项目的主动输出闭环。

## 建议用时

30～45 分钟。

## 任务

1. 选择本学期准备学习的 6～10 个主题，画出先后依赖关系。
2. 为其中一个主题写出“解释、实现、测试、审阅”四类最小产出。
3. 与同伴交换学习地图，各提出一个范围过大点和一个遗漏点。
4. 根据反馈完成一次修订，并保留修订说明。

## 提交物

- 一份 Markdown 学习地图；
- 一段不超过 150 字的修订说明。

## 验收标准

- [ ] 至少包含 6 个明确主题与合理顺序；
- [ ] 至少一个主题具有四类可验证产出；
- [ ] 能指出本月“必须做”和“以后再做”的内容；
- [ ] 有同伴反馈和对应修改记录。

## 思考

如果两周后进度落后，你会删减哪些非核心工作，同时保留怎样的最小学习闭环？
