# Lab 00-02：用操作计数观察增长趋势

## 目标

通过记录基本操作次数，直观比较常数、线性和平方级算法的增长趋势，并区分理论分析与机器计时。

## 建议用时

45～60 分钟。

## 任务

1. 编写三个小函数，使基本操作次数分别近似为 `1`、`n` 和 `n²`。
2. 对 `n = 10、100、1000` 记录操作次数；过慢时可以减小最大输入。
3. 将结果整理为表格，写出每个函数的时间复杂度判断。
4. 任选一个函数测量运行时间，说明计时为何可能波动。

## 提交物

- 可运行代码；
- 一张操作次数表；
- 100～200 字结论。

## 验收标准

- [ ] 计数器统计的是明确写出的基本操作；
- [ ] 实验至少包含 3 组递增规模；
- [ ] 理论数量级与记录趋势相符；
- [ ] 结论没有把 `O(n)` 解释成固定秒数；
- [ ] 能指出至少一个计时误差来源。

## 加分项

增加一个每次将问题规模减半的函数，观察 `O(log n)` 的增长趋势。
