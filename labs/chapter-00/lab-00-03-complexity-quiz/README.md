# Lab 00-03：复杂度计算自测

## 目标

在浏览器里直接作答 8 道选择题，练习三步分析法：定义规模 → 数基本操作 → 保留主导项。覆盖 `O(1)`、`O(log n)`、`O(n)`、`O(n log n)`、`O(n²)` 与额外空间判断，并包含"两层循环不一定是 O(n²)"的陷阱题。

## 建议用时

20～30 分钟，建议先读完教材 0.2 节「复杂度入门」再做。

## 作答方式

每题先选择一个选项，再点击「提交答案」；提交后立即显示对错，并给出正确答案与计算过程。做错的题，先看题解、自己再推一遍，然后点击「重新作答」。

## 完成清单

- [ ] 8 道题全部作答，错题的题解都能独立复述
- [ ] 能说出"两层循环不一定是 O(n²)"的一个反例

## 思考题

1. 第 4 题把内层循环改为 `for (int j = 0; j < n * n; j++)`，复杂度变成多少？
2. 第 7 题若改用额外数组缓存结果，空间复杂度变为多少？
3. 若题目没有说明统计口径，"空间复杂度 O(n)" 指的是什么空间？

## 复盘

- 我常把哪类代码误判成 O(n²)？
- 判断空间复杂度时，我是否先说明了统计口径（是否包含输入本身）？
- 文字描述题和代码题相比，哪个更容易出错？为什么？
