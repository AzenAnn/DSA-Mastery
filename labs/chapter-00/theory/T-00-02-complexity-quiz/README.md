# Lab 00-T-02：复杂度计算自测

## 目标

在浏览器里直接作答 19 道选择题，练习三步分析法：定义规模 → 数基本操作 → 保留主导项。覆盖 `O(1)`、`O(log n)`、`O(√n)`、`O(n)`、`O(n log n)`、`O(n²)`、`O(2ⁿ)` 等复杂度形态，并包含递推主定理、渐近增长排序与空间复杂度判断，以及「两层循环不一定是 O(n²)」「递归不一定是 2ⁿ」等陷阱题。

## 建议用时

30～45 分钟，可随 [0.2 时间与空间复杂度概论](../../../../content/chapter-00-introduction/02-time-and-space-complexity.md)分组完成。每次先写计数依据，再选择答案；不要求在入门阶段提前掌握主定理。

代码题默认输入规模非负（题面另有限定时从其限定），整数运算不溢出，基本算术按常数成本计；运行实验时应限制输入范围。若选项使用 O 列出若干量级，选择与实际增长同阶的最紧一项；第 11 题明确用 Θ，避免把有效但较松的上界误当唯一答案。

::: warning 常见陷阱
- 看到两层循环不要直接选 O(n²)——先看内层循环次数是否随外层联动变化（第 3、6、7、13 题是四道对照题）；
- 递归时间累计各调用的非递归工作，不能只看深度；仅当每次调用成本同阶时，才能简化为调用次数乘单次成本（第 2、14 题）；
- 渐近分析忽略常数与低阶项，讨论的是充分大的输入；`20000log₂n` 并非对每个小 `n` 都小于 `n`（第 17 题）；
- 折半的正整数先到 1 再到 0；只改停止值会多一次除法，不会变成平方级（第 19 题）。
:::

## 思考题

1. 第 6 题把内层循环改为 `for (int j = 0; j < n; j++)`，复杂度变成多少？与第 3 题一致吗？
2. 第 14 题若把 `fun(n/2)` 的两次调用改成 `fun(n-1)` 两次，复杂度变成多少？
3. 第 4 题的 `while (sum < n) sum += ++i;` 改为 `while (sum < n) sum += n;`，复杂度变成多少？
4. 为什么大 O 记法可以忽略对数的底数？（提示：换底公式）

::: details 思考题反馈
1. 数 `sum++`：第 6 题改后每轮内层 `n` 次，共 `⌈log₂n⌉` 轮，时间 `Θ(n log n)`。与第 3 题同阶，但第 3 题的外层是 `<=n`，在 `n` 为 2 的幂时多一轮，精确次数不总相同。
2. 对正整数 `n`，两次 `fun(n-1)` 的总调用数满足 `C(n)=1+2C(n-1)`、`C(1)=1`，解为 `2^n-1`，时间 `Θ(2^n)`。兄弟调用依次返回，最大活跃深度为 `n`，辅助空间 `Θ(n)`。
3. `n>0` 时第一次就把 `sum` 从 0 变成 `n`，只执行一轮；`n=0` 时零轮，整体时间 `Θ(1)`。改变的是每轮增量，不能沿用三角和反推平方根。
4. 对固定常数 `a,b>1`，`log_a n=log_b n/log_b a`，分母与 `n` 无关，故同阶。若底数随 `n` 改变，这个常数因子论证就不适用。
:::
