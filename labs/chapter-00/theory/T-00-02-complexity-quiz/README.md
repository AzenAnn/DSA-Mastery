# Lab 00-T-02：复杂度计算自测

## 目标

在浏览器里直接作答 19 道选择题，练习三步分析法：定义规模 → 数基本操作 → 保留主导项。覆盖 `O(1)`、`O(log n)`、`O(√n)`、`O(n)`、`O(n log n)`、`O(n²)`、`O(2ⁿ)` 等复杂度形态，并包含递推主定理、渐近增长排序与空间复杂度判断，以及「两层循环不一定是 O(n²)」「递归不一定是 2ⁿ」等陷阱题。

## 建议用时

30～45 分钟，建议先读完教材 0.2 节「复杂度入门」再做。题量大，可以分两次完成：先做第 1～10 题，休息后再做第 11～19 题。

::: tip 作答方法
每题先选择一个选项，再点击「提交答案」；提交后立即显示对错，并给出正确答案与详细计算过程。做错的题，先看题解、自己再推一遍，然后点击「重新作答」，直到能独立得出正确答案。
:::

::: warning 常见陷阱
- 看到两层循环不要直接选 O(n²)——先看内层循环次数是否随外层联动变化（第 3、6、7、13 题是四道对照题）；
- 递归复杂度看「调用次数 × 每次调用代价」：规模减半与规模减 1 天差地别（第 2、14 题）；
- 渐近分析忽略常数与低阶项：20000log₂n 依然比 n 小（第 17 题）。
:::

## 完成清单

- [ ] 19 道题全部作答，错题的题解都能独立复述
- [ ] 能说出「两层循环不一定是 O(n²)」的至少一个反例并解释原因
- [ ] 能说出「规模每次减半的递归」与「规模每次减 1 的递归」复杂度上的区别

## 思考题

1. 第 6 题把内层循环改为 `for (int j = 0; j < n; j++)`，复杂度变成多少？与第 3 题一致吗？
2. 第 14 题若把 `fun(n/2)` 的两次调用改成 `fun(n-1)` 两次，复杂度变成多少？
3. 第 4 题的 `while (sum < n) sum += ++i;` 改为 `while (sum < n) sum += n;`，复杂度变成多少？
4. 为什么大 O 记法可以忽略对数的底数？（提示：换底公式）

## 复盘

- 我常把哪类代码误判成 O(n²)？误判时是漏看了内层循环次数，还是漏看了外层步长？
- 做递推题时，我是否先写出了递推式再套主定理？
- 判断空间复杂度时，我是否先说明了统计口径（是否包含输入本身）？
- 文字描述题和代码题相比，哪个更容易出错？为什么？
