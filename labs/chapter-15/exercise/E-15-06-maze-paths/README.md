## 题目描述

在 N 行 M 列的网格中有 T 个障碍。从起点走到终点，每次只能向上、下、左、右移动一格，不可走出网格、穿过障碍或重复经过同一个格子。求不同路径的总数。起点没有障碍，终点可能是障碍。

本 Lab 保留原题的标准输入/输出合同。

### 输入格式

第一行 `N M T`；第二行起点与终点坐标 `sx sy fx fy`；之后 T 行每行一个障碍坐标。所有坐标从 1 开始。

### 输出格式

输出合法路径总数。若终点被障碍封住或不可达，输出 `0`。起终点相同时，不移动就是一条路径。

### 数据范围

`1 <= N,M <= 5`，`1 <= T <= 10`，坐标均在网格内。障碍重复描述不会增加可走格子。

### 样例输入

```text
2 2 1
1 1 2 2
1 2
```

### 样例输出

```text
1
```

## 状态与边界

当前位置与本条路径已经经过的格子共同构成状态；visited不是整次搜索的永久标记。

到达终点应立即计数并返回；一条分支结束后必须恢复visited，让其他路径能够使用该格子。

## 复杂度目标

最坏时间 O(4^(N*M))，辅助空间 O(N*M)。计数使用64位整数。
