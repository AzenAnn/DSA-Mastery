## 题目描述

在 n×n 棋盘上放置 n 个皇后，使任何两个皇后都不在同一行、同一列或同一条对角线上。返回全部不同棋盘，使用 Q 表示皇后、. 表示空位。

本 Lab 将原题函数接口适配为标准输入/输出。枚举题的读写框架负责按本页约定排序，核心返回值的含义与原题一致。

### 输入格式

一行整数 n。

### 输出格式

第一行合法棋盘数。每个棋盘紧接着输出 n 行 n 个字符，不加空行。棋盘之间按各行皇后所在列（从0开始）构成的整数序列字典序排列。无解只输出 `0`。

### 数据范围

`1 <= n <= 9`。

### 样例输入

```text
4
```

### 样例输出

```text
2
.Q..
...Q
Q...
..Q.
..Q.
Q...
...Q
.Q..
```

## 状态与边界

每层负责一行；列、行列差、行列和三个占用数组用于O(1)判断攻击关系。

n=2和n=3没有解；对角线下标要平移到非负范围；不能只返回一种方案。

## 复杂度目标

搜索粗略上界 O(n * n!)，另有 O(解数 * n^2) 输出；辅助空间 O(n^2)，答案存储 O(解数 * n^2)。

以上描述核心算法与答案收集的开销。设答案数为 A、单项最大长度为 L，读写框架的字典序整理另需最多 O(A * L * log A) 时间。
