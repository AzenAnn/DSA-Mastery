## 题目描述

给定可能包含重复数字的整数数组 nums，返回所有不同的子集。一个输入位置最多选择一次。两个子集如果各数值的出现次数相同，就视为相同。

本 Lab 将原题函数接口适配为标准输入/输出。枚举题的读写框架负责按本页约定排序，核心返回值的含义与原题一致。

### 输入格式

第一行 n，第二行 n 个整数。

### 输出格式

第一行子集数量，每行子集为 `长度 数字...`，内部升序、集合按数值序列字典序。空子集写 `0`，不得重复输出。

### 数据范围

`1 <= n <= 10`，`-10 <= nums[i] <= 10`。

### 样例输入

```text
3
1 2 2
```

### 样例输出

```text
6
0
1 1
2 1 2
3 1 2 2
1 2
2 2 2
```

## 状态与边界

排序后用start限定后续下标；在同一层跳过重复的值，在不同层仍可以继续取同值。

不能用set先对输入去重，例如[2,2]仍有子集[2,2]；需要去除的是重复答案。

## 复杂度目标

时间 O(n * 2^n)，递归辅助空间 O(n)，答案存储最坏 O(n * 2^n)。

以上描述核心算法与答案收集的开销。设答案数为 A、单项最大长度为 L，读写框架的字典序整理另需最多 O(A * L * log A) 时间。
