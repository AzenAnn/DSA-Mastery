## 题目描述

给定可能含有重复数值的数组 nums，返回所有不同的全排列。每个排列必须恰好使用全部输入位置，各数值的出现次数与输入相同。

本 Lab 将原题函数接口适配为标准输入/输出。枚举题的读写框架负责按本页约定排序，核心返回值的含义与原题一致。

### 输入格式

第一行 n，第二行 n 个整数。

### 输出格式

第一行排列数量，其后每行 `n 排列中的数字...`。排列集合按数值序列字典序输出，不改变每个排列内部的顺序。

### 数据范围

`1 <= n <= 8`，`-10 <= nums[i] <= 10`。

### 样例输入

```text
3
1 1 2
```

### 样例输出

```text
3
3 1 1 2
3 1 2 1
3 2 1 1
```

## 状态与边界

used记录已进入路径的输入位置；相同数字只有前一个副本已被使用时才能选择后一个副本。

不能仅以数值作为used下标；同层重复要跳过，但路径中允许有多个相同数值。

## 复杂度目标

最坏时间 O(n * n!)，递归辅助空间 O(n)，答案存储 O(n * n!)；重复值可减少答案数。

以上描述核心算法与答案收集的开销。设答案数为 A、单项最大长度为 L，读写框架的字典序整理另需最多 O(A * L * log A) 时间。
