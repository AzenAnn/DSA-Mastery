## 题目描述

在 n 行 m 列的棋盘上，一匹马从 (x,y) 出发，每次按照国际象棋中马的走法移动：一个方向走两格，垂直方向走一格。求到达棋盘中每个格子最少需要多少步。

本 Lab 保留原题的标准输入/输出合同。

### 输入格式

一行 `n m x y`，起点坐标从1开始。

### 输出格式

输出 n 行，每行 m 个整数，表示起点到每格的最短步数。起点为0，不可达为-1，数之间用空格分隔。当前洛谷题面不再要求固定场宽。

### 数据范围

`1 <= n,m <= 400`，`1 <= x <= n`，`1 <= y <= m`。

### 样例输入

```text
3 3 1 1
```

### 样例输出

```text
0 3 2
3 -1 1
2 1 4
```

## 状态与边界

棋盘格是顶点，八种合法跳跃是等权边；队列按距离层序展开。

马的跳跃不是四邻移动；应当输出整个距离矩阵，不能只输出一个终点的距离。

## 复杂度目标

时间 O(n*m)，辅助空间 O(n*m)。
