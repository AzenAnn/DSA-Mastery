## 题目描述

给定元素互不相同的整数数组 nums，返回它的所有子集，包括空集与全集。答案中不能含有重复子集。

原题采用函数接口并允许题面规定范围内的结果顺序；本 Lab 使用下面的标准输入/输出约定。读写框架负责输出排序，核心返回值的含义与原题一致。

### 输入格式

第一行整数 `n`，第二行 `n` 个整数。

### 输出格式

第一行输出子集数量。之后每行先输出子集长度，再输出其中的整数。子集内部升序，所有子集按数值序列字典序排列，较短的共同前缀在前。空子集用单个 `0` 表示。

### 数据范围

`1 <= n <= 10`，`-10 <= nums[i] <= 10`，元素互异。

### 样例输入

```text
2
1 2
```

### 样例输出

```text
4
0
1 1
2 1 2
1 2
```

## 状态与边界

每个递归结点的路径本身就是一个子集；只向更大的输入下标扩展。

不要仅在叶子收集答案，否则会漏掉空集和中间长度的子集。

## 复杂度目标

时间 O(n * 2^n)，递归辅助空间 O(n)，返回答案占 O(n * 2^n)。

以上描述核心算法与答案收集的开销。设答案数为 A、单项最大长度为 L，读写框架的字典序整理另需最多 O(A * L * log A) 时间。
