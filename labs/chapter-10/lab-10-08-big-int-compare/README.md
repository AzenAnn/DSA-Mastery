# Lab 10-08：大整数比较（宇宙总统）

题目原型为洛谷 [P1781 宇宙总统](https://www.luogu.com.cn/problem/P1781)。本题的考点是**高精度整数比较**：票数超长，任何内置整型都存不下，但题目只要求比较大小、不要求做运算，因此用字符串即可。

## 目标

完成本题后，你应该能够：

- 判断「只比较、不运算」时是否真的需要高精度运算库；
- 用两条规则比较超长非负整数：位数长的更大；位数相同按字典序；
- 说明为什么字符串字典序恰好等于数值大小（位数相同时）。

## 前置知识

- 字符串的基本操作与字典序比较；
- 内置整型的取值范围（`long long` 约为 ±9.2 × 10¹⁸）。

## 题目

宇宙总统竞选，有 `n` 位候选人，每位候选人的得票数是一个可能非常巨大的正整数。请找出得票最多的候选人。

### 输入格式

- 第一行一个整数 `n`，表示候选人人数；
- 接下来 `n` 行，每行一个正整数，表示该候选人的得票数（无前导零）。

### 输出格式

- 第一行：得票最多的候选人的编号（`1` 到 `n` 的整数，若并列取先出现者）；
- 第二行：该候选人的得票数。

## 数据范围

| 项目 | 范围 |
| --- | --- |
| 候选人人数 `n` | 1 ≤ n ≤ 20 |
| 票数 | 不超过 100 位的正整数 |

## 样例

### 样例输入

```input
5
98765
12365
87954
1022356
985678
```

### 样例输出

```output
4
1022356
```

### 样例解释

五张票中最大的是第 4 位候选人的 `1022356`（七位数，比其它五位数都大）。

### 思路

高精度整数比较只需两条规则：

1. 位数（字符串长度）不同 → 位数长的更大；
2. 位数相同 → 逐位比较，等价于字符串的字典序 `a > b`。

遍历所有票，维护「当前最大值」和它的编号即可，无需排序。

### 复杂度分析

- 时间复杂度：`O(n · L)`，`L` 为票数最大位数；
- 空间复杂度：`O(L)`。
