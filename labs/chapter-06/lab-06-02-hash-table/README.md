# Lab 06-02：散列表实现与冲突统计

## 目标

实现链地址法与线性探测两种散列表，统计冲突与平均探测次数，定量验证负载因子对查找性能的影响。

## 前置知识

- [第 6.5 节 散列表](../../../content/chapter-06-search/05-hash-table.md)中的散列函数、链地址法、开放定址法与装填因子。

## 建议用时

90～120 分钟。

## 任务

1. 实现整数键散列函数 `h(key) = key % m`，支持任意表长 `m`。
2. 实现两种散列表：

   - **链地址法**：槽位为链表，记录每条链的长度；
   - **线性探测**：冲突时探测下一槽，记录每次插入的探测次数。

3. 完成以下对比实验：

   | 编号 | 实验 | 记录与期望 |
   | --- | --- | --- |
   | 1 | `m = 11`，插入 `{50, 63, 5, 90, 76}` | 画出两种结构；线性探测出现聚集 |
   | 2 | 随机 1000 个键，`m = 2000`（α ≈ 0.5） | 平均链长 ≈ 0.5，最长链明显大于均值 |
   | 3 | 随机 1000 个键，`m = 500`（α = 2.0） | 平均链长 ≈ 2，最长链更长 |
   | 4 | 表长为 2 的幂 vs 素数（如 1024 vs 1031），随机键 | 比较两者最大链长差异 |
   | 5 | 全部插入后统计查找成功/失败的平均比较次数 | 与理论 `1 + α/2` 对比 |

4. 输出每个实验的：平均链长（或平均探测次数）、最大链长、查找成功/失败的平均比较次数。

## 提交物

- 两种散列表的可运行代码；
- 五个实验的统计表；
- 100～200 字结论：负载因子增大时性能如何变化，表长取素数是否如理论所说更好。

## 验收标准

- [ ] 链地址法插入与查找正确，失败查找明确返回空；
- [ ] 线性探测实现正确，删除用"已删除"标记且查找仍正确；
- [ ] 实验 2、3 的平均链长与 α 大致吻合；
- [ ] 记录并对比表长取素数前后的最大链长；
- [ ] 报告每个实验的统计数据。

## 加分项

- 实现再散列（扩容）并在 α 超阈值时自动触发，验证扩容后性能回升；
- 用字符串键（加权和散列）重复实验 2，对比整数键的分布质量。
