# Lab 06-02：图的存储结构选择题精练

## 目标

- 从边集读出邻接矩阵与邻接表，并检查有向、无向存储语义；
- 比较指定边查询、邻居枚举和全图扫描的时间与空间复杂度；
- 根据图的密度和高频操作选择矩阵、邻接表、边集数组或混合索引。

## 前置知识

建议先阅读[6.2 图的存储结构](../../../content/chapter-06-graph-foundations/02-graph-storage.md)，并能区分逻辑边数 $m$ 与邻接记录数。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔手写矩阵或邻接表。
- **输入**：本页按源文件顺序整理的 10 道四选一选择题。
- **预期输出**：一份独立作答记录，以及每道错题的复杂度依据或表示选择理由。

## 作答方法

1. 先写清图的方向、权重和底层容器，再判断复杂度；
2. 点击“提交答案”后核对答案与选项辨析；
3. 做错的题点击“重新作答”，并补写被忽略的实现前提；
4. 完成全部题目后再查看答案总览。

## 题型覆盖与边界

| 类型 | 本 Lab 的处理方式 |
| --- | --- |
| 正常情况 | 比较矩阵、动态数组邻接表和边集数组的常见操作 |
| 边界情况 | 单独考查零权边、无向边双向记录和有向图行列含义 |
| 易错情况 | 区分逻辑边与存储记录，并避免脱离容器类型背复杂度 |

## 思考题

1. 为什么“邻接表查询边是 $O(1)$”必须附加哈希等实现前提？
2. 零权边存在时，怎样把“边是否存在”和“权重是多少”分开？
3. 维护邻接表与哈希索引两个视图时，怎样避免更新不一致？
