# Lab 06-E-20：Building Roads

> 题目来源：[CSES 1666](https://cses.fi/problemset/task/1666/)。本 Lab 使用下述本地数据范围与规范化输出。原题允许任意有效答案，本地评分按明确的规范化规则比较；样例为课程样例。

## 学习目标

- [ ] 找出每个分量的最小城市编号，按编号升序排列。
- [ ] 把其余分量的代表城市都连接到最小代表城市，输出固定顺序。
- [ ] 能解释算法正确性与复杂度，并通过正常、边界和回归用例。

## 前置知识

先阅读 [6.3 图的遍历与连通性](../../../../content/chapter-06-graph-foundations/03-graph-traversal-connectivity.md)。环境需要 Node.js、pnpm 和支持 C++17 的编译器；Make 可选，可用下方 pnpm 命令替代。

## 题目

给定 n 座城市和已有双向道路，需要添加尽量少的道路，使任意两座城市都能互相到达。设现有分量各自的最小城市编号从小到大为 r1..rk，本 Lab 要求依次添加 r1-r2、r1-r3、...、r1-rk，输出该规范方案。

## 输入格式

第一行 `n m`，随后 m 行已有道路 `u v`。

### 数据范围

本 Lab：`1 <= n <= 100000`，`0 <= m <= 200000`，城市编号 `1..n`；无自环、无重边。

输入为单组有效数据，所有整数和命令按空白分隔。自动评分不包含非法编号、非法命令或违反上述限制的图，不需要额外输出输入校验提示。

## 输出格式

第一行最少新增道路数 `k-1`。随后 k-1 行按上述顺序输出道路两个端点。原图已连通时仅输出 `0`。

只向标准输出写入答案；调试信息写入标准错误。按题面规定分行，评分按空白分隔的 token 比较。

## 样例

### 样例输入

```text
6 3
1 3
2 4
5 6
```

### 样例输出

```text
2
1 2
1 5
```

三个分量是 {1,3}、{2,4}、{5,6}，代表为 1、2、5。新增 1-2 和 1-5 即可连通全部城市。

## 正常、边界与错误情况

- 正常情况：按题目定义处理全部输入，输出与输入边的排列顺序无关。
- 只有一个城市：输出 0。
- 空图：新增 n-1 条道路。
- 顶点编号交错的分量：代表必须是每个分量的最小顶点。
- 常见错误：输出 k 条道路不是最优；原题任意最优方案可以合法，但本地必须满足题面规范顺序。
- 非法输入不在评分范围；不要在标准输出中添加提示词、调试标记或额外解释。

## 正确性说明

一条新增道路最多使分量数减少 1，所以 k 个分量至少需要 k-1 条道路。以一个分量为中心连接其他所有分量恰好使用 k-1 条，且图变连通，因此达到下界。

## 复杂度分析

按城市编号递增启动遍历时代表天然有序，总时间 `O(n+m)`，空间 `O(n+m)`。
