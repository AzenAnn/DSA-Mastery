# Lab 06-03：查找理论选择题精练

## 目标

通过 2009～2025 年的 24 道 408 选择题，检查自己能否准确处理查找比较次数、分块查找、B/B+ 树性质与调整、散列表冲突和平均查找长度。

完成后应能：

- 写出顺序、分块和折半查找成立的前提与比较次数；
- 根据 m 阶 B 树的结点上下界判断合法结构，推演插入与删除；
- 区分 B 树和 B+ 树的查找终点、叶结点链接和应用场景；
- 构造开放定址散列表，分别计算成功与失败 ASL；
- 说明散列函数、冲突策略与装填因子怎样影响查找效率。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔，用于画判定树、B 树和散列表。
- **输入**：按年份排列的 24 道单项选择题，每题恰有四个选项。
- **正常输出**：选择一个选项并提交后，页面显示对错、正确答案与解析；点击“重新作答”可再次提交。
- **边界情况**：涉及图形的 B 树题已用文本树或层级说明重建，题面无需访问外部图片也能作答。
- **错误情况**：未选择选项时不应被当作正确答案；若推导与解析不一致，应记录争议点并交由 Review Owner 核验。

## 作答方法

1. 先标出题目属于基础查找、B/B+ 树还是散列表；
2. 写出本题使用的定义或统计口径，不要先猜答案字母；
3. 折半题画出比较区间，B 树题写出阶数上下界，散列表题列完整探测序列；
4. 选择一个选项并提交，再核对答案和解析；
5. 做错后点击“重新作答”，遮住解析重新推导；
6. 完成全部题目后再展开答案速查表。

## 思考题

1. 为什么折半查找和 BST 都能画成判定树，却只有平衡 BST 能稳定保证动态操作为 $O(\log n)$？
2. B 树删除题中，“向兄弟借关键字”为什么必须经过父结点，而不能直接横向移动？
3. 线性探测失败 ASL 的分母何时等于表长，何时只等于散列函数的值域大小？
4. B+ 树与散列表都常用于索引，它们分别更适合哪类查询？

## 复盘

- 我最容易漏掉的是根结点例外、非根结点下限，还是高度的层数口径？
- 计算散列表失败 ASL 时，我是否把墓碑与从未使用的空槽区分开？
- 遇到复合判断 I～IV 时，我是否逐条验证，而不是凭熟悉的关键词组合答案？
- 哪道题需要 Review Owner 再核验？我能否清楚写出自己的推导与分歧位置？
