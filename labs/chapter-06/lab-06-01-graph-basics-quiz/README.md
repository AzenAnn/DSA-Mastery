# Lab 06-01：图的基本概念选择题精练

## 目标

- 运用握手定理、入度与出度关系完成度数计算；
- 辨析简单图、自环、路径、环、可达与连通；
- 判断连通分量、强弱连通以及图的稀疏程度。

## 前置知识

建议先阅读[6.1 图的基本概念](../../../content/chapter-06-graph-foundations/01-graph-basics.md)，掌握 $G=(V,E)$、度、路径和连通性的基本定义。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔画图或记录度数。
- **输入**：本页按源文件顺序整理的 10 道四选一选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后先画图、列度数或写出可达关系，再选择答案；
2. 点击“提交答案”，核对正确答案、解析和其余选项；
3. 做错的题点击“重新作答”，不要只记答案字母；
4. 完成全部题目后再展开组件生成的答案总览。

## 题型覆盖与边界

| 类型 | 本 Lab 的处理方式 |
| --- | --- |
| 正常情况 | 计算简单图的度、边数、路径和连通分量 |
| 边界情况 | 单独考查自环、孤立顶点和有向图的单向可达 |
| 易错情况 | 区分逻辑边与度贡献、弱连通与强连通、路径与简单路径 |

## 思考题

1. 为什么无向图的自环对同一顶点贡献两次度？
2. “忽略方向后连通”为何不能推出有向图强连通？
3. 稀疏与稠密为什么更适合作为数量级判断，而不是固定阈值？

## 复盘

- 我最容易混淆的是边数、邻接记录数，还是度数贡献？
- 遇到连通性题时，我是否明确了图是有向还是无向？
- 哪个干扰项利用了“把无向图结论直接套到有向图”的错误？
