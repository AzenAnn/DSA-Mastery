# Lab 06-T-03：图的遍历与连通性选择题精练

## 目标

- 区分单源遍历、完整遍历与搜索森林；
- 判断无向连通分量以及有向图的弱连通、强连通；
- 解释原图与转置图的双向可达检查；
- 理解 Kosaraju 的两轮 DFS、SCC 划分与凝聚图；
- 根据问题是否动态增边选择遍历或并查集。

## 前置知识

建议先阅读[6.3 图的遍历与连通性](../../../../content/chapter-06-graph-foundations/03-graph-traversal-connectivity.md)，并能在邻接表上手推一次 DFS 或 BFS。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔记录 `visited`、完成顺序和分量编号。
- **输入**：本页按源文件顺序呈现的 12 道四选一选择题。
- **预期输出**：一份独立作答记录，并能为每题写出“遍历覆盖范围”或“有向可达方向”的依据。

## 作答方法

1. 先确认图是有向还是无向，再判断可达是否对称；
2. 区分“一次从起点搜索”与“外层扫描所有顶点”；
3. 遇到强连通问题时，同时检查正向与反向可达；
4. 点击“提交答案”后核对解析，做错的题重新画出分量或凝聚图。

## 题型覆盖与边界

| 类型 | 本 Lab 的处理方式 |
| --- | --- |
| 正常情况 | 单源可达、完整遍历、无向分量标号和 SCC 划分 |
| 边界情况 | 孤立顶点、只有单向可达但从起点覆盖全图 |
| 易错情况 | 混淆弱连通与强连通、把访问顺序当作分量定义 |
| 方法选型 | 比较 DFS/BFS、Kosaraju 与只增边并查集 |

## 思考题

1. 为什么改变邻接表中的邻居顺序可能改变 DFS 树，却不会改变 SCC 划分？
2. 判断整张图强连通只需两次单源遍历，为什么划分全部 SCC 还需要完成顺序？
3. 并查集为什么适合无向图增量连通性，却不能直接维护有向图强连通性？
