# Lab 06-T-04：图论综合选择题精练

## 目标

- 综合运用图的度、边数和图类型的基本定义；
- 根据查询与遍历需求选择合适的图存储结构；
- 区分 BFS、DFS、完整遍历与单源可达的结论；
- 从有向图的可达关系判断弱连通与强连通。

## 前置知识

建议先阅读[6.1 图的基本概念](../../../../content/chapter-06-graph-foundations/01-graph-basics.md)、[6.2 图的存储结构](../../../../content/chapter-06-graph-foundations/02-graph-storage.md)和[6.3 图的遍历与连通性](../../../../content/chapter-06-graph-foundations/03-graph-traversal-connectivity.md)。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔画图、记录队列或栈的状态。
- **输入**：本页按源文件顺序呈现的 10 道四选一选择题。
- **预期输出**：一份独立作答记录，以及每道错题对应的定义、复杂度或可达性依据。

## 作答方法

1. 先写清图是否有向、是否允许自环或重边，以及边是否带权；
2. 遇到复杂度题时，先确认高频操作是点对查询、邻居枚举还是全图扫描；
3. 遇到遍历题时，区分从单一起点搜索和外层扫描全部顶点；
4. 提交后阅读选项辨析；做错的题重新画出图或搜索过程。

## 题型覆盖与边界

| 类型 | 本 Lab 的处理方式 |
| --- | --- |
| 正常情况 | 度数计算、图表示选型、BFS/DFS 的基本结论 |
| 边界情况 | 自环、孤立顶点、不可行度序列和零权边 |
| 易错情况 | 把矩阵的快速查询误认为快速邻居枚举，或把单源覆盖误认为强连通 |
| 综合推理 | 将图的定义、表示和遍历结果放在同一道题的具体条件下判断 |

## 思考题

1. 如果带权图允许零权边，为什么不能只用数值 `0` 表示“没有边”？
2. 在稀疏图中，哪些需求值得用额外索引换取更快的点对查询？
3. 为什么从一个顶点遍历到全部顶点仍不能推出有向图强连通？

## 复盘

- 我是否在开始计算前先确认了图模型的约束？
- 我是否把“邻居枚举”和“指定边查询”当成了同一种操作？
- 我能否用一个反例说明单源可达不等于强连通？
