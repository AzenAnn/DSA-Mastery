# Lab 05-02：Dijkstra 最短路径

## 目标

实现堆优化的 Dijkstra 算法，求单源最短距离，回溯输出最短路径，并演示负权边导致的结果错误。

## 前置知识

- 第 5.3 节 Dijkstra 与堆；第 4.3 节优先队列。

## 建议用时

120～150 分钟。

## 任务

1. 用邻接表表示带权有向图（或作为无向图），支持 `(u, v, w)` 加边。
2. 实现堆优化 Dijkstra：`dist` 数组 + 最小堆 `(dist, vertex)`，出堆后跳过已确定顶点，松弛邻居时可能重复入堆（记录访问次数）。
3. 记录每个顶点的 `prev`，从终点回溯输出路径。
4. 用下列图验证，并统计"松弛次数"与"堆弹出次数"：

   | 编号 | 图 | 期望 |
   | --- | --- | --- |
   | 1 | 教材示例图（4～6 顶点、非负权） | 距离与手工计算一致 |
   | 2 | 含零权边 | 正确 |
   | 3 | 不连通：部分顶点不可达 | dist 为无穷，明确表示 |
   | 4 | 含负权边（如 `A→B = -3`） | 输出与 Bellman-Ford/手工结果不符，展示错误 |
   | 5 | 自环与多重边 | 不崩溃，结果正确 |

## 提交物

- 可运行代码（含堆优化与路径回溯）；
- 五个用例的距离、路径与断言结果；
- 100～200 字结论：负权边为什么让 Dijkstra 失效（配合用例 4 的具体数字）。

## 验收标准

- [ ] 非负权用例的距离与手工计算一致；
- [ ] 路径回溯输出与距离匹配；
- [ ] 不可达顶点明确标识（无穷），不崩溃；
- [ ] 用例 4 能展示出错误结果并给出解释；
- [ ] 松弛次数为 `O(m log n)` 量级（可在报告中记录实际值）；
- [ ] 报告每个用例的断言结果。

## 加分项

- 实现朴素 Dijkstra（`O(n²)`）对比堆优化版本的操作次数；
- 实现 Bellman-Ford 对比负权图上的正确结果，验证用例 4 的差距。
