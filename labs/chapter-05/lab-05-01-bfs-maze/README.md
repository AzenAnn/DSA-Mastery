# Lab 05-01：BFS 迷宫寻路

## 目标

把迷宫网格建模为无权图（相邻空格为边），用 BFS 求起点到终点的最短路径，并回溯输出路径。

## 前置知识

- 第 5.2 节 BFS 与入队时标记。

## 建议用时

90～120 分钟。

## 任务

1. 用字符网格表示迷宫（`#` 墙、`.` 空地、`S` 起点、`E` 终点），支持从文件或字符串输入。
2. 实现 BFS：用队列遍历，记录每个格子的前置格子（`prev`）用于回溯。
3. 输出：最短步数、路径坐标序列（或路径标记后的迷宫图）。
4. 验证：路径上任意相邻两格在迷宫中相邻，步数为最少。

## 测试输入

| 编号 | 迷宫 | 期望 |
| --- | --- | --- |
| 1 | 5×5 简单迷宫，起点左上终点右下 | 最短步数正确，路径可达 |
| 2 | 起点与终点相邻 | 步数 1 |
| 3 | 终点被墙完全包围 | 无路径，明确报错 |
| 4 | 起点即终点 | 步数 0 |
| 5 | 多条等长路径 | 任一条最短路径均可，步数最小 |

## 提交物

- 可运行代码；
- 至少 3 个迷宫的路径输出；
- 100～200 字说明：为什么 BFS 保证最短步数、DFS 不能保证。

## 验收标准

- [ ] 五个输入的行为与期望一致（无路径时明确失败）；
- [ ] 路径回溯正确：终点沿 prev 链可达起点；
- [ ] 输出的步数是最短的（可对简单迷宫手工验证）；
- [ ] 每个格子最多入队一次；
- [ ] 报告每个用例的断言结果。

## 加分项

- 同时用 DFS 求解，对比遍历顺序与路径长度的差异；
- 扩展到带权迷宫（每格不同代价），改用 Dijkstra 求解并说明改动点。
