# Lab 13-E-14：分发糖果

## 学习目标

- 将本题的局部选择写成可执行的不变量。
- 用边界与反例检验贪心选择是否安全。
- 完成 C++17 标准输入输出程序并通过公开评分。

## 前置知识

- 数组、排序或顺序扫描。
- 贪心选择性质与交换论证。
- C++17 的标准输入输出。

## 问题描述

每个孩子至少一颗糖；评分高于相邻孩子时糖果也必须更多。求最少糖果总数。

## 输入格式

第一行是孩子数 `n`；第二行是 `n` 个评分。

## 输出格式

输出最少糖果数。

## 约束

`1 ≤ n ≤ 50000`，评分在 `[0, 50000]`。

## 示例

输入：

```text
3
1 0 2
```

输出：

```text
5
```

## 思路提示

左扫满足“比左邻居高”，右扫满足“比右邻居高”；每个位置取两种需求的较大值。

## 复杂度分析

时间 `O(n)`，额外空间 `O(n)`。

## 测试设计提示

公开测试共 20 组，每组 5 分，总分 100 分。测试覆盖题面样例、最小输入、退化或反例场景、贪心选择边界与符合题目约束的压力数据。
