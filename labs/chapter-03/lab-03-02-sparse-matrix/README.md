# Lab 03-02：稀疏矩阵三元组转置

## 目标

用三元组表表示稀疏矩阵，实现快速转置，并对比朴素转置与计数法转置的操作次数。

## 前置知识

- 第 3.3 节稀疏矩阵与三元组表示。

## 建议用时

90～120 分钟。

## 任务

1. 实现三元组结构 `(row, col, value)` 与稀疏矩阵类型，支持从二维数组构建。
2. 实现朴素转置：按新矩阵行序（原矩阵列序）逐列收集非零元，记录访问次数。
3. 实现快速转置：先统计原矩阵每列（新矩阵每行）的非零元个数，用前缀和确定每个三元组在新表中的目标位置，一次扫描完成（`O(t + n)`），记录访问次数。
4. 用同一稀疏矩阵运行两种转置，校验结果一致，并输出各自的访问次数。

## 提交物

- 可运行代码；
- 一组 6×6 稀疏矩阵（非零元 ≥ 8 个）的转置前后三元组表；
- 两种转置的访问次数对比与 100 字结论。

## 验收标准

- [ ] 转置后每个三元组的行列为原值的交换，且按行有序；
- [ ] 快速转置输出与朴素转置完全一致；
- [ ] 快速转置访问次数为 `O(t + n)` 量级，明显少于朴素转置的 `O(t × n)`；
- [ ] 全零矩阵、单元素矩阵转置正确；
- [ ] 报告两个用例的访问次数与断言结果。

## 加分项

- 实现稀疏矩阵乘法（逐行扫描），说明为什么比普通矩阵乘法更复杂；
- 把三元组换成行链接表示（每行一条链表），比较空间与访问代价。
