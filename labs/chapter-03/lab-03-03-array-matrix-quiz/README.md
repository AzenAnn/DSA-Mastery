# Lab 03-03：数组与矩阵选择题精练（3.3）

## 目标

辨析数组与线性表的关系、行优先与列优先的寻址换算，掌握对称、三角、三对角矩阵的压缩下标公式，以及稀疏矩阵的三元组表、十字链表与转置算法的取舍。

## 前置知识

建议先阅读 3.3 数组寻址与特殊矩阵正文，掌握行优先/列优先的地址公式，以及对称、三角、三对角矩阵的压缩存储下标换算。

## 思考题

1. 为什么数组被称为随机存取结构？它的 $O(1)$ 访问靠什么保证？
2. 对称矩阵压缩后访问 $A[j][i]$（$j<i$）时下标如何换算？
3. 三对角矩阵中 $|i-j|>1$ 的元素值一定是什么？为什么能直接跳过存储？
