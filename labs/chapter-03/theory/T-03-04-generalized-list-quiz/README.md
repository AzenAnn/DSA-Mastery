# Lab 03-T-04：广义表选择题精练

## 目标

辨析广义表的递归定义，掌握表头、表尾、长度、深度的计算，理解头尾链表与扩展线性链表两种存储结构的取舍。

## 前置知识

建议先阅读 3.4 广义表与递归算法正文，掌握表头表尾、长度深度，以及头尾链表与扩展线性链表存储。

<QuizSet />

## 思考题

1. 为什么表尾一定是一个表（可能是空表）？它比直觉多一层括号的原因是什么？
2. 空表、原子的深度约定分别是多少？深度与长度有何区别？
3. 头尾链表与扩展线性链表各适合什么场景？为什么？
