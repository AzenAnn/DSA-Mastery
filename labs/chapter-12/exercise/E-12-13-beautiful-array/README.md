## 题目

构造 `1..n` 的一个排列，使任意 `i<k<j` 都不满足 `2*a[k]=a[i]+a[j]`。

### 输入格式

一行一个整数 `n`。

### 输出格式

输出课程规范构造：先递归构造 `ceil(n/2)` 并映射为奇数 `2x-1`，再递归构造 `floor(n/2)` 并映射为偶数 `2x`。

### 数据范围

`1 ≤ n ≤ 1000`。

### 样例输入

```text
5
```

### 样例输出

```text
1 5 3 2 4
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `beautiful(n)` 返回 `1..n` 的规范漂亮排列。 |
| Divide | 分别递归解决奇数位置的缩小问题和偶数位置的缩小问题。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 奇数映射整体放在前，偶数映射整体放在后。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
漂亮数组答案不唯一；本地只接受“奇数映射在前、偶数映射在后”的规范构造。
:::

## 复杂度目标

时间 `O(n log n)`（直接递归拼接），输出空间 `O(n)`。
