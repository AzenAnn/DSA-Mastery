## 题目

给定 n 个整数和 0-based 下标 k，求升序排列后下标为 k 的数。

### 输入格式

第一行 `n k`，第二行 n 个整数。

### 输出格式

输出第 k 小的数。

### 数据范围

`1 ≤ n ≤ 5×10^6`，`0 ≤ k < n`，元素在 32 位整数范围内。

### 样例输入

```text
5 1
4 3 2 1 5
```

### 样例输出

```text
2
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `select(left,right,k)` 保证返回当前区间按升序排列后全局下标 k 对应的值。 |
| Divide | 以枢轴做 `<`、`=`、`>` 三路划分。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 若 k 落入等于区间直接返回，否则只进入一侧，不需要合并数组。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
题目的 k 从 0 开始；重复值需要三路划分，否则可能退化或死循环。
:::

## 复杂度目标

期望时间 `O(n)`，最坏 `O(n²)`；原地额外空间取决于递归深度。
