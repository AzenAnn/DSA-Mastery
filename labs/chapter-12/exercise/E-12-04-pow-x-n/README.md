## 题目

计算实数 x 的整数 n 次幂。不得调用语言内置的幂函数作为核心算法。

### 输入格式

一行一个浮点数 `x` 和一个 32 位整数 `n`。

### 输出格式

输出 `x^n`，本地判题使用绝对与相对误差 `1e-9`。

### 数据范围

`-100 < x < 100`，`-2^31 ≤ n ≤ 2^31-1`；测试保证结果可表示。

### 样例输入

```text
2.00000 10
```

### 样例输出

```text
1024
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `fastPow(x,e)` 处理非负 64 位指数 `e` 并返回幂。 |
| Divide | 只递归计算一次 `x^(e/2)`。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 平方半幂；奇数指数再乘一个 x。负指数先转为倒数。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
直接对 32 位的 `INT_MIN` 取负会溢出，应先提升到 64 位。
:::

## 复杂度目标

时间 `O(log |n|)`，递归栈 `O(log |n|)`。
