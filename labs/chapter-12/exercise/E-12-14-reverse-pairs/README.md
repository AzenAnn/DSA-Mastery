## 题目

给定整数数组，统计满足 `i<j` 且 `a[i] > 2*a[j]` 的重要翻转对数量。

### 输入格式

第一行 `n`，第二行 n 个 32 位整数。

### 输出格式

输出重要翻转对数量。

### 数据范围

`1 ≤ n ≤ 5×10^4`。

### 样例输入

```text
5
1 3 2 3 1
```

### 样例输出

```text
2
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `count(left,right)` 返回区间内重要翻转对数，并把区间排序。 |
| Divide | 递归统计左右半区内部答案。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 两半有序后，对每个左元素单调推进右指针统计，再执行普通归并。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
`2*a[j]` 必须在 64 位中计算，否则极值会溢出并改变比较结果。
:::

## 复杂度目标
