# Lab 12-E-03：南蛮图腾

## 学习目标

- [ ] 能写清递归函数的输入、返回值、边界条件与规模递减方式。
- [ ] 能识别本题的拆分与合并阶段，并独立完成 C++17 实现。
- [ ] 能用边界或反例解释「不要在控制台用不稳定的退格或光标移动；先构造每一行再输出。」。

## 前置知识与环境

先阅读 [第 12 章对应小节](../../../../content/chapter-12-divide-conquer-recursion/02-call-stack-and-iteration.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

输出规模为 n 的南蛮图腾。规模 1 是两行三角形；每扩大一级，上半部分放置一个旧图形，下半部分并排放置两个旧图形。

### 输入格式

一行一个整数 `n`。

### 输出格式

输出 `2^n` 行 ASCII 图。行末多余空格不参与本地 exact 比较，但行首与行内空格必须正确。

### 数据范围

`1 ≤ n ≤ 10`。

### 样例输入

```text
2
```

### 样例输出

```text
   /\
  /__\
 /\  /\
/__\/__\
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `build(n)` 返回高度 `2^n`、逻辑宽度 `2^(n+1)` 的字符画。 |
| Divide | 递归取得规模 `n-1` 的完整图形。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 上半居中复制一次，下半左右复制两次。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
不要在控制台用不稳定的退格或光标移动；先构造每一行再输出。
:::

## 复杂度目标

时间与输出量相同，为 `Θ(4^n)`；递归辅助栈 `O(n)`。
