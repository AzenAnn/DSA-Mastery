## 题目

给定整数数组，将其按非递减顺序排序。课程要求使用归并排序完成。

### 输入格式

第一行 `n`，第二行 n 个整数。

### 输出格式

输出排序后的 n 个整数，以空格分隔。

### 数据范围

`1 ≤ n ≤ 5×10^4`，`-5×10^4 ≤ a[i] ≤ 5×10^4`。

### 样例输入

```text
5
5 2 3 1 2
```

### 样例输出

```text
1 2 2 3 5
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `mergeSort(left,right)` 返回时保证闭区间 `[left,right]` 已排序。 |
| Divide | 按中点拆成两个近似等长区间并递归排序。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 用双指针稳定合并两个有序区间。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
合并后必须把临时结果写回原数组；相等时先取左侧可保持稳定。
:::

## 复杂度目标

时间 `O(n log n)`，辅助数组 `O(n)`，递归栈 `O(log n)`。
