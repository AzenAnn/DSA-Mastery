## 题目

把正整数写成若干个 2 的幂之和，并继续递归表示指数。指数 0 写成 `2(0)`，指数 1 写成 `2`，其余写成 `2(expression)`；各项按指数从大到小排列。

### 输入格式

一行一个整数 `n`。

### 输出格式

输出 `n` 的题目规定幂次表示，不输出空格。

### 数据范围

`1 ≤ n ≤ 20000`。

### 样例输入

```text
137
```

### 样例输出

```text
2(2(2)+2+2(0))+2(2+2(0))+2(0)
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `encode(n)` 返回整数 `n` 的唯一规范字符串。 |
| Divide | 找出所有为 1 的二进制位；大于 1 的位指数继续交给 `encode`。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 按指数降序用 `+` 连接各项。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
指数 0 和 1 有特殊格式，不能统一写成 `2(encode(exp))`。
:::

## 复杂度目标

主层扫描 `O(log n)` 个二进制位，递归指数很小；空间为递归深度 `O(log log n)`。
