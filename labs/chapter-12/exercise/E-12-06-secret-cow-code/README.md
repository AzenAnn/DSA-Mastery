# Lab 12-E-06：Secret Cow Code

## 学习目标

- [ ] 能写清递归函数的输入、返回值、边界条件与规模递减方式。
- [ ] 能识别本题的拆分与合并阶段，并独立完成 C++17 实现。
- [ ] 能用边界或反例解释「旋转副本的第一个字符来自旧串末尾，其余位置向前偏移一位。」。

## 前置知识与环境

先阅读 [第 12 章对应小节](../../../../content/chapter-12-divide-conquer-recursion/03-divide-conquer-modeling.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

从初始大写字符串 S 开始反复扩展：新串由旧串和“旧串最后一个字符移到最前面后的结果”拼接。求无限扩展过程中第 N 个字符。

### 输入格式

一行给出字符串 `S` 和 1-based 位置 `N`。

### 输出格式

输出第 `N` 个字符。

### 数据范围

`1 ≤ |S| ≤ 30`，`1 ≤ N ≤ 10^18`。

### 样例输入

```text
COW 8
```

### 样例输出

```text
C
```

## 递归契约卡

| 问题 | 本题答案 |
| --- | --- |
| 子问题契约 | `locate(N,len)` 把当前长度 `len` 中的位置映射回前一半，直到落入初始串。 |
| Divide | 先倍增长度覆盖 N，再逐层判断 N 位于旧串还是旋转副本。 |
| Conquer | 对规模严格更小的子问题递归求解；达到最小规模时直接返回。 |
| Combine | 不构造字符串，只更新 N 和当前长度。 |
| 终止性检查 | 每次递归都缩短区间、减小规模或把下标映射到更短的一层。 |

::: pitfall 易错点
旋转副本的第一个字符来自旧串末尾，其余位置向前偏移一位。
:::

## 复杂度目标

时间 `O(log(N/|S|))`，额外空间 `O(1)`。
