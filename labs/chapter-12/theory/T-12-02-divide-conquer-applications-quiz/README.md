# Lab 12-T-02：典型分治算法选择题精练

## 目标

- 解释主定理递归式中各参数的含义；
- 分析归并排序的时间、空间与比较次数；
- 判断快速排序的最好、最坏情况及稳定性；
- 识别逆序对、最大子段和和大整数乘法中的分治结构。

## 前置知识

建议先阅读[分治模式与典型路径](../../../../content/chapter-12-divide-conquer-recursion/02-divide-and-conquer-patterns.md)和[正确性与复杂度分析](../../../../content/chapter-12-divide-conquer-recursion/03-correctness-complexity.md)。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔画递归树和归并过程。
- **输入**：本页按顺序给出的 10 道四选一选择题。
- **预期输出**：独立作答记录，以及每道错题对应的复杂度推导或算法不变量。

## 作答方法

1. 复杂度题先写递归式，再比较 $f(n)$ 与 $n^{\log_b a}$；
2. 排序题明确比较次数、移动次数、辅助空间和稳定性讨论的是哪一项；
3. 点击“提交答案”后核对解析，重新推导做错的题；
4. 完成全部题目后再查看答案总览。

## 题型覆盖与边界

| 类型 | 本 Lab 的处理方式 |
| --- | --- |
| 归并排序 | 时间复杂度、辅助空间、合并比较次数与逆序对 |
| 快速排序 | 划分均衡性、最坏退化与稳定性 |
| 综合分治 | 最大子段和三类候选与 Karatsuba 子问题数 |
| 易错边界 | 区分渐进上界 $O$ 与紧确界 $\Theta$ |

## 思考题

1. 为什么归并排序的初始有序程度通常不改变其渐进时间复杂度？
2. 随机选择枢轴如何降低快速排序持续出现极端划分的概率？
3. “减少一次子问题”为什么可能改变递归算法的复杂度指数？

- 我能否准确指出最大子段和分治合并阶段计算的对象？
