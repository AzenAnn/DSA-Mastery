# Lab 14-E-27：通天之分组背包

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「若在同一组内原地连续更新，会错误地选中同组多件物品。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/04-knapsack-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

有 n 件物品，每件有重量、价值和组号。同一组最多选择一件，背包容量为 C，求最大价值。

### 输入格式

第一行 `C n`，随后 n 行为 `weight value group`。

### 输出格式

输出最大价值。

### 数据范围

`C ≤ 1000`，`n ≤ 1000`，组数不超过 100。

### 样例输入

```text
10 3
4 7 1
6 9 1
5 8 2
```

### 样例输出

```text
15
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[c]` 表示处理完若干整组后容量 c 内的最大价值。 |
| 选择 | 当前组不选，或选其中恰好一件。 |
| 转移 | 新层从旧层复制，再用旧层 `dp[c-weight]+value` 更新各候选。 |
| 初值 | 未处理任何组时均为 0。 |
| 顺序 | 按组处理；组内候选必须共同读取上一组状态。 |
| 答案 | `dp[C]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(Cn)`，空间 `O(C)` 或双层数组。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
