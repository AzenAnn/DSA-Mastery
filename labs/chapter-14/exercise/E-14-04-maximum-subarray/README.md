## 题目

给定一个非空整数序列，选择一段连续且非空的区间，使区间元素和最大，输出这个最大值。

### 输入格式

第一行 `n`，第二行 `n` 个整数。

### 输出格式

输出最大连续子段和。

### 数据范围

`1 ≤ n ≤ 2×10^5`，`|a[i]| ≤ 10^4`。

### 样例输入

```text
9
-2 1 -3 4 -1 2 1 -5 4
```

### 样例输出

```text
6
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[i]` 表示必须以 `a[i]` 结尾的最大子段和。 |
| 选择 | 把 `a[i]` 接到上一段后面，或从 `a[i]` 重新开始。 |
| 转移 | `dp[i]=max(a[i],dp[i-1]+a[i])`。 |
| 初值 | `dp[0]=a[0]`。 |
| 顺序 | 从左到右。 |
| 答案 | 所有 `dp[i]` 的最大值。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n)`，空间 `O(1)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
