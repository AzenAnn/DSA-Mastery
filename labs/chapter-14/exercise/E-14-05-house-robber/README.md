# Lab 14-E-05：打家劫舍

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「状态下标和房屋下标容易错一位，先明确 `dp[i]` 是否包含第 i 间。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/01-dp-thinking-and-state-design.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

一排房屋各有非负收益。不能同时选择相邻两间房，求可取得的最大总收益；允许一间也不选。

### 输入格式

第一行 `n`，第二行 `n` 个非负整数。

### 输出格式

输出满足相邻互斥条件的最大收益。

### 数据范围

`1 ≤ n ≤ 100`，单间收益不超过 400。

### 样例输入

```text
4
1 2 3 1
```

### 样例输出

```text
4
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[i]` 表示只考虑前 i 间房时的最大收益。 |
| 选择 | 不选第 i 间，或选第 i 间并跳过第 i-1 间。 |
| 转移 | `dp[i]=max(dp[i-1],dp[i-2]+value[i])`。 |
| 初值 | `dp[0]=0`，第一间单独处理。 |
| 顺序 | 房屋从左到右。 |
| 答案 | `dp[n]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n)`，空间 `O(n)`，可滚动到 `O(1)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
