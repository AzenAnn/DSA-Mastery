# Lab 14-E-22：分割等和子集

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/04-knapsack-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

给定一组正整数，判断能否把所有元素分成两个子集，使两个子集的元素和相等。每个元素必须且只能属于一个子集。

### 输入格式

第一行 `n`，第二行 n 个正整数。

### 输出格式

可行输出 `YES`，否则输出 `NO`。

### 数据范围

`1 ≤ n ≤ 200`，每个数不超过 100。

### 样例输入

```text
4
1 5 11 5
```

### 样例输出

```text
YES
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[s]` 表示能否从已处理元素中选出和为 s 的子集。 |
| 选择 | 当前元素选或不选。 |
| 转移 | `dp[s] = dp[s] || dp[s-x]`。 |
| 初值 | `dp[0]=true`。 |
| 顺序 | 若总和为偶数，元素在外，容量倒序到一半。 |
| 答案 | `dp[sum/2]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n·sum)`，空间 `O(sum)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
