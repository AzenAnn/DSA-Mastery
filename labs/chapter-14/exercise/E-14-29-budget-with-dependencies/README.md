# Lab 14-E-29：金明的预算方案

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「附件不能脱离主件；不能把主件和附件当作互相独立的普通 0-1 物品。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/04-knapsack-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

预算为 N。每件物品有价格和重要度，收益为价格×重要度；物品要么是主件，要么是某主件的附件。购买附件前必须购买其主件，每个主件最多两个附件。求预算内最大收益。

### 输入格式

第一行 `N m`，随后 m 行为 `price importance parent`；parent 为 0 表示主件，否则是主件编号。

### 输出格式

输出最大收益。

### 数据范围

`N ≤ 32000`，`m ≤ 60`，重要度在 `1..5`。

### 样例输入

```text
1000 3
800 2 0
400 5 1
300 5 1
```

### 样例输出

```text
1600
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[c]` 表示处理完若干主件组后预算 c 内的最大收益。 |
| 选择 | 每组可不买、只买主件、主件加任一附件、或主件加两个附件。 |
| 转移 | 枚举合法组合，用上一组状态更新当前组。 |
| 初值 | 未买任何物品时收益为 0。 |
| 顺序 | 按主件分组处理，预算倒序或使用新旧两层。 |
| 答案 | `dp[N]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

每组至多四个候选，时间 `O(Nm)`，空间 `O(N)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
