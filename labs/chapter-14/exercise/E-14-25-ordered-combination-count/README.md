# Lab 14-E-25：组合总和 IV

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/04-knapsack-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

给定一组互不相同的正整数，每个数可使用任意多次。求元素和恰好为 target 的有序序列数量；例如 `[1,2]` 与 `[2,1]` 是两种方案。

### 输入格式

第一行 `n target`，第二行 n 个正整数。

### 输出格式

输出有序序列数量。

### 数据范围

`1 ≤ n ≤ 200`，`0 ≤ target ≤ 1000`，测试保证答案可放入 64 位有符号整数。

### 样例输入

```text
3 4
1 2 3
```

### 样例输出

```text
7
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[s]` 表示总和为 s 的有序序列数。 |
| 选择 | 选择最后一个加入的数字 x。 |
| 转移 | `dp[s]+=dp[s-x]`。 |
| 初值 | `dp[0]=1`，空序列是构造后续序列的起点。 |
| 顺序 | 总和 s 在外层，候选数字在内层。 |
| 答案 | `dp[target]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n·target)`，空间 `O(target)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
