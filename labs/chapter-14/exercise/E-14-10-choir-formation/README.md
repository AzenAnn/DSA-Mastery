# Lab 14-E-10：合唱队形

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「峰值被左右两段各计算一次，合并时必须减 1。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/03-linear-and-grid-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

一排同学按原顺序站立。请移除尽量少的人，使剩余身高先严格上升、再严格下降；峰值可以位于任意位置。输出最少移除人数。

### 输入格式

第一行 `n`，第二行 n 个身高。

### 输出格式

输出最少移除人数。

### 数据范围

`2 ≤ n ≤ 100`，身高在 `130..230`。

### 样例输入

```text
8
186 186 150 200 160 130 197 220
```

### 样例输出

```text
4
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `left[i]` 为以 i 结尾的上升长度，`right[i]` 为以 i 开始的下降长度。 |
| 选择 | 把 i 作为峰值，组合左右两段。 |
| 转移 | 分别做左右 LIS，峰形长度为 `left[i]+right[i]-1`。 |
| 初值 | 每个位置两侧初值都是 1。 |
| 顺序 | left 正序，right 逆序。 |
| 答案 | `n-max(left[i]+right[i]-1)`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n²)`，空间 `O(n)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
