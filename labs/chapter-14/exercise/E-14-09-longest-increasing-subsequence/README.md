## 题目

给定一个整数序列，删除任意元素但保持剩余元素原有顺序，求严格上升子序列的最大长度。

### 输入格式

第一行 `n`，第二行 n 个整数。

### 输出格式

输出最长严格上升子序列长度。

### 数据范围

`1 ≤ n ≤ 5000`，元素为正整数且不超过 `10^6`。

### 样例输入

```text
8
10 9 2 5 3 7 101 18
```

### 样例输出

```text
4
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[i]` 表示以 `a[i]` 结尾的 LIS 长度。 |
| 选择 | 选择一个更早且更小的 `a[j]` 接在前面。 |
| 转移 | `dp[i]=1+max(dp[j])`，其中 `j<i` 且 `a[j]<a[i]`。 |
| 初值 | 每个位置单独成序列，初值 1。 |
| 顺序 | i 从左到右，j 枚举 i 之前。 |
| 答案 | 所有 `dp[i]` 的最大值。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。
