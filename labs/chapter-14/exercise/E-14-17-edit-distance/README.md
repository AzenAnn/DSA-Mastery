# Lab 14-E-17：编辑距离

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「字符相等时对角转移代价为 0；空串边界不是 0。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/03-linear-and-grid-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

把字符串 A 变成字符串 B。每次可以插入一个字符、删除一个字符或替换一个字符，三种操作代价均为 1。求最少操作数。输入中的单个连字符 `-` 表示空串。

### 输入格式

两行字符串 A、B；每行仅含小写字母或单个 `-`。

### 输出格式

输出最小编辑距离。

### 数据范围

两个字符串长度均不超过 2000。

### 样例输入

```text
kitten
sitting
```

### 样例输出

```text
3
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[i][j]` 表示把 A 的前 i 个字符变成 B 的前 j 个字符的最小代价。 |
| 选择 | 删除 A 末字符、插入 B 末字符、或匹配/替换末字符。 |
| 转移 | `min(dp[i-1][j]+1,dp[i][j-1]+1,dp[i-1][j-1]+cost)`。 |
| 初值 | `dp[i][0]=i`，`dp[0][j]=j`。 |
| 顺序 | 两个前缀长度递增。 |
| 答案 | `dp[|A|][|B|]`。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(|A||B|)`，空间可滚动到 `O(|B|)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。

## 思考与复盘

1. 如果改用另一种状态定义，转移和循环顺序会怎样变化？
