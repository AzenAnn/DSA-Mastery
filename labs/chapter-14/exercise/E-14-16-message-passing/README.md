# Lab 14-E-16：传纸条

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「不能把两条路径分别求最优后相加；它们在重合格上的收益存在耦合。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/03-linear-and-grid-dp.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

两名同学同时从网格左上角走向右下角，每一步各自只能向右或向下。经过格子可获得该格的好感值；若两人在同一步位于同一格，该格只计一次。求两条路径可获得的最大总和。

### 输入格式

第一行 `m n`，随后 m 行各 n 个非负好感值。

### 输出格式

输出最大总和。

### 数据范围

`2 ≤ m,n ≤ 50`，格值非负。

### 样例输入

```text
3 3
0 2 3
4 5 6
7 8 0
```

### 样例输出

```text
32
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[k][x1][x2]` 表示走了 k 步、两人行坐标为 x1/x2 时的最大收益，列坐标由 k 推出。 |
| 选择 | 两人上一步各自来自左或上，共四种组合。 |
| 转移 | 取四个前驱最大值，再加入两个当前位置的值；重合时只加一次。 |
| 初值 | 两人都在起点，收益为起点值。 |
| 顺序 | 同步步数 k 递增。 |
| 答案 | 两人同时到达终点的状态。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O((m+n)m²)`，空间 `O(m²)` 滚动。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
