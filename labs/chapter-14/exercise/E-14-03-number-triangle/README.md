# Lab 14-E-03：数字三角形

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「边缘结点只有一个父状态，不能把不存在的父状态默认为 0 后参与一般数据比较。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/01-dp-thinking-and-state-design.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

给定一个 n 行数字三角形。从顶点出发，每次只能走到下一行相邻的左下或右下位置，求到达最后一行时能取得的最大数字和。

### 输入格式

第一行 `n`，随后第 i 行给出 i 个整数。

### 输出格式

输出一条合法顶到底路径的最大数字和。

### 数据范围

`1 ≤ n ≤ 1000`，每个数字在 `0..100`。

### 样例输入

```text
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

### 样例输出

```text
30
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `dp[i][j]` 表示到达第 i 行第 j 个位置的最大和。 |
| 选择 | 由左上父结点或右上父结点到达。 |
| 转移 | `dp[i][j]=a[i][j]+max(dp[i-1][j-1],dp[i-1][j])`，越界父状态忽略。 |
| 初值 | `dp[0][0]=a[0][0]`。 |
| 顺序 | 逐行自上而下。 |
| 答案 | 最后一行所有状态的最大值。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(n²)`，空间 `O(n²)`；一维倒序可降到 `O(n)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。
