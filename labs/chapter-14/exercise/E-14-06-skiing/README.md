# Lab 14-E-06：滑雪

## 学习目标

- [ ] 能独立写清状态含义、合法转移与初始化，而不是只背代码模板。
- [ ] 能实现本题的 C++17 动态规划，并解释为什么循环顺序满足依赖关系。
- [ ] 能用边界与反例检查「必须使用严格不等号；平台高原不能相互转移，否则会出现环。」这一常见错误。

## 前置知识与环境

先阅读 [第 14 章对应小节](../../../../content/chapter-14-dynamic-programming/02-memoization-to-tabulation.md)，并确保本机可使用 C++17。首次运行可执行 `make doctor`；Windows 未安装 Make 时可在仓库根使用 pnpm 命令。

## 题目

给定一张高度矩阵。可以从任意格出发，每一步移动到上下左右相邻且高度严格更低的格子，求最多能经过多少个格子。

### 输入格式

第一行 `R C`，随后 R 行各 C 个高度。

### 输出格式

输出最长严格下降路径包含的格子数。

### 数据范围

`1 ≤ R,C ≤ 100`，高度在 `0..10000`。

### 样例输入

```text
2 2
4 3
2 1
```

### 样例输出

```text
3
```

## 做题前先填状态卡

| 问题 | 本题答案 |
| --- | --- |
| 状态 | `memo[x][y]` 表示从格子 `(x,y)` 出发的最长下降路径长度。 |
| 选择 | 选择一个更低的四邻格作为下一步。 |
| 转移 | `memo[x][y]=1+max(memo[nx][ny])`。 |
| 初值 | 没有更低邻格时答案为 1。 |
| 顺序 | DFS 按依赖计算；缓存后每格只展开一次。 |
| 答案 | 所有起点状态的最大值。 |

不要急着写循环。先用一个最小输入手算状态表，再检查每个右侧依赖是否已经计算；如果依赖来自“当前物品的新状态”，还要说明这是否意味着允许重复选择。

## 复杂度目标

时间 `O(RC)`，空间 `O(RC)`。

## 测试设计提示

公开测试共 20 组、总分 100 分，覆盖样例、最小规模、单行/单列或单元素、不可达/全负/重复值等题型边界，以及容易暴露循环方向和初始化错误的回归输入。测试只接受标准输出；调试信息请写到标准错误。

## 思考与复盘

1. 如果改用另一种状态定义，转移和循环顺序会怎样变化？
2. 哪个最小反例最容易暴露「必须使用严格不等号；平台高原不能相互转移，否则会出现环。」？
