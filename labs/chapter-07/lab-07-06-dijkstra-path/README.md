# Lab 07-06：Dijkstra 最短路径

## 学习目标

- 用邻接表表示带权图；
- 实现最小优先队列驱动的 Dijkstra 松弛过程；
- 区分未到达、已发现和已取得当前最短条目的状态；
- 用前驱数组恢复路径，并验证路径权重和；
- 通过反例说明负权边为何不满足算法前提。

## 前置知识

- [7.3 最短路径](../../../content/chapter-07-graph-traversal/03-shortest-path.md)；
- [5.2 堆与优先队列](../../../content/chapter-05-tree-applications/02-heap-and-priority-queue.md)。

## 环境与输入约定

输入一张顶点编号为 `0..n-1` 的带权有向图；无向图通过添加两条方向相反的边表示。正式实现必须说明权重范围，并在进入算法前拒绝负权边。距离使用足够宽的整数类型，并在加法前避免无穷哨兵溢出。

## 操作步骤

1. 用邻接表保存 `(to, weight)`。
2. 初始化 `dist[source]=0`，其他为无穷；最小堆存 `(distance, vertex)`。
3. 弹出条目时跳过与当前 `dist` 不一致的过期记录。
4. 松弛每条出边；成功缩短时更新 `dist`、`previous` 并插入新堆条目。
5. 从目标沿 `previous` 回溯路径，验证每条边存在且权重和等于目标距离。

## 测试设计

| 类型 | 图 | 预期 |
| --- | --- | --- |
| 正常 | 4～6 个顶点、多个候选路径 | 距离和路径与手算一致 |
| 边界 | 含零权边 | 正确处理，不当作无边 |
| 边界 | 部分顶点不可达 | 保持无穷并明确输出不可达 |
| 正常 | 自环与多重边 | 不崩溃，选择更优边 |
| 错误 | 含负权边 | 在运行算法前明确拒绝 |
| 压力 | 稀疏大图 | “重复入堆 + 跳过过期条目”实现与 $O((n+m)\log m)$ 上界相符 |

## 预期输出

对每个顶点输出最短距离或“不可达”；指定目标时再输出从源到目标的顶点序列。附加统计可以包含成功松弛次数、堆弹出次数和过期条目数。

## 完成清单

- [ ] 所有边权在算法开始前验证为非负；
- [ ] 源点、顶点编号和距离加法均有边界检查；
- [ ] 过期堆条目被跳过，不重复用旧距离扩展；
- [ ] 可达目标的路径权重和等于 `dist[target]`；
- [ ] 不可达目标不会进入无效回溯；
- [ ] 至少覆盖正常、边界和错误三类情况。

## 思考题与复盘

1. 为什么标准 `priority_queue` 可以用“重复入堆 + 跳过过期条目”代替 decrease-key？
2. 构造一个负权边使 Dijkstra 失效的最小反例。
3. 无权图为什么应优先使用 BFS，而不是把每条边权设为 1 后运行 Dijkstra？
4. 朴素 $O(n^2)$ 与堆实现分别适合怎样的图？
