# Lab 07-02：BFS 迷宫寻路

## 学习目标

- 把二维迷宫映射为无权图；
- 用队列完成 BFS，并在入队时标记访问；
- 用前驱关系回溯一条最短路径；
- 区分“不可达”和“距离为 0”两种结果。

## 前置知识

- [7.1 图的遍历：DFS 与 BFS](../../../content/chapter-07-graph-traversal/01-dfs-and-bfs.md)；
- 队列、二维数组与坐标边界检查。

## 环境与输入约定

使用字符网格表示迷宫：`#` 为墙、`.` 为空地、`S` 为起点、`E` 为终点。先使用内存中的固定样例，扩展时再从文件或标准输入读取。输入必须明确行列数一致、起终点数量和非法字符的处理方式。

## 操作步骤

1. 把每个可通行格子视为顶点，上下左右相邻可通行格子之间连无权边。
2. 从 `S` 开始 BFS，记录 `distance` 与 `previous`；格子入队时立即标记。
3. 首次发现 `E` 后可停止扩散，从 `E` 沿 `previous` 回溯到 `S`。
4. 输出最短步数和路径坐标，或在迷宫副本上标出路径。
5. 对正常、边界与错误输入逐项记录断言结果。

## 测试设计

| 类型 | 输入 | 预期 |
| --- | --- | --- |
| 正常 | 5×5 简单迷宫 | 最短步数与手算一致，路径相邻且不穿墙 |
| 边界 | 起点与终点相邻 | 步数为 1 |
| 边界 | 起点就是终点（若接口允许） | 步数为 0 |
| 正常 | 存在多条等长最短路径 | 返回任意合法最短路径 |
| 错误/不可达 | 终点被墙包围 | 明确报告无路径，不访问非法前驱 |
| 错误 | 行长度不一致或缺少终点 | 按接口约定拒绝输入 |

## 预期输出

输出至少包含：是否可达、最短步数、路径坐标序列。调试日志写入标准错误或单独报告，不混入约定结果。

## 完成清单

- [ ] 每个可达格子最多入队一次；
- [ ] 所有坐标访问前检查边界；
- [ ] 回溯路径从 `S` 开始、在 `E` 结束，相邻坐标曼哈顿距离为 1；
- [ ] 路径步数等于坐标数减 1，并与 `distance[E]` 一致；
- [ ] 不可达和非法输入不会尝试沿未初始化前驱回溯；
- [ ] 至少覆盖正常、边界和错误三类情况。

## 思考题与复盘

1. 为什么 BFS 保证无权图最短步数，而普通 DFS 不保证？
2. 为什么必须在入队时标记？若出队才标记，哪个样例会重复入队？
3. 若每个格子具有不同进入代价，应换用什么算法和优先结构？
4. 记录完整 `previous` 与只记录距离的空间和输出能力有什么差别？
