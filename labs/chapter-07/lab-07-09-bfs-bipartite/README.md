# Lab 07-09：BFS 二分图判定

## 学习目标

- [ ] 能用队列实现 BFS，并在入队时完成染色与访问标记；
- [ ] 能用黑白染色判定二分图，并理解"冲突边即奇环"的等价关系；
- [ ] 能在非连通图上按固定规则确定唯一输出。

## 前置知识

完成前建议先阅读[第 7.1 节 图的遍历：DFS 与 BFS](../../../content/chapter-07-graph-traversal/01-dfs-and-bfs.md)的"BFS 能做什么"小节。你需要准备支持 C++17 的编译器；可先运行 `make doctor` 检查环境。

## 输入格式

第一行包含两个整数 `n m`，分别表示顶点数和无向边数。顶点编号为 `0` 到 `n-1`。

接下来 `m` 行，每行包含两个整数 `u v`，表示一条无向边。输入保证：

- `1 <= n <= 100000`；
- `0 <= m <= 200000`；
- `0 <= u, v < n`；
- 不包含自环和重复边；
- 图不保证连通。

为保证结果唯一，遍历规则固定为：

1. 按编号从 `0` 到 `n-1` 依次扫描，对尚未染色的顶点作为 BFS 起点，起点染 `0`；
2. 每个顶点的邻居按编号**升序**处理；
3. 处理中发现第一条冲突边（两个端点颜色相同）时，立即终止整个程序并输出它。

## 输出格式

输出两行，分两种情况：

**二分图**：第一行输出 `YES`，第二行输出 `n` 个整数 `color[0] color[1] ... color[n-1]`，取值 `0` 或 `1`。孤立顶点在各自起点染 `0`，直接输出 `0`。

**非二分图**：第一行输出 `NO`，第二行输出两个整数 `u v`，表示按上述规则首次发现的冲突边的两个端点，**保证 `u < v`**。

两行输出之间均以换行分隔，行末无多余空格。

### 样例输入

```input
5 4
1 3
0 1
1 4
0 2
```

### 样例输出

```output
YES
0 1 1 0 0
```

## 任务

1. 读入无向图，构建邻接表并升序排序；
2. 初始化 `color` 为 `-1`（未染色），从 `0` 号顶点开始扫描；
3. 遇到未染色顶点时染 `0` 并入队，开始 BFS；
4. 出队顶点 `u`，对每个邻居 `v`：未染色则染 `1 - color[u]` 并入队；已染色且与 `color[u]` 相同，则发现冲突边 `(u, v)`；
5. 冲突时输出 `NO` 与该边（`min(u, v)` 在前），立即结束；全部处理完则输出 `YES` 与颜色数组。

::: tip 输出唯一性
非连通图中可能有多个冲突边。本题按"根升序扫描 + 邻居升序 + 首次发现即终止"的规则保证输出唯一，标准答案据此生成。
:::

## 正常、边界与错误情况

| 情况 | 预期行为 |
| --- | --- |
| 二分图（含树、偶环、星形） | `YES` + 合法的 0/1 染色数组 |
| 奇环（如三角形） | 染色到某条边两端同色，输出 `NO` + 该边 |
| 非连通且冲突在后面的分量 | 第一个冲突边以首次发现的为准 |
| 孤立顶点 | 染 `0`，正常输出 |
| 单顶点图 | `YES`，颜色 `0` |
| 单边图 | `YES`，两个端点异色 |

## 复杂度分析

每个顶点入队一次、每条边扫描一次，时间为 `O(n + m)`；颜色数组与队列各占 `O(n)` 空间，邻接表占 `O(n + m)` 空间。BFS 不使用递归，`n = 100000` 规模安全。

## 思考与复盘

1. 为什么"相邻同色"等价于存在奇环？试从一条冲突边回溯出奇环。
2. 如果把 BFS 换成 DFS 染色，判定结果会变吗？为什么？
3. 若输出要求改为"任意一条冲突边"，评测会遇到什么问题？固定扫描规则解决了什么？
4. 二分图判定还能用哪些工具实现（如并查集奇偶性）？各自需要多记录什么信息？
