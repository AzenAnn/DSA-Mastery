# Lab 07-01：BFS 遍历与无权距离

## 学习目标

- [ ] 能使用队列实现广度优先搜索；
- [ ] 能在顶点入队时完成访问标记，避免重复入队；
- [ ] 能计算无权图中起点到各顶点的最短距离；
- [ ] 能正确处理非连通图中的不可达顶点。

## 前置知识

完成前建议先阅读[第 7.1 节 图的遍历：DFS 与 BFS](../../../content/chapter-07-graph-traversal/01-dfs-and-bfs.md)。你需要准备支持 C++17 的编译器；可先运行 `make doctor` 检查环境。

## 输入格式

第一行包含三个整数 `n m s`，分别表示顶点数、无向边数和 BFS 起点。顶点编号为 `0` 到 `n-1`。

接下来 `m` 行，每行包含两个整数 `u v`，表示一条无向边。输入保证：

- `1 <= n <= 100000`；
- `0 <= s, u, v < n`；
- 不包含自环和重复边。

为保证遍历结果唯一，访问某个顶点的邻居前必须按编号升序排列。

## 输出格式

第一行输出从 `s` 出发能够访问到的顶点，按 BFS 出队顺序排列。

第二行输出 `n` 个整数：起点到每个顶点的最少边数；不可达顶点输出 `-1`。

### 样例输入

```input
6 6 0
0 2
0 1
1 3
2 3
3 4
2 5
```

### 样例输出

```output
0 1 2 3 5 4
0 1 1 2 3 2
```

## 任务

1. 使用邻接表存储无向图，并对每个顶点的邻居升序排序；
2. 将起点加入队列，并在入队时把距离设为 `0`；
3. 每次取出队首顶点，将所有尚未访问的邻居加入队列；
4. 邻居首次入队时设置 `dist[v] = dist[u] + 1`；
5. 输出遍历顺序与完整距离数组。

## 正常、边界与错误情况

| 情况 | 预期行为 |
| --- | --- |
| 一般连通图 | 每个顶点恰好入队一次，距离按层递增 |
| 非连通图 | 只输出起点所在分量，不可达距离为 `-1` |
| 单顶点图 | 遍历顺序只有起点，距离为 `0` |
| 含环图 | 已访问标记阻止顶点重复入队 |
| 越界顶点或格式错误 | 不属于自动评分输入；实现不应主动访问越界下标 |

## 复杂度分析

邻接表上的 BFS 本身需要 `O(n + m)` 时间和 `O(n + m)` 空间。本题为了固定邻居访问顺序还需排序，排序总成本不超过 `O(m log m)`。

## 思考与复盘

2. 为什么 BFS 得到的是无权图中的最短路径长度？
3. 如果图是有向图，构建邻接表时需要修改哪一步？
