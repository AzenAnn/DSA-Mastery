# Lab 07-01：DFS 与 BFS 选择题精练

## 目标

- 辨析 DFS 与 BFS 的辅助结构、访问顺序与标记时机；
- 能手推给定邻接表上的 DFS/BFS 访问序列；
- 掌握 DFS 的边分类、括号化定理与生成树高度关系；
- 理解两种遍历在邻接表与邻接矩阵下的复杂度，以及"什么时候选谁"。

建议先阅读[第 7.1 节 图的遍历：DFS 与 BFS](../../../content/chapter-07-graph-traversal/01-dfs-and-bfs.md)，再开始本组练习。其中第 6、8 题涉及的括号化定理与 DFS 边分类，已在 7.1 正文的"DFS 时间戳与边分类"小节讲解。

## 环境、输入与预期输出

- **环境**：任意现代浏览器。
- **输入**：15 道四选一选择题，部分题目含图或邻接表。
- **预期输出**：一份独立作答记录，以及每道错题的完整推理过程。

## 作答方法

1. 先独立判断并记录依据，再点击"提交答案"；
2. 提交后核对正确答案和解析，做错的题使用"重新作答"；
3. 对含图的题目，先在草稿纸上手推访问顺序或队列/栈变化，再对照选项；
4. 对重复考查同一性质的题，说明它们在不同语境下分别考查了什么。

## 复盘

### 1. 哪道题最容易因访问顺序、标记时机或边分类判断失误？

::: details 参考答案
通常是同时涉及邻接顺序和标记时机的题。DFS/BFS 的访问序列会随起点和邻接顺序变化；而“是否可达、是否存在环、BFS 距离”等性质不依赖某一次具体序列。标记应在入栈或入队时完成，避免同一顶点重复加入。
:::

### 2. 我能否不背答案，重新画图或写出队列/栈变化过程？

::: details 参考答案
可以按“取出一个顶点、按升序扫描邻接点、在发现时标记”的规则逐步记录。DFS 记录栈和回溯，BFS 记录队列和层号；只要每一步遵守规则，序列可以从过程重新推出。
:::

### 3. 如果改变起点或邻接顺序，哪些题的结论会变、哪些不变？

::: details 参考答案
访问序列、DFS 森林形状、发现/完成时间和某些边分类可能改变；可达性、连通分量数量、二分图性质以及 BFS 得到的无权最短距离不会改变（具体顶点到源点的距离仍由图决定）。
:::
