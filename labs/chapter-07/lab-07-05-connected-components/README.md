# Lab 07-05：连通分量计数

## 学习目标

- [ ] 能对非连通图依次启动 DFS，覆盖全部顶点；
- [ ] 能统计无向图连通分量的个数，并为每个顶点标记所属分量；
- [ ] 能说明孤立顶点为何自成一体。

## 前置知识

完成前建议先阅读[第 7.1 节 图的遍历：DFS 与 BFS](../../../content/chapter-07-graph-traversal/01-dfs-and-bfs.md)的"DFS 能做什么"小节。你需要准备支持 C++17 的编译器；可先运行 `make doctor` 检查环境。

## 输入格式

第一行包含两个整数 `n m`，分别表示顶点数和无向边数。顶点编号为 `0` 到 `n-1`。

接下来 `m` 行，每行包含两个整数 `u v`，表示一条无向边。输入保证：

- `1 <= n <= 10000`；
- `0 <= m <= 100000`；
- `0 <= u, v < n`；
- 不包含自环和重复边；
- 图不保证连通。

为保证结果唯一，遍历使用 **DFS**：按编号从 `0` 到 `n-1` 扫描，对尚未标记的顶点启动 DFS，并把该顶点所在连通分量的所有顶点标记为同一个编号。每个顶点的邻居按编号**升序**访问（读入后对邻接表排序即可）。

## 输出格式

输出两行：

- 第一行包含一个整数 `k`：连通分量的个数；
- 第二行包含 `n` 个整数：`comp[0] comp[1] ... comp[n-1]`，其中 `comp[u]` 是顶点 `u` 所属分量的编号。

分量编号按发现顺序从 `0` 开始递增：扫描时第一个启动 DFS 的顶点所在分量编号为 `0`，第二个为 `1`，依此类推。相邻整数之间用单个空格隔开，行末无空格。

### 样例输入

```input
6 2
0 1
2 3
```

### 样例输出

```output
4
0 0 1 1 2 3
```

## 任务

1. 读入无向图，构建邻接表并升序排序；
2. 按 `0..n-1` 扫描，遇到未标记顶点时启动 DFS，把所有可达顶点标记为当前分量编号；
3. 每启动一次 DFS 分量编号加一，统计总个数；
4. 输出分量个数与分量编号数组。

## 正常、边界与错误情况

| 情况 | 预期行为 |
| --- | --- |
| 一般非连通图 | 每个连通分量恰好一次 DFS，编号按发现顺序递增 |
| 全连通图 | `k = 1`，所有顶点分量编号为 `0` |
| 全部孤立点 | 每个顶点一个分量，`k = n`，编号 `0..n-1` |
| 单顶点图 | `k = 1`，`comp[0] = 0` |
| 链状/星形图 | 一个分量，`k = 1` |
| 含环图 | 环上顶点同属一个分量，不重复计数 |

## 复杂度分析

每个顶点恰好进入一次、每条边恰好扫描一次，时间为 `O(n + m)`；邻接表、`visited`/`comp` 数组共占 `O(n + m)` 空间。递归栈最坏深度为 `O(n)`，实际可用深度取决于系统与编译器；需要处理更深图时应改用显式栈。

## 思考与复盘

### 1. 为什么只从 `0` 出发跑一次 DFS 会漏掉其他分量？如何补全？

::: details 参考答案
一次 DFS 只能访问起点所在的连通分量。应按 `0..n-1` 扫描，遇到未访问顶点就把分量编号加一并启动新的 DFS，直到所有顶点都被标记。
:::

### 2. 若把 DFS 换成 BFS，在本题的扫描规则下，分量编号会变吗？为什么？

::: details 参考答案
不会。分量编号由外层扫描中“第几个未访问顶点启动遍历”决定，DFS/BFS 都会完整访问该顶点所在分量；但分量内部的访问顺序不同，本题只输出分量编号，因此结果不变。
:::

### 3. 有向图的"连通分量"叫法应换成什么？判断标准有什么不同？

::: details 参考答案
应区分弱连通分量和强连通分量。弱连通忽略方向后判断无向可达；强连通要求任意两点间都存在有向路径，通常需要 SCC 算法，不能直接套无向图 DFS 的分量定义。
:::
