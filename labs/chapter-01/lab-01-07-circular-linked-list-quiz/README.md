# Lab 01-07：循环链表选择题精练

## 目标

识别循环链表删除操作中的双向摘链和仅剩一个数据节点时的尾指针更新。

## 前置知识

建议先掌握带头结点循环单链表与循环双链表的空表、首元和尾元关系。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔或一份错题记录。
- **输入**：本页按源文件顺序整理的 2 道选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击“提交答案”，再核对对错、正确答案和题解；
3. 做错的题点击“重新作答”后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再展开组件生成的答案总览，避免只记答案字母。

## 思考题

1. 循环结构为什么不能使用 next == NULL 判断表尾？
2. 删除唯一数据节点后，头指针、头结点和尾指针分别应指向哪里？
3. 循环双链表删除已知节点时，需要修复哪两个相邻节点？
