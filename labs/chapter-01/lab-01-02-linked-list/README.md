# Lab 01-02：实现并验证单链表

## 目标

通过实现单链表理解节点、链接和边界处理，并与顺序表使用同一组行为测试。

## 建议用时

90～120 分钟。

## 任务

1. 自定义节点类型，实现 `size`、`get`、`insert`、`remove`、`find` 和 `clear`。
2. 选择“直接头引用”或“哨兵节点”方案，并说明理由。
3. 复用 Lab 01-01 的行为测试，证明两种实现遵守相同契约。
4. 画出一次中间插入和一次删除的链接变化。

## 约束

- 不使用语言自带链表容器完成核心逻辑；
- 不得通过复制全部元素模拟插入或删除；
- 遍历必须有明确终止条件。

## 验收标准

- [ ] 空表、单节点和多节点情况均能正确工作；
- [ ] 表头、表中和表尾插入删除均有测试；
- [ ] 删除后不会丢失后续节点，也不会形成意外环；
- [ ] 与顺序表共享至少一组黑盒行为测试；
- [ ] 能说明“已知前驱”和“需要先定位”时的复杂度差异。

## Review 提示

审阅者重点检查链接修改顺序，并尝试连续删除首节点直到空表，再重新插入元素。
