# Lab 01-02：单链表选择题精练

## 目标

追踪单链表的链接变化，识别头结点、指针更新顺序和定位成本。

## 前置知识

建议先掌握单链表结点结构、头指针与头结点，以及已知前驱时的插删操作。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔或一份错题记录。
- **输入**：本页按源文件顺序整理的 10 道选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击“提交答案”，再核对对错、正确答案和题解；
3. 做错的题点击“重新作答”后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再展开组件生成的答案总览，避免只记答案字母。

- [ ] 10 道题均在展开答案前独立作答；
- [ ] 每道错题都记录了错误原因，而不只抄写正确答案；

- [ ] 复做错题时能够在不看解析的情况下得到正确结论。

## 思考题

1. 头结点为什么能统一表头插入和删除的边界？
2. 为什么在 p 后插入 s 时必须先保存 p 的原后继？
3. 链表的局部修改是 O(1) 时，整体操作为什么仍可能是 O(n)？

## 复盘

- 哪道题的错误选项最有迷惑性？它利用了哪个常见概念混淆？
