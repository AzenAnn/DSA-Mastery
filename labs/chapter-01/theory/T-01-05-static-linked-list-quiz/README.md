# Lab 01-T-05：静态链表选择题精练

## 目标

辨析静态链表的数组物理存储、游标逻辑链接、固定容量和空间利用率。

## 前置知识

建议先能比较顺序表、动态链表与静态链表的物理位置和逻辑次序。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔或一份错题记录。
- **输入**：本页按源文件顺序整理的 4 道选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击“提交答案”，再核对对错、正确答案和题解；
3. 做错的题点击“重新作答”后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再展开组件生成的答案总览，避免只记答案字母。

## 思考题

1. 静态链表使用数组后，为什么仍不能按逻辑位序随机访问？
2. 静态链表的固定容量和未使用数组单元分别带来什么限制？
3. 已知前驱游标时，静态链表插删为什么不需要整体移动元素？
