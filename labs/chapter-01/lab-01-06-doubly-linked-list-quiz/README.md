# Lab 01-06：双链表选择题精练

## 目标

正确追踪双链表插删中的四条链接，理解反向遍历与循环哨兵边界。

## 前置知识

建议先掌握单链表插删，再复习 prev/next 不变量和循环双链表空表结构。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔或一份错题记录。
- **输入**：本页按源文件顺序整理的 10 道选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击“提交答案”，再核对对错、正确答案和题解；
3. 做错的题点击“重新作答”后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再展开组件生成的答案总览，避免只记答案字母。

- [ ] 10 道题均在展开答案前独立作答；
- [ ] 每道错题都记录了错误原因，而不只抄写正确答案；

## 思考题

1. 双链表插入时，哪些赋值必须在覆盖原链接之前完成？
2. 如何同时用正向和反向遍历发现只修复了一侧链接的错误？
3. 双链表为什么能 O(1) 修改已知节点，却不能按下标 O(1) 定位？
