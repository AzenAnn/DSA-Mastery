# Task 1：宿管王的学生名单表

宿管王想根据姓名或学号知道学生住在哪间寝室。你先为他做一份可以增删改查的名单，再处理“一间寝室整体搬离”的情况。

## 本关交付

只修改 `student/student_table.cpp`。公共接口在 `../../contracts/student_table.hpp`，数据结构在 `../../contracts/model.hpp`。数组与逻辑长度已定义，`size`、带越界检查的 `at` 和数据合法性函数已提供。

| 函数 | 成功结果 | 失败或空结果 | 目标复杂度 |
| --- | --- | --- | --- |
| `findIndex(id)` | 学号对应下标 | -1 | O(n) |
| `add(id, name, floor, room)` | 尾部追加，返回 true | false，表不变 | O(n)，含查重 |
| `update(...)` | 只改姓名、楼层、房间，返回 true | false，表不变 | O(n) |
| `erase(id)` | 稳定删除一个学生，返回 true | false，表不变 | O(n) |
| `removeByRoom(floor, room)` | 稳定批量删除，返回人数 | 无匹配或非法寝室返回 0 | O(n)，额外空间 O(1) |
| `findByName(name, indices)` | 写入全部匹配下标，返回个数 | 0，不写结果数组 | O(n) |

学号必须是 1～20 位数字，姓名非空，楼层 1～10、房间 1～30；满 105 人、重复学号或非法字段都必须拒绝。新记录的体力为 100，累计值为 0。`update` 必须保留学号、体力、热心值和成功次数。

`findByName` 的调用方提供容量至少为 105 的数组；只能写实际结果数量内的槽位。`at` 返回指针是为了后续任务更新学生统计，插入或删除造成搬移后应重新查找，不保存长期学生指针。

## 从基础到算法

先完成 `findIndex` 与 `add`，确认能够创建名单，再实现修改、单人删除和同名查询。最后做批量删除，要求使用给定数组，不能用 `vector`、`list` 或另一份学生数组替代核心算法。

手算例子：

~~~text
学号：001 002 003 004 005
房间：(3,1) (3,2) (3,2) (3,1) (4,2)
删除寝室：(3,2)
剩余学号：001 004 005
返回值：2
~~~

注意 005 的房间号也是 2，但楼层不同，应该保留。004 的全部字段都要随记录一起搬移，不能只搬学号。

::: details 提示：卡在批量删除时
把“原名单已经检查到哪里”和“保留名单已经写到哪里”分开。循环中的不变量可以是：写入下标之前，恰好保存已扫描部分中所有应保留的学生，顺序与原名单一致。根据这个含义推导两个下标如何移动。
:::
