# Lab 01-01：实现一个最小动态顺序表

## 目标

根据统一操作契约实现动态顺序表，处理下标边界、元素搬移和容量扩展。

## 建议用时

90～120 分钟。

## 任务

1. 实现 `size`、`get`、`insert`、`remove`、`find` 和 `clear`。
2. 初始容量设为较小值，在空间不足时按固定倍数扩容。
3. 为表头、表中、表尾和非法下标编写测试。
4. 记录一次触发扩容的过程，并解释尾部追加的摊还复杂度。

## 约束

- 不直接使用语言自带的动态列表作为内部存储；
- 接口的失败方式必须统一并写在说明中；
- 实现应始终保持 `0 ≤ size ≤ capacity`。

## 验收标准

- [ ] 所有规定操作可运行且含简短接口说明；
- [ ] 插入不会覆盖尚未搬移的元素；
- [ ] 删除后元素顺序与长度正确；
- [ ] 至少包含空表、边界位置、扩容和越界测试；
- [ ] 能正确说明访问、插入、删除和追加的复杂度。

## Review 提示

审阅者可把初始容量改为 `1`，连续追加多个元素，再交替删除与插入，以检查扩容和边界状态。
