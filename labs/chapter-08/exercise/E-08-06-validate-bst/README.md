# Lab 08-E-06：验证二叉搜索树

> 题目来源：改编自 [LeetCode 98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)。本 Lab 使用课程自定义输入输出协议和独立测试，不复制来源站点的代码或测试。

## 学习目标

- [ ] 用"向子树传递开区间上下界"的递归验证 BST，理解检查对象是**整棵子树**而不是单个父子对；
- [ ] 按**教材口径**处理严格有序：关键字互不相同，出现相等值即判非法；
- [ ] 用 `long long` 与正确的哨兵处理关键字恰好等于 ±10¹⁸ 的边界。

## 前置知识与环境

先阅读[第 8.2 节 二叉排序树](../../../../content/chapter-08-search/02-binary-search-tree.md)的"定义与不变量"一节：BST 的不变量作用在**整棵子树**上，这正是本 Lab 递归传界写法的出处。

在 Lab 目录执行 `make doctor` 检查环境；未安装 Make 时可在仓库根使用 pnpm 兜底命令（见下文"运行"）。

## 任务

给定一棵以编号 0 为根的二叉树（`n = 0` 时为空树），判定它是否为二叉排序树。

**教材口径**：BST 中关键字**互不相同**，任一结点左子树的所有关键字**严格小于**它，右子树的所有关键字**严格大于**它——只要出现相等关键字即非法；空树是 BST。

### 输入格式

- 第一行：一个整数 `n`（结点数，可以为 0）；
- 接下来 `n` 行：每行四个整数 `i val l r`——结点编号 `i`（0 ≤ i < n）、关键字 `val`、左孩子编号 `l` 与右孩子编号 `r`（不存在为 `-1`）。`n > 0` 时编号 0 是根，输入保证这些指针构成一棵以 0 为根的二叉树。

### 输出格式

一行一个整数：是 BST 输出 `1`，否则输出 `0`。

### 数据范围与限制

| 项目 | 范围 |
| --- | --- |
| 结点数 `n` | 0 ≤ n ≤ 10⁴ |
| 关键字 `val` | −10¹⁸ ≤ val ≤ 10¹⁸（必须用 64 位整数读取） |
| 结点编号 | 0 ≤ i < n；孩子不存在时为 −1 |
| 时间复杂度要求 | 每个结点只访问常数次，$O(n)$ |
| 输出上限 | 1 MB（单个整数，默认上限足够） |

### 正常、边界与错误情况

- **正常**：每个结点的整棵左右子树都落在祖先约束的范围内，而不只是与父结点比较；
- **边界**：`n = 0`（空树，输出 `1`）；单结点；关键字恰好等于 ±10¹⁸ 的深层结点；
- **违规**：孙辈结点违反祖先约束、但每个父子局部关系都合法（只比较父子的写法会误判为合法）；出现相等关键字（按教材口径即非法）。

## 样例

### 样例 1

```input
5
0 50 1 2
1 30 3 4
2 70 -1 -1
3 20 -1 -1
4 40 -1 -1
```

```output
1
```

左子树 {30, 20, 40} 全部小于 50，右子树 {70} 大于 50；30 的左孩子 20、右孩子 40 局部与全局都合法。

### 样例 2

```input
3
0 50 1 -1
1 30 -1 2
2 60 -1 -1
```

```output
0
```

30 < 50（父子的左孩子关系合法），60 > 30（30 的右孩子关系也合法），但 60 位于根 50 的**左子树**内却大于 50，违反 BST。只比较父子结点的检查在这里会误判为合法。

## 实现提示

- 递归时向子树传递**开区间** `(low, high)`：当前结点必须满足 `low < val < high`，递归左子树时把上界收紧为 `val`，递归右子树时把下界收紧为 `val`；
- 哨兵初值用 `long long` 的极限值（`<climits>` 中的 `LLONG_MIN`/`LLONG_MAX`），**不要**用 ±10¹⁸ 当哨兵——结点关键字本身可以恰好取到 ±10¹⁸；
- 严格比较（`val <= low` 或 `val >= high` 判非法）自动排除相等关键字；等价做法是"中序遍历严格递增"。
