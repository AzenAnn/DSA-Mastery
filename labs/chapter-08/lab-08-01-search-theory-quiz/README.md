# Lab 08-01：查找理论选择题精练

## 目标

通过 2009～2025 年的 6 道 408 选择题，检查自己能否准确处理顺序查找、分块查找与折半查找的前提条件、比较次数与判定树高度。

完成后应能：

- 写出顺序、分块和折半查找各自成立的前提与比较次数；
- 由折半判定树高度推算失败查找的最多比较次数；
- 判断一种存储结构或查找序列能否用折半查找；
- 由最优块长理解分块查找两级代价的权衡。

## 前置知识

建议先阅读 [8.1 基础查找与折半查找](../../../content/chapter-08-search/01-linear-and-binary-search.md)，并复习 8.2 节二叉排序树中"查找路径"的对比视角。

## 环境、输入与预期输出

- **环境**：任意现代浏览器；建议准备纸笔，用于画折半判定树。
- **输入**：本页按年份排列的 6 道单项选择题。
- **预期输出**：一份独立作答记录，以及每道错题的错误原因和正确推理。

## 作答方法

1. 阅读题面后点击一个选项，先写下选择依据；
2. 点击"提交答案"，再核对对错、正确答案和题解；
3. 做错的题点击"重新作答"后再次推导，直到能说明其余选项为什么不成立；
4. 完成全部题目后再使用页面末尾的答案总览复核，避免只记答案字母。

## 思考题

1. 为什么折半查找同时要求"有序"和"随机访问"，缺一不可？
2. 分块查找的两级顺序查找，代价为什么近似正比于 `s + n/s`？
3. 顺序查找在什么情况下反而是比折半查找更合理的选择？
