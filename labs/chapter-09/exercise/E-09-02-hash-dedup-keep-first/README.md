# Lab 09-E-02：去重保首次

> 题目来源：改编自[洛谷 P4305（JLOI2011）不重复数字](https://www.luogu.com.cn/problem/P4305)。本 Lab 使用课程自定义输入输出协议和独立测试，不复制来源站点的代码或测试。

## 学习目标

- [ ] 手写一张支持“插入并判重”的散列表（开放定址或链地址均可），理解 H(k)=k 的直接定址只是散列的特例；
- [ ] 在多组数据之间正确复位散列表，保证组与组互不干扰；
- [ ] 解释为什么用“已输出序列线性扫描”判重的 $O(n^2)$ 做法在 Σn = 5×10⁵ 时不可接受。

## 前置知识与环境

先阅读[第 9.2 节 散列表](../../../../content/chapter-09-hashing-indexes/02-hash-table.md)的“从关键字到地址”与“链地址法”两节，掌握散列函数、冲突处理与装填因子的基本口径；实现线性探测版本时可对照“开放定址法”一节。

在 Lab 目录执行 `make doctor` 检查环境；未安装 Make 时可在仓库根使用 pnpm 兜底命令（见下文“运行”）。

## 任务

对 T 组数据：每组给定 n 个整数，按**输入顺序**输出其中每个值**第一次出现**的形态（重复出现的值只保留第一个），同一组内数值之间用一个空格分隔，每组独占一行。

### 输入格式

- 第一行：一个整数 `T`，表示数据组数；
- 接下来 `T` 组数据，每组两行：
  - 第一行一个整数 `n`；
  - 第二行 `n` 个整数，依次为 a₁ … aₙ。

### 输出格式

共 `T` 行：第 i 行为第 i 组数据“去重保首次”后的序列，数值之间用一个空格分隔；若整组数值全部相同，则该行只有一个值。

### 数据范围与限制

| 项目 | 范围 |
| --- | --- |
| 数据组数 `T` | 1 ≤ T ≤ 50 |
| 每组元素个数 `n` | 1 ≤ n ≤ 5×10⁴，且 Σn ≤ 5×10⁵ |
| 元素取值 | 0 ≤ a ≤ 10⁵ |
| 时间复杂度要求 | 每组期望 $O(n)$；每读一个数就扫描一遍已输出序列的 $O(n^2)$ 做法会在压力用例超时 |
| 输出上限 | 8 MB（判题器放宽了默认 1 MB 输出上限；Σn 较大且基本互不相同时单行输出可超过 1 MB） |

### 正常、边界与错误情况

- **正常**：重复值只保留首次出现，其余数值按输入顺序原样保留；
- **边界**：整组数值全部相同（只输出一个值）；整组互不相同（输出与输入一致）；首元素与末元素相同；
- **多组数据**：上一组留下的“已出现”状态必须清空，否则下一组会漏输出首次出现的值。

## 样例

### 样例 1

```input
3
6
1 2 2 3 1 3
5
5 4 3 2 1
7
7 7 7 7 7 7 7
```

```output
1 2 3
5 4 3 2 1
7
```

第一组里 `2` 与 `3` 的第二次出现被丢弃，只保留首次出现；第二组互不相同，原样输出；第三组全部相同，只输出一个 `7`。

### 样例 2

```input
2
4
0 100000 0 100000
3
9 8 9
```

```output
0 100000
9 8
```

`0` 与 `100000` 取到值域两端；第二组首尾都是 `9`，只保留第一个。注意 `0` 也是合法元素，判重结构不能把“存着 0”和“空槽”混为一谈。

## 实现提示

值域只有 0…10⁵ 时，开一个 `bool seen[100001]` 直接判重确实可行——这本质上是散列函数 H(k)=k 的**直接定址**，是散列的特例。但请把本 Lab 当作手写散列表的练习：取素数表长（如 200003）做除留余数法 H(k) = k mod p，冲突时线性探测（开放定址）或拉同义词链（链地址法）。它与直接定址功能等价，但套路可以原样迁移到键值域很大的场景。

两个易错点：每组数据开始前要把散列表整体复位；若用开放定址，空槽哨兵要能与合法键 0 区分开。
