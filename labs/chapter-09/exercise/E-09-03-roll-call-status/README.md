# Lab 09-E-03：点名状态机

> 题目来源：改编自[洛谷 P2580 于是他错误的点名开始了](https://www.luogu.com.cn/problem/P2580)。本 Lab 使用课程自定义输入输出协议和独立测试，不复制来源站点的代码或测试。

## 学习目标

- [ ] 手写以**字符串为键**的链地址法散列表，把名字映射成桶下标并在同义词链上查找；
- [ ] 在散列表节点上挂状态标记，把“首次点到 / 已点过”的判定做成 $O(1)$ 的状态转移；
- [ ] 解释为什么每次点名都线性扫一遍名单的 $O(nm)$ 做法在 m = 10⁵ 时不可接受。

## 前置知识与环境

先阅读[第 9.2 节 散列表](../../../../content/chapter-09-hashing-indexes/02-hash-table.md)的“从关键字到地址”与“链地址法”两节：字符串不是整数键，需要先用多项式滚动散列把它映射成整数，再对表长取模得到桶下标。

在 Lab 目录执行 `make doctor` 检查环境；未安装 Make 时可在仓库根使用 pnpm 兜底命令（见下文“运行”）。

## 任务

先给出一串**互不相同**的名单名字；随后进行 m 次点名。对每次点名输出一行：

- 名字**在名单中**且**首次**点到：输出 `OK`；
- 名字在名单中但**之前已经点到过**：输出 `REPEAT`；
- 名字**不在名单中**：输出 `WRONG`。

名字**大小写敏感**（本 Lab 输入保证全部为小写字母，不做任何大小写转换）。

### 输入格式

- 第一行：一个整数 `n`，表示名单人数；
- 接下来 `n` 行：每行一个名字，互不相同；
- 接下来一行：一个整数 `m`，表示点名次数；
- 接下来 `m` 行：每行一个名字，表示一次点名。

### 输出格式

共 `m` 行，每行一个词：`OK`、`REPEAT` 或 `WRONG`，顺序与点名一一对应。

### 数据范围与限制

| 项目 | 范围 |
| --- | --- |
| 名单人数 `n` | 1 ≤ n ≤ 10⁴ |
| 点名次数 `m` | 1 ≤ m ≤ 10⁵ |
| 名字 | 仅小写字母，长度 1 ～ 50；名单内互不相同 |
| 大小写 | 敏感（输入保证小写，不做大小写转换） |
| 时间复杂度要求 | 每次点名期望 $O(\lvert s\rvert)$；每点名一次就扫描整个名单的 $O(nm)$ 做法会在压力用例超时 |

### 正常、边界与错误情况

- **正常**：三种输出各按定义出现；同一个人第二次及以后被点到都是 `REPEAT`；
- **边界**：名单只有 1 个人；同一个人被连续点到多次；点名次数远大于名单人数（m ≫ n）；
- **不在名单**：名字再常见也一律 `WRONG`，且**不会**影响任何状态标记。

## 样例

### 样例 1

```input
3
alice
bob
carol
7
alice
david
alice
bob
eve
carol
bob
```

```output
OK
WRONG
REPEAT
OK
WRONG
OK
REPEAT
```

`alice` 首次点到输出 `OK`，第二次变成 `REPEAT`；`david`、`eve` 不在名单，输出 `WRONG`；三种状态都出现了。

### 样例 2

```input
1
tom
3
tom
tom
tom
```

```output
OK
REPEAT
REPEAT
```

名单只有 1 个人；同一个人连点 3 次，只有第一次是 `OK`。

## 实现提示

散列表用链地址法：`head[表长]` 存每条同义词链的头节点下标，节点池数组存 `{名字, 是否已点名, next}`，用下标代替指针做链表。散列函数取 131 进制多项式滚动散列，对素数表长（如 20011）取模；名单规模 1×10⁴ 时装填因子约 0.5。

名单内名字互不相同，插入时不必判重。查询流程：先 `find`——找不到输出 `WRONG`；找到再看节点上的标记，未点过则置为已点并输出 `OK`，点过则输出 `REPEAT`。用 `std::unordered_map<std::string, bool>` 做对照可以，但本 Lab 要求提交的手写实现里包含自己的散列函数与冲突处理。
