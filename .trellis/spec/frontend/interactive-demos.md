# 教材内的独立交互式演示

## 适用范围与参考

适用于 `public/demos/` 的独立 HTML 与教材 iframe 挂载点。外观参考 `binary-search.html`、`bst-explorer.html`；第 4 章的 `tree-demo.css`、`tree-demo.mjs` 提供共享样式和播放控制。独立演示保持自己的深色画布，不修改站点全局令牌或其他章节演示。

## 挂载与资源

- Markdown 用 `<script setup>` 从 `vitepress` 导入 `withBase`，对 `/demos/<file>.html`（可带查询参数）生成 iframe URL。
- iframe 必须有明确中文 `title`、`loading="lazy"`，沿用 8.1/8.2 的局部 `search-demo-frame` 样式：桌面 760px，720px 以下 1100px。不要假定此类名由全局样式提供。
- 演示内部 CSS、模块用 HTML 相对路径，禁止写死 `/DSA-Mastery/`、引入 CDN 或依赖开发服务器路由。
- `.mjs` 的静态测试服务器 MIME 必须为 `text/javascript`；验证最终 `dist/pages`，同时覆盖 `/` 与 Pages 子路径。

## 算法状态与教学合同

- 将纯算法轨迹和 DOM/播放控制分开。每帧保存独立的节点表、指针、阶段、访问序列、说明和改边记录，回退不能读取被后续步骤修改的对象。
- 节点身份使用稳定 id。渲染线索/Morris 回边和 flatten 中间状态时按节点表绘边，不能把当前指针当无环树递归排版。
- 线索化仅替换原空域，保留真实孩子边；首尾 null 线索仍显示 tag。Morris 回边必须标为临时，结束时恢复原指针。
- flatten 的三次赋值分别成帧；临时重合的 L/R 指针需分开画，删边用红虚线及叉号，新边用绿色粗线，并保留原树对照。
- 孩子兄弟转换从有序 `children` 与根列表派生。两侧遍历各自计算，在“输出一个节点”事件上同步，不把同一数组复制两份来假装验证等价。
- 演示保存快照的空间开销与原算法的辅助空间明确区分。不要因为循环嵌套就修改算法复杂度结论。

## 交互、布局与验收

- 提供播放/暂停、上一步/下一步、重置、进度、速度及案例选择；首次加载不自动播放。
- 手动步进、拖动、重置、切换模式/案例先停止旧计时器；到末尾、页面隐藏和 pagehide 时停止。重播从第一帧开始。
- 原生控件有可访问名称；SVG 节点支持 Enter/空格选择，并在重绘后保留键盘焦点。状态解说有 `aria-live`，线型和文字辅助颜色区分，支持减少动态效果设置。
- 成对图优先占满主区域，变量/代码/表格可移至下方；窄屏上下堆叠。390px 下父页面和 iframe 均不横向溢出。
- 纯算法测试对照独立遍历：真实孩子保持、线索遍历、Morris 还原、flatten 先序右链、森林两种等价关系；覆盖空、单节点、偏斜和分支树。
- Playwright 从教材真实 iframe 检查浅/暗主题、390/1440px、控制生命周期、指针删改、跨图选中和资源/控制台错误。新增测试接入 `pnpm test` 和 Pages CI 对应门禁。
