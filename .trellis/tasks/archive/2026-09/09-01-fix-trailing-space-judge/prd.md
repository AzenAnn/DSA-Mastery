# 测评忽略行末空格

## Goal

让共享 Lab 测评器在学生输出与标准答案仅存在“每行末尾的水平空白”差异时判定为正确，避免算法和有效输出均正确却因常见格式细节得到 WA。

## Background

- `tools/lab/compare.mjs:19` 的 `exact` 比较目前只统一换行符并允许一侧缺少一个最终换行，其他字符全部逐字比较。
- `tests/lab-tools.test.mjs:191` 当前明确断言 `"42 "` 与 `"42"` 不相等，缺少用户截图所示的“行末空格应被接受”回归覆盖。
- `.trellis/spec/content/lab-tooling.md:60` 当前合同要求 `exact` 不忽略其他空白，因此实现、测试和规范必须在同一个变更中同步。
- 仓库中约 51 处 Lab/测试配置使用 `exact`，修复共享比较器即可统一生效，无需修改各 Lab 的 `.out` 文件。

## Requirements

- `exact` 比较在统一 CRLF/LF 后，忽略每一行末尾的水平空白（空格和制表符）。
- 行内字符和行内空白仍逐字符比较；不能退化成 `tokens` 模式。
- 内部换行、缺失或新增的非空内容、额外空行仍应被检测为差异。
- 保留现有“输出可缺少一个最终换行”的兼容行为。
- 首处差异报告继续基于比较时采用的规范化文本，位置和片段必须可理解。
- 同步更新 Lab 工具规范，明确新的 `exact` 判定合同。
- 不批量修改 Lab 标准答案，也不改变 `tokens`、`float`、计分或终端展示逻辑。

## Acceptance Criteria

- [x] 标准答案 `"1 2 3\n4 5\n"` 与实际输出 `"1 2 3 \n4 5\n"` 在 `exact` 模式下相等。
- [x] 每行末尾存在一个或多个空格/制表符时，在 `exact` 模式下相等。
- [x] `"1  2"` 与 `"1 2"`、`"42\n43"` 与 `"4243"` 仍不相等。
- [x] 额外空行和额外非空行仍不相等。
- [x] CRLF/LF 兼容与可选最终换行的现有测试继续通过。
- [x] `tokens` 与 `float` 比较行为不变。
- [x] `pnpm run test:lab-tools` 通过，相关差异检查无错误。

## Out of Scope

- 不忽略行首空白或行内连续空白。
- 不修改具体 Lab 的题面、学生代码、标准答案或评分权重。
- 不把 `exact` 比较改为 token 化比较。
