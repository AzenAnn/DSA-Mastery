### 存储专项

**06 邻接矩阵查询**：洛谷 T471612 改编。输入 `n m q`，随后 m 条无向边和 q 个查询 `u v`；输出 n 行矩阵，再逐行输出每次查询的 0/1 结果。顶点为 `1..n`；`1 <= n <= 1000`，`0 <= m <= min(100000,n(n-1)/2)`，`0 <= q <= 100000`。图无自环重边，查询允许 `u=v`，结果为 0。保留矩阵建图训练，增加查询、允许空图，省略原题附带的邻接表输出。

**07 邻接表规范化**：洛谷 T419391 改编。输入 `n m` 和 m 条简单无向边；输出 n 行 `k neighbor1 ... neighbork`，依顶点顺序枚举，邻居升序。顶点为 `1..n`；`1 <= n <= 100000`，`0 <= m <= min(200000,n(n-1)/2)`。孤立点输出 `0`。省略原题矩阵输出，扩大规模以体现稀疏存储价值。

**08 转置图**：输入 `n m` 和 m 条有向边，顶点 `0..n-1`。`1 <= n <= 100000`，`0 <= m <= 200000`；允许自环和平行边。输出转置图的 n 行邻接表，每行 `k` 加升序邻居；平行边按输入重数保留，自环仍保留一次/条。原图不能在原地枚举时插入反向边。

**09 三种表示转换**：输入首行 `type format n`，`type` 为 `U` 或 `D`，`format` 为 `E`、`M` 或 `L`，`1 <= n <= 500`，顶点 `0..n-1`，仅支持无权简单图。

- E：下一行 m，再读 m 条边。无向边每条输入一次，可任意端点顺序。
- M：读 n 行 n 列矩阵；对角线为 0；U 保证矩阵对称。
- L：读 n 行 `k` 加 k 个互异邻居；输入邻居顺序任意；U 保证双向记录一致。
- 输出固定为 `MATRIX` 标记及 n 行矩阵、`LIST` 标记及 n 行升序邻接表、`EDGES m` 标记及 m 行字典序边。U 边只输出 `u < v`，D 输出全部有向边。包括空图，所有格式均可作为输入，避免仅完成边集到其他表示的单向转换。

**10 Graph ADT**：初始空简单图。输入 `type n q`，type 为 U/D，`1 <= n <= 100000`，`0 <= q <= 200000`；随后 q 行 `ADD u v`、`DEL u v` 或 `HAS u v`，顶点 `0..n-1` 且 `u!=v`。

- ADD：新边插入返回 1；边已存在返回 0。
- DEL：存在并成功删除返回 1；边不存在返回 0。
- HAS：边存在返回 1，否则 0。
- 每条操作输出一行，U 保持两端邻接一致，D 不自动插入反向边。重复 ADD 不产生平行边，删除不存在边无副作用。q=0 时输出为空。

### 连通与 SCC 专项

**15/16 无向分量**：输入 `n m` 和简单无向图，0-based，`1 <= n <= 100000`，`0 <= m <= 200000`。15 输出 k 和 n 个分量编号；按各分量最小顶点递增赋编号 `1..k`。16 输出 k 和按非增序排列的 k 个分量规模。

**17 弱连通**：输入规模同 15，有向图允许自环和平行边；忽略方向计算分量，输出合同同 15。弱连通不意味着任意两点沿原方向互达。

**20 Building Roads**：stdio 输入 `n m` 和 m 条简单无向边，顶点 `1..n`；本 Lab 约定 `1 <= n <= 100000`，`0 <= m <= 200000`。取各分量最小顶点，排序为 `r1 < ... < rk`；输出 k-1，再依次输出 `r1 r2`、...、`r1 rk`。已连通仅输出 0。该规范方案是原题任意最优道路方案的一种课程适配。

**21 Flight Routes Check**：输入 `n m` 和有向边，1-based；本 Lab 约定 `1 <= n <= 100000`，`0 <= m <= 200000`，允许自环和平行边。强连通输出 YES；否则输出 NO 后按以下优先级输出唯一见证：若有点不能从 1 到达，取最小此点 v，输出 `1 v`；否则取最小不能到达 1 的点 v，输出 `v 1`。见证选择是课程约定，原题允许任意有效不可达点对。

**22 Planets and Kingdoms**：输入图约定同 21；输出 k 和按输入顶点顺序排列的 n 个 SCC 编号。按每个 SCC 的最小顶点递增规范化为 `1..k`；不要求编号是拓扑序。原题允许任意一致的 SCC 编号。

**23 SCC 凝聚图**：输入 `n m` 和有向边，0-based，`1 <= n <= 100000`，`0 <= m <= 200000`，允许自环和平行边。输出首行 `k p`，第二行 n 个 SCC 编号，随后 p 行凝聚边。编号按 SCC 最小顶点升序从 1 开始；剔除分量内部边，对跨分量边去重并按 `(from,to)` 字典序输出；p=0 时无边行。所有原始顶点均须归属，包括孤立点。

## 算法与性能

- 星型中心从前两条边交点判断，仍完整消费输入；总读取时间 O(n)，辅助空间 O(1)。法官用入度和出度 O(n+m)。
- 矩阵题 O(n^2+m+q)；三种表示转换至少 O(n^2+m)，符合完整矩阵输出成本。邻接表规范化与转置排序成本写为 O(n+m+sum(d_v log d_v))，不能笼统声称 O(n+m)。
- ADT 用每个顶点的 `std::set<int>`，单次操作 O(log(n+1)) 上界，空间 O(n+e)，e 为当前边数。
- 网络秩 O(n^2+m)；普通遍历、弱连通、分量规模和道路方案 O(n+m)，分量规模排序另加 O(k log k)。省份矩阵遍历 O(n^2)。
- 点对数使用 `long long` 与跨分量前缀累计；乘法先提升为 64 位。完全分量按内部边数与 s(s-1)/2 比较，孤立点成立。
- 强连通判断在原图、反图各遍历一次。SCC 使用迭代 Kosaraju，第一次 DFS 用带邻居游标的栈得到退出序；不可用发现顺序代替退出序。原始 SCC 编号通过顶点递增扫描在线性时间规范化。
- 凝聚边排序去重使总成本为 O(n+m+m log(m+1))。大图避免递归深度依赖，C++ 使用标准头文件，兼容 Clang/MSVC。
- 默认 timeMs=2000、outputKb=4096；包含完整矩阵、边集或长邻接表的题目根据最大输出预算提升到 16384 KB，并用实际规模用例验证。时间预算若需调整，保留测量证据。
