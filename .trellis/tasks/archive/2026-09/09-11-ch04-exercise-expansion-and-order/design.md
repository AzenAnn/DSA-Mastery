# Design

## Identity And Ordering

清单顺序以 mapping.json 为唯一事实来源。31 行来自用户清单，旧 E10/E11/E15 按保留原则追加到 32/33/34。旧题 slug 不变；目录序号、README labId/title/H1、order=newNumber+8 及 README 命令同步更新。8 个 Theory Lab 的身份和内容不变。站点继续由 ContentIndex 自动生成分类顺序，不创建第二套侧栏。

迁移脚本先打印、核对全部源和目标绝对路径、唯一性及不覆盖约束，再一次性移动目录，使用结构化 frontmatter API 更新字段、一次替换映射处理活动引用，保留源文件换行。旧 student/solution/tests 在迁移前后计算摘要，必须逐文件相同。历史 Trellis 记录不改写；迁移清单保留旧新 ID 和完整目录映射，旧 URL 不额外创建兼容副本。

## New Programs

复用 tools/lab/scaffold.mjs 创建标准骨架，再补齐任务内容。各题独立、自包含；保留 C++17、stdio、薄 Makefile 和统一 CLI。允许使用 support/ 目录放本题的类型、输入解析和固定运行驱动，使 student/main.cpp 聚焦要求实现的函数；solution 只包含同一接口的参考算法。多源编译和 includeDirs 使用现有 manifest 合同，不修改判题器。

二叉树常规题沿用逐行层序 token/null 输入；两树题用两行，空树显式写 null。结点值使用 long long，单树最多 10000 结点，坡度累加与层和避免 int 溢出。层平均值使用 float 比较器和声明的绝对/相对容差。

孩子兄弟/线索/森林题使用唯一编号 1..n，0 表示空指针，根可以不是 1。一般树输入 n/root 加 firstChild/nextSibling 表；高度按边数，空树 -1。线索化输出完整指针/tag 表；后继题输入合法线索表、输出遍历和查询答案，源码人工核对 O(1) 辅助空间。森林与二叉树之间转换采用有序孩子数组和左右链接表，保留结点编号及顺序，输出完整结构以避免仅检查遍历的假阳性。

## Tests And Oracles

每个新增 Lab 恰好 20 点，每点 5 分，涵盖样例、空/单结点、左右单侧、深/宽/梳状结构、非 1 根、乱序编号、符号/数值边界及固定种子随机数据。测试生成脚本保存生成来源结构，由独立直接算法生成 oracle；不从 C++ solution 输出反向生成正确答案。至少一个典型错误模型在真实测试集合上被拒绝。对旧题只搬迁原有测试。

所有 34 题使用统一 lab:verify 验证 solution 满分、student 可编译且非满分、oracle 不漂移。另保留新题独立小规模枚举/变异与结构守恒检查；代表性多源新题打包后脱离仓库验证。新 README 使用原生折叠题解和相对引用代码片段，结构题附本地生成 PNG 示意图及 DOT 源。

## Saved Progress

此次 ID 重用需一次性迁移 VS Code globalState：只有识别新目录布局后，从源快照并行映射旧 Program ID 和事件键到最终 ID，不能逐条原地搬移。迁移版本标志与数据同次持久化，先保存原状态备份；load、别名迁移和 resetAll 保留该标志，源码快照路径不动。补充旧目录别名。使用现有扩展测试入口验证交叉映射、幂等、备份、清空后不二次迁移及旧布局不触发。

## Local Delivery

执行适用的扩展检查、pnpm test、Pages 前缀最终构建/产物及完整浏览器回归。专项检查顺序、31 清单项与 3 补充项、目录与搜索、题面代码/公式/图及四组桌面手机浅暗主题。最终构建后启动新本地预览服务；保留未提交状态等待用户验收。
