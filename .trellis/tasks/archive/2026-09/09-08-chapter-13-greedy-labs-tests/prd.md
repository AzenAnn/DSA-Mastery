# 扩充贪心章节题目与测试

## Goal

完善 `greedy`（第 13 章）实验题覆盖：审查章节现有题目，从 LeetCode 选择并新增两道与章节知识结构匹配的题目，同时让该章每一道现有题和新增题都具备 20 条有效测试用例。

## Background

- 第 13 章当前有 3 道 C++17 Program Lab：`13E01`「盛最多水的容器」（LeetCode 11）、`13E02`「最长回文串」（LeetCode 409）、`13E03`「跳跃游戏」（LeetCode 55）。
- 3 道现有 Lab 的 `tests/cases.json`、`.in` 与 `.out` 均各有 7 条；每题当前总分为 100。
- 章节理论正文明确讲解活动选择/区间调度，但尚无对应 Program Lab；现有 Lab 也没有覆盖“先排序、再做资源匹配”的基础贪心模型。
- 全仓搜索未发现 LeetCode 455「分发饼干」、435「无重叠区间」、134「加油站」或 763「划分字母区间」的重复 Lab。
- Program Lab 合同要求 C++17、标准输入输出、可编译但不满分的 starter、100 分 solution、总分恰为 100 的 cases，以及 `lab:verify` 对 reference 满分和 starter 非满分的校验。

## Requirements

- 盘点第 13 章现有实验题、题目元数据、学生代码、参考实现与测试数据的组织方式。
- 通过 LeetCode 原题页面核对候选题的题意、约束、难度与题号，避免与章节现有题目重复。
- 新增 `13E04`「分发饼干」（LeetCode 455，简单）与 `13E05`「无重叠区间」（LeetCode 435，中等），分别补齐排序匹配和活动选择/区间调度模型。
- `13E04` 的本地标准输入为孩子数 `n`、饼干数 `m`、`n` 个胃口值和 `m` 个饼干尺寸；输出最多满足的孩子数。允许 `m = 0`，数值范围与 LeetCode 原题一致。
- `13E05` 的本地标准输入为区间数 `n`，随后 `n` 行各给出 `start end`；输出使剩余区间互不重叠所需删除的最少区间数。端点相接视为不重叠，范围与 LeetCode 原题一致。
- 两道新题均采用 C++17、stdio 判题和 token 比较器，包含 README、`lab.json`、薄 Makefile、starter、solution 与完整测试目录。
- 将第 13 章所有现有题和两道新增题的测试用例分别扩充到恰好 20 条。
- 测试数据覆盖典型场景、边界条件、退化输入及容易出错的反例；期望结果必须可独立校验。
- 保持学生起始代码不泄露完整解答，并确保参考实现可通过全部测试。
- 每题 20 条 case 均按 5 分计，总分保持 100。
- 在第 13 章概览的“配套 Lab”中加入两道新题链接，不维护第二份手工 Lab 索引。
