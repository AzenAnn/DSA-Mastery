# 第 5 章树结构题库 Lab

## Goal

把维护者本地 Obsidian 导出的 09～13 节树结构习题整理为第 5 章可直接作答的五个 Theory Quiz Lab，使读者能够在网站完成选择题交互，并在同一页面完成源材料已有的综合题；本地验收通过并经维护者确认预览后，再提交独立 PR。

## Confirmed Facts

- 本地源目录中的 09～13 五个 Markdown 文件均存在，分别覆盖森林转换、树和森林遍历、哈夫曼编码、并查集与堆。
- 按文件顺序截取“最多 20 道选择题、最多 5 道综合题”后，实际题量为：09（16+1）、10（9+0）、11（20+5，原有 28 道选择题）、12（9+0）、13（13+3），合计 67 道选择题与 9 道综合题。
- 第 4 章已有同类 Quiz Lab：选择题由 `quiz.json` 和 `<QuizSet />` 提供交互，综合题写在 README 并用折叠解析呈现。
- 第 5 章已经声明 `autoLabChapter: 5`，有 `lab.json` 的 Quiz 会自动进入“本章 Labs → 理论 Theory”，无需维护第二份侧栏名单。
- 原 PR #61 已合并；本任务已从最新 `origin/main` 建立本地分支 `codex/chapter05-tree-labs`。

## Requirements

### R1 · 题目选择范围

- 只读取 09“森林与二叉树的转换”、10“树和森林的遍历”、11“哈夫曼树与编码”、12“并查集”、13“堆”。
- 每个文件按原始出现顺序取前 20 道选择题和前 5 道综合题；不足时全部保留，不补题、不跨节凑数。
- 11 节只采用前 20 道选择题，舍弃其余 8 道选择题；所有五道综合题保留。

### R2 · 五个 Chapter 5 Theory Lab

- 新增五个 `quiz` 类型 Lab，章节号为 5、顺序为 1～5，标题与 09～13 五个主题一一对应。
- 每个 Lab 包含 `README.md`、`lab.json`、`quiz.json`；选择题只在 `quiz.json` 维护，README 只挂载一次 `<QuizSet />`。
- 综合题保留题面、必要约束、参考答案、推导、算法/代码和复杂度分析，在 README 使用 `details` 折叠参考解析；无综合题的 10、12 节明确说明源材料未提供，不创建占位题。
- README 提供可检查的目标、前置知识、环境/输入/预期输出、作答步骤、完成清单与复盘，并链接第 5 章对应教材。

### R3 · 题目数据与 Markdown 转换

- 每道选择题使用中性稳定 ID（如 `ch05-01-q01`），保留四个选项、零基答案索引、解析、难度、考点和分值。
- 去除选项中的 A～D 前缀，确保每题恰好四个非空且不重复的选项。
- 将 Obsidian callout、wiki link 和个人语法转换为仓库现有 Markdown/VitePress 可渲染形式；树形示意与代码块保留为普通受信任 Markdown 内容。
- 不改写题目的知识结论；转换过程中若遇到格式歧义，以保留题意、答案和解析完整为优先，并记录需要人工知识复核的风险。

### R4 · 公开来源与个人发布痕迹清理

- 按维护者明确决定，公开 Lab 不展示题源：Quiz 省略 `source`、`targetId`，标题改为中性的“选择题 N”，综合题标题改为“综合题 N”。
- 移除题目信息中的“来源”“题目标识”和真题/巩固题来源后缀，移除正文内可识别的题库 ID、题源交叉引用与 CodeBrick 字样。
- 移除“查看原始页面”“相关学习资源”“看交互可视化”“答案来源说明”“答案来源：…Codex”、OJ/可视化等个人外链及删链后留下的空区块。
- 目标 Lab 中不得残留 Obsidian `[[...]]`、作者机器路径或个人工作流说明；内部 ID、正确答案与解析必须完整保留。

### R5 · 章节入口与本地验收

- 更新第 5 章概览中“Labs 仍为空”的过时说明，使其反映五个 Theory Lab 已可用；Exercise 与 Project 仍保持空槽位。
- 运行 Quiz manifest、内容、自动发现、构建和静态站点门禁，并检查工作树没有生成物污染。
- 启动最终静态预览，在桌面与 390px 窄屏检查 Chapter 5 侧栏、五个 Lab 路由、题量、综合题折叠和至少一条“选择 → 提交 → 反馈 → 题解 → 重试”交互链路。

### R6 · 远端交付门禁

- 预览阶段只保留本地分支与本地改动，不推送、不创建 PR。
- 维护者明确确认预览后，才提交、推送并创建面向 `main` 的独立 PR；PR 记录隐藏来源的维护者决定、实际门禁结果和人工复核风险。

## Out of Scope

- 不新增 Program 或 Project Lab，不实现 C++ 判题、工程脚手架或新组件。
- 不修改 Quiz Schema、`QuizSet` 行为、侧栏分类逻辑、样式或依赖。
- 不补写源材料缺少的题目，不把 11 节第 21～28 道选择题移入其他 Lab。
- 不发布 GitHub Pages，不自动合并 PR，不替代 Review Owner 对知识正确性与版权的人工复核。
