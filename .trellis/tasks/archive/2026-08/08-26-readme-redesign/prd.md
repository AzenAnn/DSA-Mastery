# README 信息架构与视觉改版

## Goal

把仓库根目录 README 从“早期 Demo 说明书”改造成 DSA Mastery 的清晰项目入口：读者能在首屏理解项目价值、查看课程覆盖范围，并快速进入在线课程或开始使用仓库。

## Background

- 当前 README 共 177 行，开头连续三段介绍后才出现在线课程入口，主要行动路径不够突出。
- README 仍称项目重点是第 0、1 章 Demo，但最新 `main` 已有 63 篇教材正文、109 个 Lab，内容覆盖绪论、线性结构、树、图、查找、排序和贪心等课程主题。
- 项目已有可复用的品牌横幅 `public/og.png`，视觉语言为纸张/墨色、靛蓝主色、橙色强调，与在线课程网站一致。
- 用户要求在正式 README 的特定内容区域生成并插入新图片，并在完成后提供本地部署预览。
- 仓库已有站内“Windows 学生实验环境安装指南”，线上路径为 `/learn/chapter-preface/02-windows-student-setup/`，README 无需重复环境配置步骤。
- 仓库尚无明确 License；README 必须保留“公开可见不等于获得再分发授权”的准确说明。

## Requirements

1. README 采用“学习者优先、贡献者次级”的信息层级，不在首屏堆叠维护流程。
2. 首屏复用现有 `public/og.png`，展示一句价值主张、在线课程主入口、课程地图/Labs/贡献入口和 Pages 检查状态。
3. 用简短模块回答四个问题：这是什么、为什么值得学、当前有什么、如何开始。
4. 内容规模使用耐更新的表述（如“60+ 教材页面、100+ Lab”）并配合主题分组，避免再次长期保留过时的精确 Demo 描述。
5. 保留三类 Lab 的区别：Theory/Quiz、Exercise/Program、Project。
6. “开始学习”只提供在线课程入口、一条仓库克隆命令，以及指向站内“Windows 学生实验环境安装指南”的链接；README 不重复 Node.js、pnpm、编译器或编辑器配置步骤。
7. 删除学习闭环、质量保证、仓库导览，以及指向教材原文件和 Lab 原文件的入口；这些内容目前不够完善或对 README 读者价值有限。
8. 保留精简的贡献入口与许可状态说明，不修改网站组件、不改变现有课程 URL。
9. 新增两张与现有品牌横幅一致的无文字横向插图：课程全景图放在“当前内容”，Lab 模式图放在“Lab 类型”。图片使用纸张纹理、墨色线稿、靛蓝主色和橙色点缀，避免生成式文字和水印。
10. 新图片保存到仓库 `public/readme/`，使用稳定、语义化的英文文件名，并通过 README 相对路径引用，附带准确的中文替代文本。
11. 完成后提供 GitHub 风格的本地 README 渲染预览，检查桌面宽度下的首屏、图片比例、表格和链接层级，并向用户展示实际截图。

## Out of Scope

- 重新设计在线课程首页、现有首屏横幅或 Logo。
- 重写环境配置教程、`CONTRIBUTING.md` 或其他指南正文。
- 在 README 中介绍学习闭环、质量保证机制或完整仓库结构。
- 在 README 中提供教材源文件、Lab 源文件或维护者工具入口。
- 自动生成 README 统计数字或引入新的 README 工具链。
- 在本任务中决定或添加开源 License。

## Key Decisions

- 读者路径优先于维护者流程。
- 复用且不修改现有 OG 横幅，只为“当前内容”和“Lab 类型”新增两张配套插图。
- 用分组与圆整数量表达内容规模，减少高频维护成本。
- README 只承担项目展示和主要导航；环境配置细节交给现有站内教程。
- 当前版本不展示尚未完善的学习闭环、质量机制与仓库导览。
- 新增图片只承担分区节奏与概念表达，不承担文字说明；可访问的信息仍由 README 正文提供。
- 采用两张插图而非为每个章节配图，避免 README 体积过大和视觉噪声。
