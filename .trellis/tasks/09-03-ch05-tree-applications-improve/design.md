### 2.3 5.5 B 树插入分步演算

已手工验算 `t=2`（每节点 1~3 键）依次插入 `10,20,5,6,12,30,7,17`，**两次分裂**分别发生在插入 `6` 与插入 `17`：

| 插入 | 判断 | 动作 | 结果 |
| --- | --- | --- | --- |
| 10 | 根空 | 直接插入 | `[10]` |
| 20 | 根 1 键，未满 | 有序插入 | `[10\|20]` |
| 5 | 根 2 键，未满 | 有序插入 | `[5\|10\|20]` |
| 6 | 根 3 键**已满** | 先分裂根，`10` 上升为新根；再进入 `[5]` | `[10]` / `[5\|6]` `[20]` |
| 12 | 根未满，`12>10` 进右孩子 `[20]` 未满 | 插入 | `[10]` / `[5\|6]` `[12\|20]` |
| 30 | 右孩子 2 键未满 | 插入 | `[10]` / `[5\|6]` `[12\|20\|30]` |
| 7 | `7<10` 进左孩子 `[5\|6]` 未满 | 插入 | `[10]` / `[5\|6\|7]` `[12\|20\|30]` |
| 17 | `17>10` 进右孩子**已满** | 先分裂，`20` 上升；再进入 `[12]` | `[10\|20]` / `[5\|6\|7]` `[12\|17]` `[30]` |

终态与正文既有示例完全一致，因此**替换的是呈现方式，不是结论**。

### 2.5 自测参考答案

25 题统一用 `::: details 参考答案` 折叠。原则：

- **计算题**给出完整演算过程，不只给结果（如 5.3 第 1 题的 `2,3,7,9` 合并与 WPL）；
- **证明题**给出完整论证（如 5.4 第 3 题按大小合并的 $O(\log n)$ 深度证明）；
- **开放题**给出要点清单与判断依据（如 5.5 第 5 题复合索引）。

5.2 第 5 题原本直接问正文已用粗体答过的内容，改为需要推理的反例问法，并在答案中说明。

## 3. 风险与规避

| 风险 | 规避 |
| --- | --- |
| 参考答案出错，比没有更糟 | 每题人工验算；计算题写出中间步骤便于复核 |
| `graphviz` 在深色主题下对比度不足 | 沿用第 4 章既有配色（`#2563eb` 等），本地预览双主题检查 |
| 新增内容使页面过长 | 答案一律折叠；图示替换 ASCII 而非叠加 |
| 误改 `labs/` 或第 4 章 | 完成后用 `git status` 与 `git diff --stat` 确认改动范围 |

## 4. 验证方法

1. `pnpm run validate:content`；
2. `pnpm run dev` 本地预览，逐页检查六篇；
3. 浅色/深色主题切换，390px 与 1440px 两种宽度；
4. 抽查 Lab 链接实际可跳转；
5. `git diff --stat` 确认只动 `content/chapter-05-tree-applications/` 六个文件。
