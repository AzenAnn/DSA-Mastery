# 6.1 邻接矩阵示例

邻接矩阵用一个 $n \times n$ 的矩阵记录顶点之间是否存在边。对于无权图，通常用 `1` 表示有边，用 `0` 表示无边。

::: example 三顶点无向图
设顶点集合为 $\{A,B,C\}$，边集合为 $\{(A,B),(B,C)\}$，对应的邻接矩阵为：

|   | A | B | C |
| --- | --- | --- | --- |
| A | 0 | 1 | 0 |
| B | 1 | 0 | 1 |
| C | 0 | 1 | 0 |

矩阵关于主对角线对称，说明每条无向边会同时记录两个方向。
:::

::: complexity 复杂度
判断两个顶点是否相邻只需访问一个矩阵单元，时间复杂度为 $O(1)$；矩阵本身需要 $O(n^2)$ 空间。
:::
