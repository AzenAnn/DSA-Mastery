# 7.2 最小生成树

在带权图上，有一个经典问题把"贪心"落到实处：**最小生成树**（Minimum Spanning Tree，MST）用最小的边权总和连通全部顶点。它依靠"每一步做局部最优选择"的贪心方法，背后的理论支撑是**切分定理**与**环性质**。理解"为什么贪心在这里是对的"，比单纯硬背代码更重要。

## 学习目标

- 说出生成树与最小生成树的定义，理解 $n$ 个顶点的树恰有 $n-1$ 条边；
- 陈述并论证切分定理与环性质；
- 实现 Prim 与 Kruskal 算法，分析各自复杂度；
- 说明两种算法的适用与不适用场景，并据此选型。

## 最小生成树的概念

**生成树（Spanning Tree）**：设 $G=(V,E)$ 是连通无向图，$G$ 的一棵生成树是包含全部 $n=|V|$ 个顶点、不含环且连通的子图。生成树恰好有 $n-1$ 条边——少一条就不连通，多一条必成环。

**最小生成树（MST）**：在所有生成树中，边权总和最小的一棵。这里的“最小”指边权和，不是边数或最大单边权值。边权可以为负，因此 MST 的总权值也可能为负。

理解生成树，先记住三条由"树"的定义直接推出的性质：

- $n$ 个顶点的树恰有 $n-1$ 条边；
- 树中任意两顶点之间有且仅有一条简单路径；
- 给树加任意一条边，会形成唯一一个环；删去树上任意一条边，图不再连通。

::: tip 最小生成树可能不唯一
当图中存在权值相等的边时，MST **可能**不止一棵，但等权边并不必然导致多解；无论有多少棵 MST，**最小边权和都是唯一确定的**。若所有边权两两不同，则 MST 一定唯一（见下文定理）。存在多棵 MST 时，算法返回哪一棵取决于具体的选边顺序，但总权值相同。
:::

## 生成最小生成树：贪心框架

生成 MST 的通用做法是一个**贪心框架**：维护一个边集 $A$，始终保持 $A$ 是"某棵 MST 的子集"；每轮往 $A$ 里加一条**安全边**，直到 $A$ 有 $n-1$ 条边。所谓“安全边”，是指加入后新的边集仍是某棵 MST 的子集。由于 Kruskal 的 $A$ 在构造过程中可能包含多个连通分量，这里不能一概称为“子树”。

Prim 与 Kruskal 的区别，只在于"如何找安全边"：Prim 维护一棵连通的树，每次选跨越"树内/树外"的最小边；Kruskal 维护一片森林，每次选不形成环的最小边。它们共享同一个正确性来源——下面两条定理。

## 两条核心定理

### 切分定理（Cut Property）

把顶点集 $V$ 分成两个非空且不交的部分 $S$ 与 $V-S$，称 $(S, V-S)$ 是一个**切分**；端点分别落在两侧的边称为**跨越切分**的边。

> **切分定理**：对任意切分 $(S, V-S)$，若 $e=(u,v)$ 是跨越该切分的最小权边，则 $e$ 一定属于某棵 MST。

**证明（交换法）**：设 $T$ 是任意一棵 MST。若 $e\in T$ 已成立；否则，在 $T$ 中连接 $u$ 与 $v$ 的唯一路径上，必存在一条也跨越 $(S,V-S)$ 的边 $e'$（因为路径从 $S$ 出发、终点在 $V-S$）。由于 $e$ 是跨越切分的最小权边，$w(e)\le w(e')$。把 $T$ 中的 $e'$ 换成 $e$，得到新的生成树 $T'$，其边权和 $w(T')\le w(T)$；又 $T$ 已是最小，故 $w(T')=w(T)$，$T'$ 也是 MST，且含 $e$。证毕。

切分定理说明，跨越某个切分的最小权边至少能出现在一棵 MST 中。Prim 使用的切分是“当前树的顶点集合 $S$”与“尚未加入的顶点集合 $V-S$”，每一步选择跨越该切分的最小权边，把对应的新顶点和边加入当前树。构造尚未完成时应称其为“当前树”，而不是“当前 MST”。

### 环性质（Cycle Property）

> **环性质**：无向图中，任意一个环上权值**最大**的边（若最大边唯一）不属于任何 MST。

**证明（反证）**：设 $e$ 是环 $C$ 上唯一的最大权边，且 $e$ 属于某棵 MST $T$。从 $T$ 删去 $e$ 会把 $T$ 分成两个连通分量；环 $C$ 上必存在另一条边 $e'$ 连接这两个分量（否则 $C\setminus\{e\}$ 无法让删边后的两部分重新连通）。把 $e$ 换成 $e'$ 得到新生成树，边权减少（$w(e')<w(e)$），与 $T$ 最小矛盾。证毕。

环性质解释了为什么环上的唯一最重边可以直接排除。Kruskal 遇到会使当前森林成环的候选边时，这条边不轻于环中此前已选的边；即使存在并列权值，也可以跳过当前候选边，因为当前森林已经用不更重的边连通了它的两个端点。这里不能把“并列最重”误写成“不属于任何 MST”：只有**唯一最重**时才有这个强结论。

切分定理与环性质从两个方向约束选边：前者说明某条边可以安全加入某棵 MST，后者说明唯一最重边不可能出现在任何 MST 中。“属于某棵”不等于“属于所有”，使用时要保留量词。

### 由定理得到的两个推论

- **唯一性**：若所有边权两两不同，则 MST 唯一。反证如下：若存在不同的 MST $T_1,T_2$，考察只属于其中一棵树的边（即二者的对称差），并从中取权值最小的边 $e$；不妨设 $e\in T_1$。把 $e$ 加入 $T_2$ 会形成一个环，其中必有边 $f\in T_2\setminus T_1$；边权互异且 $e$ 是对称差中的最轻边，所以 $w(e)<w(f)$。用 $e$ 替换 $f$ 会得到权值更小的生成树，与 $T_2$ 最小矛盾。
- **贪心安全**：算法应维护“当前森林包含于某棵 MST”这一不变量。若某个切分不被当前森林中的边跨越，那么选取该切分上的最小权边，交换论证可保证加入后仍存在一棵包含新森林的 MST。Prim 与 Kruskal 选择的切分都满足这个条件；不能把规则简化为“任取某个切分的最小边”。

## Prim 算法

Prim 从任意一个起点出发，把已选顶点看作集合 $S$，每轮在"一端在 $S$、一端在 $V-S$"的边里挑最小权的一条，把新顶点并入 $S$。这正是切分定理的直接应用：每次选的边都是跨越切分 $(S,V-S)$ 的最小边。

朴素实现维护一个距离数组 `dist[v]`（$v$ 到当前树的最小边权），每轮线性扫描找最小 `dist`，共 $n$ 轮，每轮 $O(n)$：

$$
T(n) = O(n^2).
$$

由于合法 MST 的总权值可能恰好为 `-1`，不能用 `-1` 同时表示“不连通”。下面用 `std::optional<long long>` 区分失败与合法的负权结果，并用 64 位整数保存边权和。

```cpp:line-numbers [prim.cpp]
// 邻接矩阵 g[u][v] = 边权；INF 表示无边；nullopt 表示图不连通
std::optional<long long> prim(const std::vector<std::vector<long long>>& g, int n) {
    if (n == 0) return 0LL;
    std::vector<long long> dist(n, INF); // dist[v]：v 到当前树的最小边权
    std::vector<bool> inTree(n, false);
    long long total = 0;
    dist[0] = 0;                         // 从顶点 0 开始
    for (int i = 0; i < n; ++i) {
        int u = -1;
        for (int v = 0; v < n; ++v)      // 选 dist 最小且不在树内的顶点
            if (!inTree[v] && (u == -1 || dist[v] < dist[u])) u = v;
        if (u == -1 || dist[u] == INF) return std::nullopt;
        inTree[u] = true;
        total += dist[u];
        for (int v = 0; v < n; ++v)      // 用 u 更新邻居
            if (!inTree[v] && g[u][v] < dist[v]) dist[v] = g[u][v];
    }
    return total;
}
```

若用邻接表 + 二叉堆维护"当前到树的最小边权"，每轮取堆顶 $O(\log n)$、松弛总次数 $O(m)$，复杂度降为：

$$
T(n,m) = O((n+m)\log n).
$$

::: warning 稠密图别急着上堆
堆优化 Prim 通常更适合稀疏图；稠密图中 $m$ 接近 $n^2$ 时，$O(m\log n)$ 的上界反而高于朴素版的 $O(n^2)$。具体实现还会受常数和存储方式影响，判断时应比较 $m$ 与 $n$ 的规模，而不是认为“使用堆一定更快”。
:::

## Kruskal 算法

Kruskal 把所有边按权值**升序排序**，从最小边开始逐条考虑：若这条边的两个端点当前**不在同一连通分量**（加入后不成环），就选中它并合并两个分量。连通性用**并查集**维护。

正确性分两步：当候选边 $e=(u,v)$ 跨越两个连通分量时，取当前包含 $u$ 的分量作为切分的一侧；按权值排序可知，$e$ 是跨越该切分且尚未处理的最小权边，因此可由切分定理安全加入；当候选边两端已在同一分量时，当前森林中已经存在连接两端的路径，且路径上的边都不重于该候选边。加入它只会形成环，因此可以跳过，并继续保持当前森林可扩展为某棵 MST。

排序占主导，总复杂度：

$$
T(m) = O(m\log m).
$$

```cpp:line-numbers [kruskal.cpp]
struct Edge {
    int u, v;
    long long w;
    bool operator<(const Edge& o) const { return w < o.w; }
};

struct DSU {
    std::vector<int> p;                       // 根节点保存负的分量大小
    DSU(int n) : p(n, -1) {}
    int find(int x) { return p[x] < 0 ? x : p[x] = find(p[x]); }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (p[a] > p[b]) std::swap(a, b);     // 让较大的分量作为新根
        p[a] += p[b];
        p[b] = a;
    }
};

// 返回 nullopt 表示图不连通；负数总权值仍是合法结果
std::optional<long long> kruskal(std::vector<Edge> edges, int n) {
    if (n == 0) return 0LL;
    std::sort(edges.begin(), edges.end());    // 按权值升序
    DSU dsu(n);
    long long total = 0;
    int cnt = 0;
    for (auto [u, v, w] : edges) {
        if (dsu.find(u) != dsu.find(v)) {     // 不成环才加入
            dsu.unite(u, v);
            total += w;
            if (++cnt == n - 1) break;        // 已选满 n-1 条边
        }
    }
    if (cnt != n - 1) return std::nullopt;
    return total;
}
```

## 算法的适用范围与选择

Prim 与 Kruskal 都能正确求出 MST，选谁取决于图的**稠密程度**和**存储表示**：

| 场景 | 推荐算法 | 复杂度 | 说明 |
| --- | --- | --- | --- |
| 稠密图（$m \approx n^2$） | Prim 朴素版 | $O(n^2)$ | 邻接矩阵扫描，常数小 |
| 稀疏图（$m \approx n$） | Kruskal | $O(m\log m)$ | 排序 + 并查集，实现简单 |
| 稀疏图，边已按权排序 | Kruskal | $O(m\,\alpha(n))$ | 省去排序，几乎线性 |
| 稀疏图，需堆优化 | Prim + 堆 | $O((n+m)\log n)$ | 邻接表 + 优先队列 |

**各自的"不适用"部分**：

- **Prim 朴素版**在稀疏图上浪费：$O(n^2)$ 中大量时间花在扫描无边连接的顶点上。
- **Prim 堆优化**在稠密图上退化：松弛次数 $m$ 接近 $n^2$，堆操作反而拖慢。
- **Kruskal** 需要先把边排序；若图是动态的、边频繁变化，反复排序不划算。
- **求覆盖全图的 MST 要求图连通**：图不连通时，Kruskal 得到的是最小生成**森林**，Prim 则只能得到起点所在连通分量的最小生成树。

::: tip 选型口诀
先看稠密还是稀疏，再看有无排序/堆的现成条件。**稠密图选 Prim（矩阵），稀疏图选 Kruskal**，是竞赛与工程里最常用的两条默认规则；需要精确到常数时再考虑堆优化 Prim。
:::

## 做题流程与边界检查

手算或编程实现 MST 时，可以固定使用下面的检查顺序：

1. 先确认图是否连通；不连通时输出约定的失败结果，不能把生成森林误当成生成树。
2. 对 Kruskal，先按权值排序，再逐边判断并查集根是否相同；相同代表成环，必须跳过。
3. 对 Prim，维护“每个未加入顶点连接当前树的最小边”，加入顶点后只更新它的邻居。
4. 最后检查选边数量：连通的 `n` 个顶点必须恰好选出 `n-1` 条边。

重点边界包括单顶点图、平行边、相同权值、自环、负权边和稠密图。自环不能进入生成树；同一对端点之间存在多条平行边时，较重的边不会优于较轻的边，可以全部交给算法处理，也可以预处理后只保留最小权值；相同权值可能产生多棵结构不同但总权值相同的 MST。实现中不要把“存在等权边”直接当作 MST 不唯一的判定条件。

配套 Lab 建议先完成 Kruskal 的并查集版本，再用 Quiz 复核切分定理、环性质和算法选型，最后通过边界测试验证“不成环”和“恰好 n-1 条边”两个不变量。
