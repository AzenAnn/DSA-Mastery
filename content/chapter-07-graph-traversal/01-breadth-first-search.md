# 7.1 BFS 按层遍历示例

广度优先搜索（BFS）从起点出发，先访问距离起点更近的顶点，再逐层向外扩展。队列负责保持这种先后顺序。

::: example 从 A 开始遍历
设 `A` 与 `B、C` 相邻，`B` 与 `D` 相邻。按字母顺序检查邻居时，队列变化如下：

| 步骤 | 出队顶点 | 新入队顶点 | 队列 |
| --- | --- | --- | --- |
| 初始 | — | A | A |
| 1 | A | B、C | B、C |
| 2 | B | D | C、D |
| 3 | C | — | D |
| 4 | D | — | 空 |

因此遍历顺序为 `A → B → C → D`。
:::

::: property 入队时标记
顶点应在入队时立即标记为已访问，避免它在出队前被多个邻居重复加入队列。
:::
