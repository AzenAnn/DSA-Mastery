# 6.1 二叉排序树

**二叉排序树**（BST）是满足如下性质的二叉树：左子树上所有节点值小于根、右子树上所有节点值大于根，且左右子树也是 BST。它的中序遍历输出**有序序列**——这是它最重要的不变量。

## 学习目标

- 实现 BST 的查找、插入与删除（含双子女删除）；
- 分析 BST 操作的平均与最坏复杂度；
- 解释插入顺序如何决定树的形态，说出平衡树的动机。

## 查找与插入

查找沿根下行：比根小走左、比根大走右，直到命中或走到空。插入按同一路径下行，找到空位挂上新节点。树高为 `h` 时，两者均为 `O(h)`。

```cpp:line-numbers [bst-insert.cpp]
Node* insert(Node* root, int value) {
    if (!root) return new Node{value};
    if (value < root->value) root->left = insert(root->left, value);
    else if (value > root->value) root->right = insert(root->right, value);
    return root;                       // 相等时不插入（关键字唯一）
}
```

::: tip 查找次数由树高决定
BST 的查找代价是"从根到目标节点的路径长度"，平均与最坏情况都取决于树高 `h`，而不是节点总数 `n`。这是理解 BST 性能的关键。
:::

## 删除：三种情况

1. **叶节点**：直接删除；
2. **一个孩子**：用孩子顶替被删节点；
3. **两个孩子**：用**中序后继**（右子树中最小的节点）或中序前驱顶替，再删除该后继节点。

双子女删除的关键：中序后继没有左孩子，删除它退化为情况 1 或 2；顶替后 BST 性质与中序有序性保持不变。

## 复杂度：平均与退化

对随机插入顺序，树高期望 `O(\log n)`，查找、插入、删除平均 `O(\log n)`。但若插入顺序有序（如 `1, 2, 3, …, n`），每个新节点都挂在最右，BST 退化成一条链：

$$
h = n,\qquad T_{worst} = O(n).
$$

退化后 BST 与顺序表的顺序查找毫无差别——这就是需要**平衡二叉树**（AVL、红黑树）的原因：它们把树高约束在 `O(\log n)`，从而保证最坏 `O(\log n)`。

## 小结

BST 用"有序"这个不变量换来比线性表更快的动态查找，但性能承诺依赖树形，而树形依赖插入顺序。理解"随机插入树高期望对数、有序插入退化线性"，才能解释为什么真实系统中使用平衡版本。
