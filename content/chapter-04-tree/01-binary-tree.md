# 4.1 二叉树：定义、性质与遍历

树是 $n \ge 0$ 个节点的有限集合：`n = 0` 时为空树；否则有且仅有一个**根**节点，其余节点划分为若干互不相交的子树。二叉树是每个节点**至多有两个孩子**的树，孩子分**左**与**右**，顺序不能颠倒。

## 学习目标

- 解释树的术语与二叉树的基本性质，能证明 $n_0 = n_2 + 1$；
- 用递归实现先序、中序、后序遍历，用栈实现非递归版本；
- 用队列实现层序遍历，说明其与栈版本的本质区别；
- 由先序 + 中序（或中序 + 后序）唯一确定一棵二叉树。

## 基本术语

| 术语 | 含义 |
| --- | --- |
| 度 | 节点的子树个数；二叉树节点度 ≤ 2 |
| 深度/高度 | 根在第 1 层，叶节点最大层数即树高 |
| 完全二叉树 | 除最后一层外每层填满，最后一层靠左连续 |
| 满二叉树 | 每层都填满，叶子全在最底层 |

## 关键性质

设二叉树深度为 `k`，节点数为 `n`，叶节点数为 $n_0$、度为 2 的节点数为 $n_2$：

$$
\text{第 } i \text{ 层最多 } 2^{i-1} \text{ 个节点},\qquad n \le 2^k - 1.
$$

叶节点与度 2 节点满足 **$n_0 = n_2 + 1$**。证明：所有节点度数之和等于边数，即 $n_1 + 2n_2 = n - 1$，又 $n = n_0 + n_1 + n_2$，两式相减即得 $n_0 = n_2 + 1$。

完全二叉树用数组存储时，下标 `i` 的节点（从 1 开始计数）左孩子为 `2i`、右孩子为 `2i+1`、父节点为 $\lfloor i/2\rfloor$——这是堆与优先队列（见 4.3）的实现基础。

## 四种遍历

递归版本的先序、中序、后序只是访问时机不同：

```cpp:line-numbers [recursive-traversal.cpp]
void preorder(Node* t, Visit fn) {
    if (!t) return;
    fn(t);                // 先序：先访问根
    preorder(t->left, fn);
    preorder(t->right, fn);
}
```

中序把 `fn(t)` 移到两次递归之间，后序移到末尾。层序则用队列：访问根后把左右孩子依次入队，队首出队访问，再入队其孩子——**先来先处理**，这正是第 2 章队列语义的直接应用。

::: warning 非递归遍历用栈模拟系统调用栈
递归版本依赖函数调用栈；非递归版本需要**显式栈**来保存"待访问的子树"信息。以中序为例：不断把左孩子压栈直到为空，然后弹栈访问，再转向右子树。理解"栈里保存的是尚未访问的祖先"，就不会把三个版本记混。
:::

## 由遍历序列确定二叉树

先序 + 中序可以唯一确定二叉树：先序的第一个节点是根；在**中序**中找到根的位置，其左边是左子树的中序、右边是右子树的中序；按子树长度在先序中划分出左、右子树的先序，递归进行。中序 + 后序同理。**只有先序 + 后序不能唯一确定**，因为无法区分左、右子树。

## 小结

二叉树用"左右孩子 + 空指针"表达层次关系，其性质由完全性、深度与节点数之间的数量关系给出。四种遍历中，递归与栈/队列版本对应了两种"辅助结构"的选择；遍历序列的互推则是后续序列化与重建的基础。
