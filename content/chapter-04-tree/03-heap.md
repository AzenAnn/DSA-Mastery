# 4.3 堆与优先队列

**堆**是一种特殊的完全二叉树：每个节点的值**不小于**（最大堆）或不大于（最小堆）其孩子的值，因此堆顶是全局最大（或最小）值。堆用数组存储、按"小根堆/大根堆"性质维护，是优先队列最常用的实现。

## 学习目标

- 用数组描述完全二叉树并实现堆的插入、删除与堆顶访问；
- 理解上浮（sift up）与下沉（sift down）的调整过程；
- 论证插入、删除为 `O(log n)`、建堆为 `O(n)`。

## 数组表示

完全二叉树按层序存入数组（下标从 1 开始），节点 `i` 的左孩子 `2i`、右孩子 `2i+1`、父节点 $\lfloor i/2\rfloor$。于是"比较父子"就是"比较数组元素"，不需要指针。

```
       5
     /   \
    3     4        →  数组: [_, 5, 3, 4, 1, 2]
   / \
  1   2
```

## 插入：上浮

新元素先放到数组末尾（保持完全性），再与其父节点比较，不满足堆性质就交换，直到到达根或满足性质。路径长度即树高，因此插入为 `O(log n)`。

```cpp:line-numbers [sift-up.cpp]
void insert(int value) {
    data[++size] = value;
    for (int i = size; i > 1 && data[i] > data[i / 2]; i /= 2)
        std::swap(data[i], data[i / 2]);   // 最大堆：孩子大于父节点就交换
}
```

## 删除堆顶：下沉

堆顶（数组首元素）与末尾元素交换后移除末尾；新的首元素向下调整：与较大的孩子比较，若不满足堆性质就与孩子交换，直到叶层。删除同样为 `O(log n)`，堆顶访问为 `O(1)`。

## 建堆：从最后一个非叶节点下沉

从最后一个非叶节点 $\lfloor n/2\rfloor$ 开始，依次对每个节点做下沉。总代价分析：第 `h` 层有约 $2^{k-h}$ 个节点、每个下沉最多 `h` 步，所以总步数：

$$
T(n) = \sum_{h=1}^{k} \frac{n}{2^{h}} \cdot h \le n \sum_{h=1}^{\infty} \frac{h}{2^h} = 2n = O(n).
$$

因此**建堆是 `O(n)`**，而不是"n 次插入"的 `O(n log n)`。

::: warning 区分两种"堆"
"堆排序"（第 7 章）用堆顶的全局最大/最小值反复取出排序；"优先队列"把堆当作支持插入与取最小的抽象数据结构。两者共用同一个堆实现，但使用目的不同。
:::

## 小结

堆用"完全二叉树的数组表示"把树形结构折叠成紧凑数组，用上浮/下沉两条调整路径维持 `O(log n)` 的插入与删除。建堆的 `O(n)` 分析是摊还思想的又一次应用。堆是优先队列、堆排序与图的最短路径优化（第 5 章）的共同基础。
