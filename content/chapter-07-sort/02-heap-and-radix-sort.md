# 7.2 堆排序与基数排序

上一节证明比较排序下界是 `\Omega(n \log n)`。本节讲两条"绕路"：堆排序用第 4 章的堆把选择排序优化到 `O(n \log n)` 且原地；基数排序干脆不做比较，直接突破下界。

## 学习目标

- 实现堆排序，分析其原地与不稳定的来源；
- 实现基数排序，解释它为什么不受 `\Omega(n \log n)` 约束；
- 归纳各类排序的时间、空间与稳定性，完成选型。

## 堆排序：用堆做选择

选择排序每趟 `O(n)` 找最小，总代价 `O(n²)`。堆排序把"找最值"换成堆的 `O(\log n)` 出堆：

1. **建堆**：把数组调整成大根堆，`O(n)`；
2. **n - 1 趟**：堆顶（最大值）与末尾交换，堆规模减一，再做一次下沉恢复堆性质。

$$
T(n) = O(n) + (n-1)\cdot O(\log n) = O(n \log n).
$$

与快排不同，堆排序**最坏也是** `O(n \log n)`；且完全原地，只需 `O(1)` 额外空间。

::: warning 堆排序为什么不稳定
堆顶与末尾元素交换时，会把相同的较大关键字直接换到数组尾部，破坏相同关键字的相对顺序。需要稳定排序时不能选堆排序。
:::

```cpp:line-numbers [heap-sort.cpp]
// 每趟：堆顶 a[0] 与末尾交换，规模减一后下沉
for (int i = n - 1; i > 0; i--) {
    std::swap(a[0], a[i]);
    siftDown(a, 0, i);          // 前 i 个元素恢复大根堆
}
```

## 基数排序：不比较，按位分配

基数排序处理**关键字可以拆成 d 位**的数据（如 d 位十进制数）。它从最低位（LSD）开始，对每一位做一次**稳定的**"分配-收集"：按该位数字分到 `r` 个桶，再按桶序收回。每趟 `O(n + r)`，共 d 趟：

$$
T(n) = O\bigl(d \cdot (n + r)\bigr).
$$

`d` 和 `r` 是常数时，它是**线性**的——并不违反下界，因为下界只约束"比较排序"，而基数排序用"按位查看"取代了"比较"。代价：要求关键字可拆位，且每趟必须是**稳定**的（否则低位的排序会被高位打乱）。

## 全章选型表

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 插入/冒泡 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 选择 | `O(n²)` | `O(n²)` | `O(1)` | 不稳定 |
| 归并 | `O(n \log n)` | `O(n \log n)` | `O(n)` | 稳定 |
| 快排 | `O(n \log n)` | `O(n²)` | `O(\log n)` | 不稳定 |
| 堆排序 | `O(n \log n)` | `O(n \log n)` | `O(1)` | 不稳定 |
| 基数排序 | `O(d(n+r))` | `O(d(n+r))` | `O(n+r)` | 稳定 |

## 小结

堆排序用堆的结构让选择排序"提速"到最优比较界且原地；基数排序跳出比较框架，用关键字结构换线性时间。至此排序主题收束：选型看数据规模、初始顺序、内存与稳定性四件事——这也是整门数据结构课程反复强调的思维：**没有万能结构，只有权衡**。

## 练习

1. 对 `{4, 1, 3, 2, 16, 9, 10, 14, 8, 7}` 走一遍建堆与堆排序全过程。
2. 为什么基数排序每一趟必须稳定？如果某趟不稳定会发生什么？
3. `0 \sim 999` 之间的整数排序，基数排序 d = 3、r = 10，与快排对比何时更有优势？
4. 堆排序能在线性时间内求出前 k 大元素吗（k 很小）？时间复杂度是多少？
5. 结合 7.1 的决策树下界，解释为什么说基数排序"突破"了下界而不是"推翻"了下界。
